## Decisions that differ from the issue text

### Stage 1 decisions (recorded 2026-10-12, from `plan.md`)

1. **"Extend the profile with `tags` and `timestamp`."** Both are optional keys on all three document types; `resource` stays rejected. `tags` is a list of non-empty strings, a duplicate tag is a violation, and `render` emits `tags` sorted. `timestamp` is an RFC 3339 / `xsd:dateTime` string, and a malformed one is a violation. Built: the schema table marks each key required or optional and both the writer and the validator read it, with fixtures for sorted render, duplicate tag, malformed and valid timestamp, `resource` still rejected, and a document with neither key.
2. **"No default roots in `raf-source`."** `Workspace::load` takes explicit roots, and each consumer owns its own default (census-ledger keeps the workspace root); the PR quotes the issue's "(default `crates/`)" and this decision. Built: `Workspace::load` has no default root, and an empty root list is the typed `NoRoots` error (see G9 below).
3. **"Containment race: closed on Linux, with a portable fallback elsewhere."** Linux: after opening the canonical path with `O_NONBLOCK|O_NOFOLLOW` and `fstat`, the handle's real path (`/proc/self/fd/<fd>`) must still lie under the canonical root. Other unix: re-canonicalise after the open and require the prefix and an equal `(dev, ino)`. Non-unix: a std-only open, a regular-file check on the handle, then post-open re-canonicalisation. Built: a per-platform handle verifier with the Contract and SECURITY.md Containment bullet stating each guarantee, plus `make cross-check` (`cargo check -p raf-source --locked` for `x86_64-apple-darwin` and `x86_64-pc-windows-gnu`) in `check` and CI. The non-Linux part was later superseded by the R8 decision below.
4. **"Links split across lines are refused."** `Body` records every inline link or image whose text or destination spans a line break, outside fences and code spans. Built: `Rule::SplitLink` reports it at its line, `docs_contract` applies it to every tracked Markdown file through `Body::parse`, and the architecture sentence reads "A link split across lines is a violation."
5. **"Completion adversary."** The user stopped the earlier run; it runs once, on its own, on the merged plan, unless the user declines at plan approval. Built: one independent completion-adversary pass on the merged plan (findings F-1..F-8, all integrated) before implementation.

### Stage 2 user decisions (2026-10-12, verbatim answers)

- **A1 (inherent impl whose self type the index cannot see).** Question: "an inherent `impl` whose self type the index can't see ... currently fails the WHOLE load ... How should it behave?" Answer: **"Per-item marker (Recommended)"**. Built: the impl is indexed with an `Unresolved` self-type marker, the load succeeds, resolution through it is a typed error, and the Contract is updated.
- **A2 (two packages with the same `[lib] name`).** Answer: **"Key crates by package (Recommended)"**. Built: a shared crate-name head resolves `Ambiguous`, and a package-qualified form disambiguates.
- **G9 (empty root list).** Answer: **"Typed NoRoots error (Recommended)"**. Built: `LoadErrorKind::NoRoots`, and the Verification line becomes "no roots is an error".
- **Sign-offs.** Answer: **"Unicode-3.0 for unicode-ident, NCSA for libfuzzer-sys, `<pkg>::bin_crate::<bin>` naming, `Rule: Sync` in census-rule-api"**. Built: crate-scoped licence exceptions in `deny.toml` and `fuzz/deny.toml` (pinned to the audited versions), bin crates named `<pkg>::bin_crate::<bin>`, and `Rule: Sync` in census-rule-api.
- **R3 per-file token budget.** Question: "R3's per-file token budget: syn's AST for the costliest admitted shape costs ~1,122 bytes/token, so a 512 MiB one-file parse peak allows ~475k tokens. Five real registry crates exceed it (chrono-tz 1.5M, encoding_rs 797k, chromiumoxide_cdp 732k, brotli 567k, spm_precompiled 476k). ... How should the bound and these crates be handled?" Answer: **"(1) - default to 2M"**. Built: `LoadOptions::max_file_tokens` is configurable with a default of 2,000,000 tokens, and the Contract states the one-file parse peak as a formula of the limit (about 2.1 GiB at the default).
- **R8 non-Linux containment.** Question: "R8: on macOS/BSD/Windows a swap made before the open and undone before the check can make a read return an outside file's contents (200k-try race: ~2-3k leaks; Linux: 0). std has no handle-relative path API there, and unsafe_code is denied. How should non-Linux containment be handled?" Answer: **"Add rustix + windows-sys"**. Built: `rustix` for handle-relative opens and listing on non-Linux Unix, and `windows-sys` for `GetFinalPathNameByHandleW` on Windows, with one scoped `#[allow(unsafe_code, reason = ...)]` and SAFETY comment confined to the single Windows module making that call; the workspace `unsafe_code = "deny"` lint is unchanged and both dependencies remain subject to `make deny`.
- **Merge scope and time cap (2026-10-14 22:25).** Question: "Which scope do you want for merging issue 2?" Answer: **"Everythign - you have 6 hours - capped"**. Built: R5c, R5d, R11 and R13 stay in this PR, with the hard deadline 04:25 on 2026-10-15.
