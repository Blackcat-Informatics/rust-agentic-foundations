    Verification
    
    - End-to-end fixtures for the Capability and Change documents: each rule of the OKF
      profile and each reader error surfaces through `check` with its file and location,
      and every kind in `Finding::KINDS` is produced by a named fixture.
    - A state fixture per state: each accepted with matching content, and each rejected
      with a mismatch, such as a `delivered` capability holding a PROPOSED block or an
      open record, a `designed` capability holding a block, or a `considered` capability
      holding none.
    - Marker fixtures: a block naming a missing change, a block whose change does not
      list the capability, a block whose section the change does not affect, a block in
      an Architecture document, and a marker inside a code fence that is not read as a
      block.
    - Graph fixtures: every kind of node and edge, section-to-section links, each query,
      an acyclic graph that passes, cycles of one, two and three nodes that fail, and
      `depends`, `changes` and `moved` references to a missing document that fail.
    - Link fixtures over every link form: a missing target, a missing anchor, a target
      outside the repository and a tracked symlink, judged against the tracked set and
      not the tree.
    - Reference fixtures: issue and pull request numbers and process wording in every
      document type and in the frontmatter, beside hex colours and prose numbers that
      pass.
    - Binding fixtures over a `MemoryTree` source: a symbol, a re-exported symbol, a test,
      an example target and a documented library item resolve; a missing path, an
      ambiguous path, a macro-generated symbol, a missing example target and an item of
      the wrong role fail with the capability, the list and the binding named.
    - Roadmap fixtures: the group and slug order, the gaps of an `implementing`
      capability, and this repository with every capability once and each capability
      it has built either `delivered`, or `implementing` with the open change record
      named after it, with no gap in either case. The rule refuses a built capability
      that is `implementing` with no record of its name or with only a record of
      another name, one with a gap, one in another state and one that is absent, and
      accepts it `delivered` with no record or reopened under its own record.
    - The dev-dependency API: `Gate::workspace(...).assert_clean()` passes on a clean
      fixture repository on disk, panics with every finding on a broken one, and is an
      error for a directory without capability documents.
    - The documentation example of `Gate` writes a repository of one package and one
      delivered capability to a scratch directory and runs the gate over it with an
      empty tracked set: the bindings resolve, and the one finding is `index-missing`.
    - Record fixtures in their directories: each record type loads into the model; a
      record in the directory of another type, under another file name or below its
      directory is refused; a file beside the coverage record is
      `singleton-other-file`; a repository without record directories reports nothing
      new.
    - Reference fixtures for the records and the claims, each beside a neighbour that
      passes: a capability in `for` with no document, a subject with no capability, a
      `scope` crate that is no package, an assessment named otherwise than its
      subject, a claim on unknown evidence with its line, and a claim on evidence for
      another capability; a claim inside a PROPOSED block is
      not read. An input of each kind that resolves is an edge, a re-exported symbol
      leads to its definition, and an input of each kind that does not resolve is no
      edge and no finding.
    - Digest fixtures: the SHA-256 test vectors (the empty message, `abc`, the 448-bit
      message and a million `a`), each encoding pinned against an independent SHA-256,
      two runs equal, CRLF and LF equal, a regenerated block that leaves a section
      digest, and each definition of a symbol counted once.
    - Writer fixtures: a written record of each type reloads with no finding as the
      same value; `create` never replaces a file; `replace` needs a record file that
      exists, renames a new file over it, and in a directory that refuses a new file
      fails with the target unchanged and no temporary file left; a record that would
      not load clean, a bad slug and half an SPDX header are refused with nothing
      written.
    - Link fixtures for the writer: a directory link inside the root at `work`, at
      `work/evidence`, at `work/assessments` and at `work/coverage`, with the record's
      own file behind it, is refused by `create` and by `replace`, naming the link, with
      the tree byte-identical, and the same writes through the real directory go
      through; with `work/coverage` a link to `docs` and `docs/default.md` there,
      `replace` of the coverage record is refused and the document keeps its text.
    - Cost fixtures: a record at the size bound with the most measures loads, and a
      hundred thousand claims load with one finding for each citation of a record that
      does not exist. The work is counted, not timed: a section of many fenced blocks
      is read once, each character and each blanked range stepped over once, and the
      count at three sizes grows by no more than its second size did; the claims of
      many capabilities are judged against sets built once, each record entered
      once, and each slug of each claim is asked of the sets twice, a number the
      lookups of sets that count their own lookups pin exactly. A count sees the steps that are counted: a loop added
      elsewhere is not seen by it. The tallies are cfg(test)-only counters whose own
      tests pin that a count adds what it is given, that each kind has its own
      counter, that the tallies reset between measures, and that a ceiling panics at
      the step that passes it and is cleared when a measure ends, even by a panic.

    /// The checks of a repository on disk, for a test of the repository itself.
    ///
    /// A repository of one package and one delivered capability, written to a
    /// scratch directory, loads with its bindings resolved; its one finding is the
    /// capability catalogue that no sync has created yet:
    ///
    /// ```rust
    /// use std::fs;
    ///
    /// use raf_workplan::Gate;
    ///
    /// let dir = std::env::temp_dir().join(format!("raf-workplan-gate-{}", std::process::id()));
    /// let sections: String = ["Purpose", "Contract", "Usage", "Examples", "Constraints", "Explanation", "Verification"]
    ///     .iter()
    ///     .map(|name| format!("## {name}\n\nThe {name} of the demo.\n\n"))
    ///     .collect();
    /// let capability = format!(
    ///     "---\ntype: Capability\nid: cap:demo\ntitle: \"Demo\"\ndescription: \"One line.\"\n\
    ///      state: delivered\n\
    ///      bindings:\n  code: [demo::run]\n  tests: [demo::tests::it_runs]\n  examples: []\n\
    ///      depends: []\n---\n\n# Demo\n\n{sections}"
    /// );
    /// let files = [
    ///     ("Cargo.toml", "[package]\nname = \"demo\"\nversion = \"0.1.0\"\n".to_string()),
    ///     ("src/lib.rs", "pub fn run() {}\n\n#[cfg(test)]\nmod tests {\n    #[test]\n    fn it_runs() {\n        super::run();\n    }\n}\n".to_string()),
    ///     ("docs/capabilities/demo.md", capability),
    ///     ("work/coverage/default.md", "---\ntype: Coverage\nid: coverage:default\nscope: []\nexclusions: []\n---\n".to_string()),
    /// ];
    /// for (path, text) in files {
    ///     let file = dir.join(path);
    ///     fs::create_dir_all(file.parent().expect("a file has a directory"))?;
    ///     fs::write(file, text)?;
    /// }
    ///
    /// let findings = Gate::workspace(&dir).tracked_paths([]).try_check()?;
    /// fs::remove_dir_all(&dir)?;
    /// let kinds: Vec<&str> = findings.iter().map(|finding| finding.kind).collect();
    /// assert_eq!(kinds, ["index-missing"]);
    /// assert_eq!(findings[0].file, "docs/capabilities/index.md");
    /// # Ok::<(), Box<dyn std::error::Error>>(())
    /// ```
    ///
    /// [`Gate::workspace`] names the directory. The gate reads `docs/capabilities`,
    /// `docs/architecture` and `work/changes` below it, and the records of
    /// `work/evidence`, `work/assessments` and `work/coverage`, loads the source
    /// [`Workspace`] with the roots `["."]` (change them with
    /// [`Gate::source_roots`]), and runs [`Workplan::check`].
    ///
    /// A repository with no `docs/capabilities` directory, or with a directory
    /// that holds no capability document, is an error and not a clean verdict: a
    /// gate pointed at the wrong directory must not pass. A missing `work/changes`
    /// is the empty set of changes.
    ///
    /// Links are judged against the tracked paths of the checkout. They are taken
    /// from `git ls-files` when the directory is inside a git work tree. If `git`
    /// cannot run, fails for another reason, is told by `GIT_DIR` or
    /// `GIT_WORK_TREE` about a repository it cannot use, or cannot list the index,
    /// the gate is an error ([`GateError::Tracked`]).
    ///
    /// There is one fallback, taken only when `git` itself answers that the
    /// directory is not inside a git work tree, as for a copy of the files without
    /// `.git` such as the snapshot of a commit hook. Then every file under the
    /// directory stands for a tracked path (see [`LinkContext::of_tree`]). That
    /// weakens the rule that a link to an untracked file is broken, since a file
    /// that is on disk and untracked then passes. [`Gate::tracked_paths`] replaces
    /// both with a list the caller owns. A path that is a symlink on disk is a
    /// tracked symlink, and a link to it is `link-symlink`.
    ///
    /// [`Gate::strict`] and [`Gate::strictness`] set the least strictness the
    /// gate judges with, its floor: the repository is judged under the stronger of
    /// the floor and the `strictness` of its coverage record
    /// ([`Workplan::strictness`]), and every [`Workplan`] that [`Opened`] gives has
    /// that floor.
    #[derive(Debug, Clone)]
    pub struct Gate {
        dir: PathBuf,
        roots: Vec<String>,
        tracked: Option<Vec<RelPath>>,
        programs: Option<Programs>,
        floor: Strictness,
    }

    /// A gate over the checkout in `dir`: the directory that holds `docs/`
        /// and `work/`, usually the manifest directory of the package. A
        /// repository runs it from a test of its own; the block is that test file,
        /// so it is compiled and not run:

        /// }
        /// ```
        #[must_use]
        pub fn workspace(dir: impl AsRef<Path>) -> Self {
            Self {
                dir: dir.as_ref().to_path_buf(),
                roots: vec![".".to_string()],
                tracked: None,
                programs: None,
                floor: Strictness::Default,
            }
        }

symbol raf_workplan::Workplan::check (named in the section)
  in crates/raf-workplan/src/model.rs
    /// Every finding of every check over the loaded documents: the findings
        /// of the load, then those of the generated blocks (`index-missing`,
        /// `generated-stale`, `generated-unknown-kind`, `generated-misplaced` and
        /// `mixed-line-endings`), which are judged by the renderers that
        /// [`Workplan::sync`] writes with, so a clean `check` is a `sync` with
        /// nothing to write.
        ///
        /// Under [`Strictness::Strict`] ([`Workplan::strictness`]) the findings of
        /// the rules of strict mode ([`crate::strict`]) follow every other
        /// finding. Under [`Strictness::Default`] no rule of strict mode is
        /// judged.
        #[must_use]
        pub fn check(&self) -> Vec<Finding> {
            let mut findings = self.findings.clone();
            findings.extend(generated::analyze(self).into_findings());
            if self.strictness() == Strictness::Strict {
                findings.extend(strict::check(self));
            }
            findings
        }

symbol raf_workplan::plain::check (named in the section)
  in crates/raf-workplan/src/plain.rs
    /// Check one tracked Markdown file that is not a workplan document.
    ///
    /// * Every file: a link or image split across lines, a link that does not
    ///   resolve (`link-broken`, `anchor-broken`, `link-outside`, `link-symlink`),
    ///   and text that does not read as Markdown (an unclosed frontmatter block, a
    ///   malformed or unclosed generated marker, a malformed PROPOSED marker, a
    ///   malformed or unattached claim or tested-by marker, an unknown `raf:`
    ///   comment).
    /// * Files at the top level and under `docs/` and `work/`: an issue or pull
    ///   request reference (`issue-reference`), an unfinished-work token
    ///   (`okf-placeholder`), a PROPOSED block, which belongs in a capability
    ///   document (`okf-proposed-outside-capability`), whose change must also
    ///   exist (`proposed-missing-change`), and a claim marker or a tested-by
    ///   marker, which belongs in a capability document too
    ///   (`okf-claim-outside-capability`, `okf-tested-by-outside-capability`).
    ///
    /// `path` is the repository-relative path with `/` separators, `text` is the
    /// file, and `context` supplies the tracked paths.
    ///
    /// ```rust
    /// use std::collections::BTreeSet;
    /// use raf_source::{MemoryTree, RelPath};
    /// use raf_workplan::{LinkContext, plain};
    ///
    /// let tree = MemoryTree::from([("NOTES.md", "")]);
    /// let context = LinkContext::new(&tree, BTreeSet::from([RelPath::new("NOTES.md")?]));
    /// let findings = plain::check("NOTES.md", "# Notes\n\n[gone](missing.md)\n", &context);
    /// assert_eq!(findings[0].kind, "link-broken");
    /// assert!(plain::check("NOTES.md", "# Notes\n\nFine.\n", &context).is_empty());
    /// # Ok::<(), Box<dyn std::error::Error>>(())
    /// ```
    #[must_use]
    pub fn check(path: &str, text: &str, context: &LinkContext<'_>) -> Vec<Finding> {
        let mut out = Vec::new();
        if is_scanned(path) {
            refs::scan(path, text, &mut out);
        }
        rules(path, text, context, &mut out);
        out
    }
symbol raf_workplan::record::create (named in the section)
  in crates/raf-workplan/src/record.rs
    /// Write the new record `record` below `root`, the directory that holds
    /// `work/`, and return its path.
    ///
    /// The text is [`Record::text`]. The file is created exclusively: a file or a
    /// link already at the path is [`RecordError::Exists`] and is not touched.
    /// The directory of the record type is created when it is missing; it and
    /// `work` must each be a directory or not exist, and a symbolic link, inside
    /// the root or out of it, or a file there is refused, so the record is written
    /// in the record directory of `root` only. A failure after the file was
    /// created removes it again.
    ///
    /// # Errors
    ///
    /// Every error of [`Record::text`], before anything is written;
    /// [`RecordError::Exists`]; and [`RecordError::Write`] when the file or its
    /// directory cannot be created, in which case no file is left.
    pub fn create(
        root: &Path,
        record: &Record,
        options: &RecordOptions,
    ) -> Result<RelPath, RecordError> {
        let text = record.text(options)?;
        let path = record.path()?;
        files::create_new(root, record.doc_type().directory(), &path, &text).map_err(|error| {
            match error {
                CreateError::Exists => RecordError::Exists { path: path.clone() },
                CreateError::Write { path, source } => RecordError::Write { path, source },
            }
        })?;
        Ok(path)
    }
symbol raf_workplan::record::replace (named in the section)
  in crates/raf-workplan/src/record.rs
    /// Put the text of `record` in place of the record file that exists at its
    /// path below `root`, and return the path.
    ///
    /// `work` and the directory of the record type must each be a directory, and
    /// a symbolic link there, inside the root or out of it, or a file is refused,
    /// as [`create`] refuses it, so a replacement never lands on another file
    /// through a link. The target must then be a regular file; a missing file, a
    /// directory and a symbolic link are refused.
    /// The new text is written to a temporary file beside the target, created
    /// exclusively, and renamed over it, so the target holds either its old text
    /// or the new one, never part of either. The file keeps its permissions.
    ///
    /// # Errors
    ///
    /// Every error of [`Record::text`], before anything is written;
    /// [`RecordError::Missing`] when no regular file is at the path;
    /// [`RecordError::Write`] naming the directory refused on the way, before
    /// anything is written; and [`RecordError::Write`] when the temporary file
    /// cannot be written or renamed, in which case the temporary file is removed
    /// and the target is unchanged.
    pub fn replace(
        root: &Path,
        record: &Record,
        options: &RecordOptions,
    ) -> Result<RelPath, RecordError> {
        let text = record.text(options)?;
        let path = record.path()?;
        let write = |source: io::Error| RecordError::Write {
            path: path.to_string(),
            source,
        };
        match files::target(root, record.doc_type().directory(), &path) {
            Ok(Target {
                kind: Some(EntryKind::File),
                ..
            }) => {}
            Ok(_) => return Err(RecordError::Missing { path }),
            Err(error) => return Err(error.into()),
        }
        let target = fs::canonicalize(root).map_err(write)?.join(path.as_str());
        let temporary = sync::stage(&target, &text).map_err(write)?;
        if let Err(error) = fs::rename(&temporary, &target) {
            // Only the temporary file this call created is removed.
            let _ = fs::remove_file(&temporary);
            return Err(write(error));
        }
        Ok(path)
    }
