section docs/capabilities/source-index.md
    Usage
    
    Load a workspace from a real directory and ask where a path is defined. The block
    needs a real tree, so it is compiled and not run:
    
    ```rust,no_run
    use raf_source::{DiskTree, Workspace};
    
    let ws = Workspace::load(&DiskTree::new(".")?, &["crates"])?;
    let resolution = ws.resolve("raf_okf::Document")?;
    for site in &resolution.sites {
        let item = ws.item(*site).expect("a site is an item of this workspace");
        println!("{} at {}:{}", item.path, item.file, item.name_line);
    }
    for target in ws.targets().filter(|t| !t.shipping) {
        println!("{} is a non-shipping target", target.name);
    }
    # Ok::<(), Box<dyn std::error::Error>>(())
    ```
    
    A line that starts with `# ` is hidden by rustdoc and is there so that the block
    compiles.
    
    List the public surface of a library or a binary with `ws.exported_items(id)`, for
    an `id` of `ws.target_ids()`. Each `ExportedItem` of `items` maps its exported
    `path` back to its definition through `ws.item(export.item)`, and each `Reexport`
    of `reexports` gives what it re-exports as `written`. `exported_items_with(id,
    &options)`, with `options.include_hidden` set on `ExportOptions::default()`, lists
    what `#[doc(hidden)]` hides as well. The block lists the surface of each library of
    a real tree, so it is compiled and not run:
    
    ```rust,no_run
    use raf_source::{DiskTree, TargetKind, Workspace};
    
    let ws = Workspace::load(&DiskTree::new(".")?, &["crates"])?;
    for id in ws.target_ids() {
        let target = ws.target(id).expect("an id of this workspace");
        if target.kind != TargetKind::Lib {
            continue;
        }
        let exports = ws.exported_items(id)?;
        for export in &exports.items {
            let item = ws.item(export.item).expect("an item of this workspace");
            println!("{} is {} in {}", export.path, item.path, export.file);
        }
        for reexport in &exports.reexports {
            println!("{} re-exports {}", reexport.path, reexport.written);
        }
    }
    # Ok::<(), Box<dyn std::error::Error>>(())
    ```
    
    Resolve a path as a `use` written in a module would with `ws.resolve_from(module, path)`, or in one name space with `ws.resolve_from_in(module, path, namespace)`, for a `module` such as `"demo::inner"`. The reading module is the viewer: `ws.resolve_from("demo::b", "crate::a::go")` finds `demo::a::go` when `go` is `pub` in `a`, and a private item of `a` is `ResolveError::NotFound` for `b`. A module that is not in the index is `ResolveError::UnknownModule`.

    /// A budget of a load.
    ///
    /// The first six bound shapes that make `syn` recurse and are enforced by the
    /// pre-scan before a file is parsed. The others bound the module walk,
    /// discovery, the tokens of one file, the bytes one load reads and keeps and
    /// the steps of glob table work one load makes. The limits live in one table,
    /// [`Budget::limit`], which the code and the documentation share. The token
    /// budget, the four byte budgets and the work budget are defaults that
    /// [`LoadOptions`](crate::LoadOptions) can change.
    #[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
    #[non_exhaustive]
    pub enum Budget {
        /// Open delimiters (`(`, `[`, `{`) nested at one point.
        Delimiters,
        /// Open `<` brackets nested in one delimiter level.
        Angles,
        /// Consecutive prefix operators (`!`, `-`, `*`, `&`, `&&`).
        PrefixOperators,
        /// Back-to-back closure heads (`||` or `|...|` with no body between).
        ClosureBars,
        /// Chained `else if` links.
        ElseIf,
        /// The nesting that the parser builds by recursion, counted additively
        /// over every open delimiter level: the counted tokens of each open level
        /// since its count last returned to zero, plus one for each open
        /// delimiter. Parsing a file, reading its facts and dropping its syntax
        /// tree take at most [`RECURSION_UNIT_BYTES`] of the parse stack for each
        /// unit, so the limit keeps them within half of
        /// [`PARSE_STACK_BYTES`](crate::PARSE_STACK_BYTES).
        Recursion,
        /// Modules nested along one path from a target root, files and inline
        /// modules together. Unlike the others it is counted by the module walk
        /// and not by the pre-scan.
        ModuleDepth,
        /// Module paths recorded in one load: every arrival of the module walk at
        /// a file, counted over all targets. Counted by the module walk.
        ModulePaths,
        /// Directories nested below a root, counted by package discovery and by
        /// the expansion of `workspace.members` patterns.
        DirectoryDepth,
        /// Tokens of one file, counted by the pre-scan. A doc comment counts as
        /// the tokens of the attribute it stands for. Parsing one file holds at
        /// most [`PARSE_BYTES_PER_TOKEN`] bytes per token at its peak, so the limit
        /// bounds that peak.
        FileTokens,
        /// Bytes read in one load: every source file and manifest.
        TotalBytes,
        /// Bytes the symbol index keeps: every item record and the index entries
        /// built for each module path, and each shared string once.
        ItemBytes,
        /// Bytes of the facts read from the files of one load, counted on the
        /// parse thread as they are built.
        FactBytes,
        /// Bytes of the glob scope tables held at once: what each module exports
        /// to glob imports, kept once for every class of importers that see the
        /// same of it and shared by them, the glob imports that read each table,
        /// and the changes waiting to be passed on as the tables grow.
        GlobBytes,
        /// Steps of glob table work in one load, counted as they are made and
        /// never given back: each glob read listed and each name gathered when a
        /// view is built, each name a new reader is given, each reader a change is
        /// passed on to, each glob read read again when what a module's globs
        /// bring in under a name is read again, and each step of the search for the modules that hold an item
        /// apart from a reading module. These are the steps whose number grows
        /// faster than the bytes of the tables on some shapes of globs, so the
        /// budget bounds the work of settling them whatever their bytes.
        Work,
    }

    ///

    /// [`Budget::ItemBytes`], [`Budget::FactBytes`], [`Budget::GlobBytes`] and

    /// the limit that applied and the file.

        /// The most tokens one file may hold, counted by the pre-scan before the
        /// file is parsed. Parsing a file holds at most
        /// [`PARSE_BYTES_PER_TOKEN`](crate::PARSE_BYTES_PER_TOKEN) bytes per token
        /// at its peak, so this bounds that peak: about 3.1 GiB at the default of
        /// [`Budget::FileTokens`], and below 512 MiB at 320,000 tokens, which a
        /// caller on a host with little memory sets.
        pub max_file_tokens: usize,
        /// The most bytes one load may read, source files and manifests together.
        /// Defaults to the limit of [`Budget::TotalBytes`].
        pub max_total_bytes: usize,

        /// entries built for each module path. Defaults to the limit of
        /// [`Budget::ItemBytes`].
        pub max_item_bytes: usize,
        /// The most bytes the facts of the files of one load may hold. Defaults to
        /// the limit of [`Budget::FactBytes`].
        pub max_fact_bytes: usize,
        /// The most bytes the glob scope tables of one load may hold. Defaults to
        /// the limit of [`Budget::GlobBytes`].
        pub max_glob_bytes: usize,
        /// The most steps of glob table work one load may make, counted as they
        /// are made and never given back (see [`Budget::Work`]). Defaults to the
        /// limit of [`Budget::Work`].
        pub max_work: usize,
    }

    /// A read-only tree of UTF-8 text files below one root.
    ///
    /// The trait is object-safe and has no `Send` or `Sync` bound: loading is
    /// serial, and requiring `Tree: Sync` for a parallel load would be a breaking
    /// change to [`Workspace::load`](crate::Workspace::load). Paths are
    /// [`RelPath`] values, so no call can name a place above the root by text. A
    /// backend may still refuse a path that its contents lead out of.
    pub trait Tree {
        /// The text of the file at `path`.
        ///
        /// # Errors
        ///
        /// Returns [`TreeError::NotFound`] when nothing is there,
        /// [`TreeError::OutsideRoot`] when the path leads out of the root,
        /// [`TreeError::NotRegular`] when it is not a regular file,
        /// [`TreeError::TooLarge`] when the file holds more than `max_bytes`
        /// bytes, [`TreeError::NotUtf8`] when it is not UTF-8, and
        /// [`TreeError::SymlinkLoop`] or [`TreeError::Io`] when the operating
        /// system fails.
        fn read(&self, path: &RelPath, max_bytes: u64) -> Result<String, TreeError>;
    
        /// Open the file at `path` once, take its identity from that open, and
        /// read its text from the same open unless `seen` says the identity is
        /// one the caller already holds.
        ///
        /// Two paths that name one file, such as a path and the same path through
        /// a symlink to a directory, have equal identities, and two different
        /// files never do. Because the identity and the text come from one open,
        /// no change to the tree between two calls can pair one file's identity
        /// with another file's text.
        ///
        /// # Errors
        ///
        /// As [`Tree::read`]; a file that `seen` accepts is not read, so it is
        /// never [`TreeError::TooLarge`] or [`TreeError::NotUtf8`].
        fn read_unseen(
            &self,
            path: &RelPath,
            max_bytes: u64,
            seen: &dyn Fn(&FileId) -> bool,
        ) -> Result<Opened, TreeError>;
    
        /// The identity of the file at `path`, without reading it: the identity
        /// [`Tree::read_unseen`] gives when every identity counts as seen.
        ///
        /// # Errors
        ///
        /// As [`Tree::read`], without [`TreeError::TooLarge`] and
        /// [`TreeError::NotUtf8`].
        fn identity(&self, path: &RelPath) -> Result<FileId, TreeError> {
            match self.read_unseen(path, 0, &|_| true)? {
                Opened::Seen(id) | Opened::Read { id, .. } => Ok(id),
            }
        }
    
        /// The entries of the directory at `path`, sorted by name.
        ///
        /// A symlink is listed as [`EntryKind::Symlink`] and is never followed:
        /// listing a symlink itself is refused.
        ///
        /// # Errors
        ///
        /// Returns [`TreeError::NotFound`] when the directory is missing,
        /// [`TreeError::NotRegular`] when `path` is not a real directory,
        /// [`TreeError::OutsideRoot`] when it leads out of the root,
        /// [`TreeError::NonUtf8Name`] when an entry name is not UTF-8 (the entry
        /// is never dropped), and [`TreeError::SymlinkLoop`] or
        /// [`TreeError::Io`] when the operating system fails.
        fn list(&self, path: &RelPath) -> Result<Vec<Entry>, TreeError>;
    
        /// What is at `path`, or `None` when nothing is.
        ///
        /// A final symlink is reported as [`EntryKind::Symlink`] and not followed.
        ///
        /// # Errors
        ///
        /// Returns [`TreeError::OutsideRoot`] when the directory holding `path`
        /// leads out of the root, and [`TreeError::SymlinkLoop`] or
        /// [`TreeError::Io`] when the operating system fails. A missing entry is
        /// `Ok(None)`, not an error.
        fn entry(&self, path: &RelPath) -> Result<Option<EntryKind>, TreeError>;
    }

    /// The public surface of a library or binary target: the items another
        /// crate can name through its crate root, each under the path it is
        /// named by, and the public re-exports that name nothing the target
        /// defines.
        ///
        /// An item is exported when a chain of `pub` declarations reaches it from
        /// the crate root: `pub` modules, and `pub use` re-exports, named or glob,
        /// renamed or not, through modules of any visibility. A `pub` item of a
        /// private module is exported only through such a re-export, and a
        /// `pub(crate)`, `pub(super)`, `pub(in path)` or private item never is,
        /// nor is one that a re-export that is not `pub` carries on the way.
        /// Test code is never exported. The members of an exported type or trait
        /// are listed under its path: each member of a trait, and each `pub`
        /// member of an inherent impl of a type; the members of trait impls are
        /// not. A binary's surface is read the same way from its crate root; no
        /// other crate can name it. A re-export of another crate, of an enum
        /// variant or of a path the index cannot follow is a
        /// [`Reexport`](crate::Reexport) and not an item, also where a `pub` glob
        /// carries it from a module it reaches.
        ///
        /// # Errors
        ///
        /// Returns [`ExportError::NotLibraryOrBinary`] for a target id that names
        /// no library or binary of the workspace, [`ExportError::Resolve`] when a
        /// public name is ambiguous, goes through a cycle of imports or reads a
        /// glob whose path names nothing in the workspace, and
        /// [`ExportError::Budget`] when what the surface holds passes the
        /// item-bytes budget left after the load, and
        /// [`ExportError::CarryBudget`], naming the re-export, when the work of
        /// deciding whether the public globs carry a re-export passes it.
        pub fn exported_items_with(
            &self,
            target: TargetId,
            options: &ExportOptions,
        ) -> Result<Exports, ExportError> {
            let Some(found) = self
                .targets
                .get(target.index())
                .filter(|found| matches!(found.kind, TargetKind::Lib | TargetKind::Bin))
            else {
                return Err(ExportError::NotLibraryOrBinary(target));
            };
            let meter = Meter::new(&self.options);
            meter
                .items(self.usage.item_bytes, &found.root, None)
                .map_err(ExportError::Budget)?;
            // The modules of the target whose own file has `#![doc(hidden)]`.
            let hidden_files: BTreeSet<&str> = self
                .files
                .values()
                .filter(|file| file.facts.doc_hidden)
                .flat_map(|file| &file.reached)
                .filter(|reach| reach.target == target)
                .map(|reach| reach.module_path.as_str())
                .collect();
            Surface::new(
                &self.index,
                target,
                &found.crate_path,
                options,
                &meter,
                &hidden_files,
            )
            .list()
        }
