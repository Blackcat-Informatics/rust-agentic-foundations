## Summary

Source exposes actual load-local package, target, public library and alias
identities to code consumers. Explicit declared target contexts determine
dependency eligibility and header selection without inferring Cargo state.
Bounded queries preserve original resource failures and refuse unsupported or
ambiguous evidence.
