# Issue #48: raf-source: evaluate cfg against a declared set and resolve into dependency crates

State: OPEN   Repo: Blackcat-Informatics/rust-agentic-foundations   Forge: github
Labels: enhancement, crate:raf-source

## Body

## Context
`raf-source` does not expand macros, evaluates no `cfg` other than `test`, does not follow items of dependencies, and fails the whole load with `UnsupportedItem` for some token-shaped items; items generated by macros are never listed (`docs/capabilities/source-index.md:1696-1700,1710-1714`, `:1480,1491,1750-1753`). A census, coverage gate or reference scan that cannot see `cfg`-gated items, macro output or dependency items has a hard utility ceiling. It also drops a carried re-export of an external item such as `pub use std::rc::Rc`, which needs an external-crate name-space oracle (std prelude and dependency names).

Goals: maximal utility; greenfield (no accepted silent omissions).

## Scope
- [ ] Add a declared cfg set (target, features, `test`) as an input to the load; index results carry the set they were computed under.
- [ ] Resolve through path dependencies of the workspace, and provide an external-crate name-space oracle for the std prelude and registry dependency names.
- [ ] Make unexpanded macro invocations an explicit `Unexpanded` marker in the index instead of a silent omission.
- [ ] Replace the whole-load `UnsupportedItem` failure with per-item markers where the item cannot affect resolution, and keep a hard error where it can.
- [ ] Add the dropped external re-export and `CarryBudget` refusal shapes to the tracked divergence list with this issue as owner.

## Acceptance criteria
- [ ] Two loads of one fixture under different cfg sets list different items and each result records its cfg set.
- [ ] A fixture re-exporting an item from a path dependency resolves to the dependency's item; `pub use std::rc::Rc` resolves to an external binding instead of being dropped.
- [ ] A macro invocation producing items yields an `Unexpanded` marker visible to the census and coverage consumers.
- [ ] The rustc differential test covers the new shapes and passes.
