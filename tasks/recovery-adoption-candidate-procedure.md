# Exact self-gate candidate procedure

This is preparation, not an executed qualification receipt. Independent caller
review accepted this boundary; actual equality and execution remain required.

1. Collect actual strict completion. Preserve its staged record before updating
   its deletion. Remove its inventory entry and update the actual count.
2. Run actual adoption reconcile. Its current impact list overstates 35 unchanged
   authored sections against the real merge base. Correct declarations only
   where the section genuinely did not change; keep all original outcomes,
   listed capabilities, full 113 accepted judgments and zero-debt acceptance.
   Do not pad prose, suppress untouched findings or change the effect flag.
3. Set genuinely finished capabilities and inventory to delivered. Keep all
   eight designed Census capabilities and their eight real records. Update the
   root inventory shape counts. Sync the live tree with adoption still present.
4. Stage every intended final source/record except stage adoption's deletion
   without deleting its live physical file. The live Lifecycle must load and
   remove that file itself.
5. Create an empty detached validation worktree at canonical main's
   .worktrees/queue-adoption-final using no-checkout. Populate its index and
   files from the intended final original index tree; it has its own matching
   tracked-path oracle. Do not place this Git-dependent candidate under .stage
   or redirect ambient GIT_DIR/GIT_WORK_TREE.
6. Run ordinary production docs sync rooted at the candidate. Inspect its exact
   removal-related generated edits. Stage those in the candidate and read its
   final tree into the original index without modifying live pre-completion
   generated files or the physical adoption record. Verify the only intended
   live/index difference is the pending lifecycle publication.
7. Freeze both indexes and candidate. Run real live adoption completion with
   RAF_GATE_ROOT selecting the candidate. This redirects only explicit
   repository read-root callers. The actual Lifecycle retains its source/history
   root, ordinary static checks, real bound execution, reopen/recheck and final
   generated writes/record removal.
8. Collect terminal result. Require record removal, both live/candidate working
   files matching their indexes, equal indexed tree objects and no extra
   untracked product files. Exact final tree equality is required acceptance,
   not a routine identity receipt. Any mismatch invalidates candidate evidence.
9. Unset RAF_GATE_ROOT. Run mandatory make check against the live final tree,
   normal signed commit/hooks, actual CI/reviews and ghprsq landing/closure/
   archive/cleanup. Candidate qualification alone never proves these passed.

The ordinary staged-index read seam already serves the root gate binaries.
The runnable repository example now shares that exact selector. Its default
success and explicit absent-root refusal were executed; genuine candidate
success remains unrun. No policy exemption or filtered failure is authorized.
