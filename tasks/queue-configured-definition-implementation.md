## Production boundary

CfgAtom, DeclaredCfg::complete and DeclaredConfiguration::new/with_host supply
explicit complete target/host cfg, complete already-unified features, and one
exact library or build-script target. LockedManifest::with_configuration admits
them against actual declarations. If any package is configured, every admitted
package must be configured. LockedBinding::configuration retains target/host
CfgSelection, features, activated optional aliases and exact target selection.

Workspace::resolve_active_from_package_id_in uses the existing resolver and
actual reading PackageId, refuses structural-only context and missing/inactive
names, and checks every returned site's admitted context. Module lookup reuses
main's full target-prefix match with PackageId filtering, needed by the actual
build-script caller rather than a parallel resolver.

The retained manifest graph validates feature references and implication closure,
implicit aliases and dep: suppression, weak/nonweak forwarding, effective defaults
and inherited requirements at actual requested destinations. Requested inactive
edges or missing evidence refuse. Normal/build roles select declared target/host
contexts; unsupported Cargo dependency selectors refuse.

These inputs are caller declarations, not observed Cargo invocation evidence.
The caller owns complete package-specific custom flags, including build-script
results. Requested destinations agree on the compilation triple; custom flags
may differ. No built-in flags are inferred and Cargo's feature resolver is not run.

Filtering runs on the existing bounded parse worker before facts and walking.
It selects modeled item/module/import and trait/impl/foreign associated headers,
including cfg_attr and selected paths. It does not transform function bodies,
fields, enum variants, source bytes or Census fingerprints. Macro expansion,
type inference and Census provider policy remain separate. Incompatible package
contexts sharing one physical file refuse. Syntax and feature work spend the
original combined grant, not renewed worker allowances. Caller-thread span
storage is not used.

Native PurRDF Memory, WorkList, fallible sort and sorted range lookup are used.
Native main was inspected: no public Rust cfg/feature grammar or Rust identifier
XID lexer supplies this boundary. Existing syn supplies language-specific parsing;
RAF owns Cargo/Source policy. No new dependency or generic utility was added.
