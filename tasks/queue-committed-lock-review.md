## Concrete findings

- `tree/git.rs::parse_record` still decodes the decimal blob size with `size.parse()` after its ASCII-digit check. This retains a supplied generic numeric parser rather than the native integer API. Current PurRDF main exposes `purrdf_xsd::numeric::parse_integer_typed` and exact unsigned conversion; Source already uses that family in its test/example helper. Reuse the native operation with the exact existing unsigned/usize overflow grammar and proper original-grant treatment, rather than adding another decimal algorithm. The production dependency/resource implications must remain explicit; XSD is currently only a dev dependency. This is a native-preference defect, not an observed wrong-size result.
- `workspace/locked.rs::install_edges` checks duplicate bound rows through `rows.windows(2).any(...)` without a Work charge for that linear traversal. The preceding sort's comparisons are charged, but do not account for this separate scan. Charge the actual scan under the original meter; preserve the existing ceiling and typed first refusal. No fitted threshold or extra measurement is requested.

Exact native reuse seam: selected pin `5db00aaae9f3abb521e98b8f79dbc1bebe5e3e43`, `crates/xsd/src/numeric.rs:801`, exports `parse_integer_typed(lexical: &str, datatype: XsdDatatype) -> Result<crate::exact::Integer, XsdError>`. The existing same-worktree adapter is `examples/registry_scan/driver.rs::unsigned` (around line 185): native NonNegativeInteger parse, `into_bigint().unsigned_abs_u128()`, then checked destination conversion. Git must preserve its stricter nonempty ASCII-digit guard: do not copy the example's optional-plus acceptance. Trimming leading zeroes preserves the current decimal grammar while bounding native significant digits; overflow must still refuse at usize. Current PurRDF main was also inspected and supplies this same operation. Exact native/resource integration belongs to the source owner's repair, not an untested patch in this review.

The existing XSD dependency moved from dev to production without a version change.
