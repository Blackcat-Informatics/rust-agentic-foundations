Workplan now applies one complete policy by default. Incomplete capability text,
unowned public code or tests, unsupported claims, missing runnable examples and
unexplained source lines are findings for ordinary production callers. The debt
record ratchets down and refuses growth or stale identities.

RAF adopts that policy across all eight first-party packages with zero debt,
real claim-level bindings and examples, and 113 current accepted assessments.
Command results use the shared native RDF graph for Turtle and N-Triples alongside
the human-readable output. Compatible scalar, text, digest, allocation and
fixture operations use the pinned PurRDF libraries.

Bound verification records a compiler-proved platform exclusion separately from
a passing test. It retains the exclusion receipt and refuses to publish it as
passing execution evidence. Rustdoc continues through its own listing and run
proof. Shared fixture implementations have one selectable assertion owner.

Validation is pending final adoption completion, exact candidate equality,
default-root `make check`, normal commit hooks and current hosted checks. Focused
tests, warnings-denied Clippy, real strict completion and independent review
have passed; these do not replace final qualification.
