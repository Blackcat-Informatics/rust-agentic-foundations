## Identity/resource contracts to preserve

Both formats hash exactly one normalized native-term-ordered Turtle body, including VERSION and LF but excluding BASE. Turtle inserts BASE; N-Triples expands only exact owned root/fragments using that same digest. Native parse_dataset_with and flat_default_graph_quads supply parsing/native terms; reject named graphs before flattening. Native TermValue ordering, term traversal/output, IRI validation, standard vocabularies, BLAKE3 and hex remain the actual paths. Retain empty-row, role, language-datatype, nested-term, dangling-reference, digest, CRLF/final-LF and own-root-boundary refusals.

The public kernel currently has no RAF input-byte/allocation/stack budget and uses native default parsing and Resident output. Its semantic depth-one restriction is not a parser admission bound. State that limitation honestly, retaining consumers' existing external admission rules; do not reinterpret the earlier closed hand parser as proof of a bound on native allocation. A selected packet must be qualified against actual main callers, not just copied fixture results.
