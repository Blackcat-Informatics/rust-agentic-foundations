# CLI section judgments

The seven accepted individual judgments below use current production contexts in
`raw/assessment-cli-effects-current/`, captured after publication-boundary prose,
the three matching internal comments and generated blocks were repaired. Earlier
CLI contexts in `assessment-census-cli-current` are historical inputs and must
not be accepted for this tree. Publication and currency have separate receipts.

- Purpose: the thin executable projects the actual library's domain judgments;
  it does not maintain a second checker or hidden lightweight policy. Actual
  gate-equivalence fixtures assert matching ordered findings and exit classes.
- Contract: both invocation shapes, argument placement, bounded manifest discovery
  and explicit-root behavior match real parser/caller fixtures. Root discovery
  makes no Cargo/compiler call; repository opening may separately list Git paths.
  All command families retain their typed values and explicit exits. Actual
  replacement fixtures cover authored SPDX and its removal, one-file changes and
  unchanged neighbors. Quiet has separate actual handler owners. Native RDF
  command projections retain field/ordinal/provenance fidelity, complete registry
  equality and canonical graph identity; JSON and removed-policy options refuse
  before root loading. Native scalar helpers support real caller assertions.
  Diagnostic writes and flushes, including help/version output, cannot falsely
  return clean status. Explicit debt publication is an API/command operation,
  never automatic adoption by ordinary check/test flows.
- Usage: the documented check, status, change, history, evidence, assessment,
  coverage and explicit debt forms match current CLI arguments. Format selection
  is text/Turtle/N-Triples only. Coverage package selection is query filtering,
  not a default-policy escape. The benchmark-like evidence command is an
  illustrative caller-selected program, not a verification run executed here.
- Examples: the narrative output remains illustrative; actual command fixtures
  separately pin domain values, finding locations and statuses. No example
  asserts that a designed Census command or preferred-provider enforcement has
  already been implemented.
- Constraints: tool-owned publication is now explicitly separated from effects
  of trusted executable inputs. Real library reconciliation executes an example
  and build script that write an owned workspace marker, beside an ordinary
  unchanged neighbor. Real partial-clone history fetches a missing object while
  preserving working/index bytes. These substantive producer proofs compose with
  inspected actual CLI-to-library routing; benign CLI snapshots are not called a
  sandbox proof. Fixed argv, tracked-list-only verify, resolved document arguments,
  terminal escaping and missing-record/slug refusals retain their actual owners.
  The tool's publication and refusal promises remain judged, not moved away.
- Explanation: the library/gate and CLI distinction and outcome/finding/tool-error
  exit separation explain actual source architecture. The roadmap is derived
  from current documents; no independent mutable status store is promised.
- Verification: actual command, renderer, record, root, sync, verify and RDF
  owner receipts remain scoped in the current runtime/recheck, native-scalar,
  CLI claim/sync and side-effect-boundary reviews. The repaired publication prose
  and comments changed no runtime branch; production docs sync compiles and runs
  the real caller. Registry controlled-child-stderr pins are distinguished from
  ordinary unmodified compiler-output callers. Native text caller receipt 85344
  reran CLI assess/history/process families; 51631 passed warnings-denied
  all-target caller Clippy. No final combined full gate, unrelated source
  acceptance or execution on untested platforms is inferred.
