    Contract
    
    The binary is `cargo-workplan`, a thin wrapper over `raf-workplan`, parsed with clap
    derive. It runs from any directory inside the workspace and finds the root from
    ancestor manifests. Cargo runs it for `cargo workplan <command>`, passing the argument
    vector `cargo-workplan workplan <command>`, and it runs directly as
    `cargo-workplan <command>`; both forms take the same arguments and give the same
    result.
    
    **Root discovery.** When `--root` is absent, `raf-workplan` opens a bounded
    `DiskTree` from the filesystem root and calls `raf_source::discover_root` from
    the canonical current directory. Discovery reads ancestor `Cargo.toml` files
    without starting a process, reading Cargo configuration, resolving registry
    dependencies or changing the lockfile. A manifest is bounded by the source
    reader's default file-size limit.
    
    The nearest explicit `[workspace]` is selected. A package must belong to its
    member set, including transitive in-workspace path dependencies; an unlisted
    package is a finding with instructions to list it, exclude it, or add its own
    `[workspace]`. A standalone package and an excluded package resolve to their
    own directories. A nested workspace resolves to the nested root. An explicit
    `package.workspace` must name a workspace reachable inside the tree whose
    membership includes the package; missing, conflicting or malformed declarations
    fail hard. A directory with no ancestor package or workspace is an error.
    `--root` directly selects a directory and bypasses discovery.

    `status` groups capabilities by state, lists for each `implementing` capability the
    bindings that are missing or do not resolve, as gaps, and names the open changes. `docs preview` applies the
    PROPOSED blocks of the named change to a copy of the text, removes the markers,
    and prints the result; it never writes a file. `docs sync` takes
    `--copyright <text>` and `--licence <id>`, the two SPDX lines of a new capability
    index; they are read only when `docs/capabilities/index.md` must be created, and then
    a missing one is an error that names it. `change new` takes `--capability` once or
    more, `--affects cap:<name>#<section>` any number of times, and `--copyright` with
    `--licence`, as [reconcile](./workplan-reconcile.md) states, and prints the PROPOSED
    block to place and the state each listed capability needs. `change complete` prints
    `completed: removed <path>` and a `rewrote <path>` line for each file whose generated
    blocks the removal rewrote, or `refused:` with the count of each kind of failure and a
    line for each failure that no other line repeats.
    
    **Values of the record commands.** Each value is checked when the arguments are
    parsed. A history id is `cap:`,
    `change:`, `arch:`, `evidence:` or `assessment:` and a slug; an evidence id is
    `evidence:<slug>` or the slug; a section is `cap:<slug>#<section>` with one of the
    seven sections; `--since` is a day from 1970-01-01 to 2099-12-31; `--limit` is
    `name=number` with no exponent; `--revision` is 40 or 64 lowercase hexadecimal
    digits; `--crate` is a package name, given as cargo names it (`raf-okf`) or as its
    crate is named (`raf_okf`). A value that is not one, or that starts with `-`, is a
    usage error, exit 2, before any process starts.
    
    **The command of `evidence record`.** Every word after the first `--` of the
    command line is the command: a `-q`, a `--format` or a second `--` after it is a
    word of the command and not an option of the tool. `raf-workplan` builds the
    command from the command line of the process
    (`TrustedArgv::from_command_line(std::env::args_os())`) and never from the text of
    a document or record; the parser reads the same words as the trailing arguments,
    and a run whose two readings differ is refused before anything starts. An option
    whose value would be `--` is a usage error, so no option can move the start of the
    command, and a process whose program name is `--` is refused with exit 2 before
    anything starts. A command and `--from-binding` exclude each other, a bare `--`
    beside `--from-binding` included, and one of them is required. `--by` is required,
    since a record states who made it. A replacement, by `--update` or by a verdict on a section that has an
    assessment, holds only what its own run gives, its SPDX lines included: without
    `--copyright` and `--licence` the new record has none.
    
    **Exit codes.** 0 means success: no violations, an empty obligation list, a completed
    change, or every binding passing. 1 means findings: violations, obligations, a refused
    completion or a failing binding. 2 means the tool could not run: a usage error, an
    unreadable file, a missing `git`, a slug that does not exist. A Git older than 2.30 is
    exit 2 for `change reconcile` and `change complete`, a change record that does not
    load (an `outcome` that is not one of the three values, for instance) is exit 2, and
    `status` exits 0 whatever gaps it lists, since a gap is not a violation.
    
    **Exit codes of the record commands.** `history`, `evidence claims`,
    `evidence for` and `assess` exit 0 when they have an answer: a recorded `rejected`
    verdict, and a stale or rejected assessment that `--list` shows, are results and
    not findings, and `change reconcile` lists what they owe. `evidence record` exits 0
    when it writes a `pass` record and 1 when it writes a `fail` record, a result the
    repository owes; it exits 2 when it writes none: a printed value that is not a
    number, a name printed twice, a limit the command never printed, output past its
    bound, a command that cannot start, or a request refused before the run.
    `coverage code` and `coverage tests` exit 1 when the report names a gap, or in the
    code direction a surface that cannot be listed, and 0 otherwise. `coverage claims`
    exits 1 when a claim of a delivered capability has no test and 0 when every claim
    has one, under either strictness. `coverage lines` exits 1 when it prints an orphan
    line or could not count the lines and 0 otherwise, and `coverage --reverse` is the
    same command, which prints the same bytes. Each exits 2 when
    the tool cannot run: an id or a capability that no loaded document has, a shallow
    clone, a Git older than 2.30 or a bound file whose lines are not committed for
    `history`, a package that `--crate` does not name, a capability that `--capability`
    of `coverage claims` names and no loaded document has. `evidence claims` also exits 2,
    naming each capability document that exists and does not load, with nothing on
    standard output, because a claim in such a document may name the record; a change
    record or an evidence record that does not load holds no claim and leaves its
    answer and exit 0 as they are. A section given to `assess --list` must be one that
    `assess --context` answers for, so a named section that can no longer be assessed
    (its capability gone or not loading, or a bound symbol it reads no longer
    resolving, for instance) is exit 2, while a bare `--list` still shows an assessment
    of it.
    
    **Options.** `--root <dir>` sets the workspace root, `--format text|json` selects the
    output, `-q` suppresses everything but findings, and `--strict` judges with
    `Gate::workspace(root).strict()`: it raises the strictness of `check`,
    `change reconcile` and `change complete` to [strict mode](./workplan-strict.md), and a
    coverage record that says `strictness: strict` gives the same judgement without it.
    `status`, `docs`, `history`, `evidence`, `assess`, `verify` and the coverage reports
    print the same with and without `--strict`, except that `coverage lines` shows its
    ceilings as enforced under it. Findings are printed to stdout in
    a stable order and diagnostics to stderr. Each option is accepted before or after the
    command. Under `-q` a command whose output holds no finding (`status`, `docs sync`,
    `docs preview`, `change new`, `change impact`, a completion, the passing bindings of
    `verify`) prints nothing on stdout and leaves out its notes on stderr, while the
    obligations, a refusal and the failing bindings are findings and stay; a failure of
    the tool is always written to stderr, and the exit code does not change.
    
    **JSON.** `--format json` prints one JSON array for the run on stdout: one object for
    each record the text form prints, in the same order, and `[]` when there is none.
    Every object begins with `kind`, the discriminator, followed by the fields of its kind,
    always present, with `null` for a field that does not apply. A finding of `check` has
    the kind of its rule, from `Finding::KINDS`, and the fields `path`, `section`, `line`,
    `key`, `message` and `fix`, a finding of strict mode as any other. The other kinds
    are `rewrote`, `state`, `open-changes`, `preview`, `new-change`, `impact`,
    `obligation`, `refused`, `refusal` (one for each failure of a refused completion,
    with its condition), `completed` and `binding`, and none of them equals the kind of
    a rule. Their fields are documented in the crate documentation of `cargo-workplan`.
    A run that could not run prints nothing on stdout, so stdout is either one complete
    array or empty.
    
    **Output of the record commands.** `history` and `coverage` print the table and
    the JSON array that `raf-workplan` renders, as one report: under `-q` a history
    prints nothing (`[]` in JSON), and a coverage report is printed whole when it names
    a gap and not at all when it names none, as a claims report is printed whole when a
    claim names no test and not at all when every claim names one. Under `-q` a `pass` record, a recorded
    verdict, a context, a list and the two evidence views print nothing, and a `fail`
    record stays. The JSON kinds are `history-entry`, `history-removed`,
    `evidence-recorded`, `evidence-claim`, `evidence-for`, `assess-context`,
    `assessment-recorded`, `assessment`, `coverage-gap`, `coverage-excluded`,
    `coverage-error`, `coverage-claim`, `lines-crate`, `lines-module`, `lines-orphan`,
    `lines-excepted` and `lines-error`; none equals the kind of a rule, and their
    members, in a fixed order, are documented in the crate documentation of
    `cargo-workplan`. A lines report is printed whole under `-q` when it holds an orphan
    line and not at all when it holds none.
    
    **Strict mode.** The last command of [strict mode](./workplan-strict.md) joins the
    table: `debt --write [--copyright <text> --licence <id>]` writes the strict debt
    record `work/debt/default.md` through `Gate::write_debt`. It exits 0 when it
    writes, 1 when it refuses with the findings printed (growth, or a finding of the
    default rules), and 2 when the repository is not judged strict (the coverage record
    does not say `strictness: strict` and `--strict` is not given), `--write` is
    missing, or the tool cannot run. The JSON kind `debt-written` joins the record
    kinds, with the members `path`, `change`, `findings` and `lines`, and it equals the
    kind of no rule. `debt --write` writes one file and the reports write nothing.

    /// `assess`: the context, a recorded verdict, or the list. Each prints
    /// outcomes only, so each exits 0 when it has an answer: a rejected verdict
    /// was recorded, and a stale or rejected assessment in the list is shown with
    /// its currency and left to `change reconcile`, which lists what it owes. A
    /// section given to `--list` must be one `--context` answers for, so an
    /// unknown capability is exit 2 in all three modes.
    pub(crate) fn assess(root: &Path, args: &AssessArgs) -> Result<Report, Failure> {
        let opened = Gate::workspace(root).open()?;
        let plan = opened.workplan();
        if args.list {
            // A section to list is one the library can assess: a capability or a
            // section that no loaded document has is an error, as for `--context`.
            if let Some(subject) = &args.subject {
                plan.assess_context(subject)?;
            }
            let states = plan.list_assessments();
            let shown: Vec<&AssessmentState> = states
                .iter()
                .filter(|state| args.subject.as_ref().is_none_or(|s| *s == state.subject))
                .collect();
            let mut report = Report::of(shown.iter().map(|state| state_record(state)));
            if shown.is_empty() {
                report.note(match &args.subject {
                    Some(subject) => format!("no assessment of {subject} loaded"),
                    None => "no assessment record loaded".to_string(),
                });
            }
            return Ok(report);
        }
        let subject = args
            .subject
            .as_deref()
            .ok_or_else(|| Failure::new("give the section to assess, `cap:<slug>#<section>`"))?;
        let Some(verdict) = args.verdict else {
            let context = plan.assess_context(subject)?;
            return Ok(Report::of([context_record(&context)]));
        };
        let by = args
            .by
            .ok_or_else(|| Failure::new("--verdict needs --by human or --by agent: who assessed"))?;
        let mut options = RecordOptions::new();
        if let Some(copyright) = &args.copyright {
            options = options.copyright(copyright.as_str());
        }
        if let Some(licence) = &args.licence {
            options = options.licence(licence.as_str());
        }
        let request =
            AssessmentRequest::new(subject, Verdict::verdict(verdict), by.actor()).options(options);
        let assessed = plan.record_assessment(root, &request)?;
        Ok(Report::of([assessed_record(&assessed)]))
    }

    /// Run the command of `args` and return what it produced.
    ///
    /// # Errors
    ///
    /// A [`Failure`] when the tool could not run: the root cannot be found, the
    /// repository cannot be opened, or the command's own input is refused. The
    /// command of `evidence record` is checked before the root is looked for, so
    /// a refusal of it starts no process.
    pub(crate) fn run(args: &Args) -> Result<Report, Failure> {
        let root = || workspace_root(args.root.as_deref());
        match &args.command {
            Command::Check => check(&root()?, args.strict),
            Command::Status => status(&root()?),
            Command::Docs(Docs::Sync(sync_args)) => sync(&root()?, sync_args),
            Command::Docs(Docs::Preview(preview_args)) => preview(&root()?, &preview_args.slug),
            Command::Change(Change::New(new_args)) => change::new(&root()?, new_args),
            Command::Change(Change::Impact(slug)) => change::impact(&root()?, &slug.slug),
            Command::Change(Change::Reconcile(slug)) => {
                change::reconcile(&root()?, &slug.slug, args.strict)
            }
            Command::Change(Change::Complete(slug)) => {
                change::complete(&root()?, &slug.slug, args.strict)
            }
            Command::Verify(verify_args) => change::verify(&root()?, verify_args.slug.as_deref()),
            Command::History(history_args) => history::history(&root()?, history_args),
            Command::Evidence(Evidence::Record(record_args)) => {
                let source = evidence::source(record_args)?;
                evidence::record(&root()?, record_args, source)
            }
            Command::Evidence(Evidence::Claims(id)) => evidence::claims(&root()?, &id.id),
            Command::Evidence(Evidence::For(cap)) => evidence::support(&root()?, &cap.capability),
            Command::Assess(assess_args) => assess::assess(&root()?, assess_args),
            Command::Coverage(Coverage::Code(coverage_args)) => {
                coverage::coverage(&root()?, coverage_args, GapKind::PublicItem)
            }
            Command::Coverage(Coverage::Tests(coverage_args)) => {
                coverage::coverage(&root()?, coverage_args, GapKind::Test)
            }
            Command::Coverage(Coverage::Claims(claims_args)) => coverage::claims(&root()?, claims_args),
            Command::Coverage(Coverage::Lines(lines_args)) => {
                coverage::lines(&root()?, lines_args, args.strict)
            }
            Command::Debt(debt_args) => debt::debt(&root()?, debt_args, args.strict),
        }
    }

    /// A coverage report of one direction, of the whole workspace or of the
    /// package `--crate` names. The report is a finding when it names a gap, or
    /// in the code direction a surface that cannot be listed, so the run exits 1;
    /// otherwise it is an outcome and exits 0. It starts no process beyond the
    /// `git` that lists the tracked files, and writes nothing.
    pub(crate) fn coverage(root: &Path, args: &CoverageArgs, kind: GapKind) -> Result<Report, Failure> {
        let opened = Gate::workspace(root).open()?;
        let plan = opened.workplan();
        let whole = plan.coverage_report();
        let report = match &args.package {
            None => whole,
            Some(name) => selected(&whole, name)?,
        };
        let errors = kind.is_code() && !report.errors().is_empty();
        let class = if report.gaps(kind).is_empty() && !errors {
            Class::Outcome
        } else {
            Class::Finding
        };
        Ok(Report::rendered(
            class,
            render::table(&report, kind),
            render::json(&report, kind),
        ))
    }

    /// `evidence record`: run the source of the verdict and write the record. A
    /// record written with the verdict `pass` is an outcome; one written with
    /// `fail` is a finding, so the run exits 1. A run that writes no record is a
    /// failure (exit 2).
    pub(crate) fn record(
        root: &Path,
        args: &RecordArgs,
        source: VerdictSource,
    ) -> Result<Report, Failure> {
        let opened = Gate::workspace(root).open()?;
        let plan = opened.workplan();
        let mut options = RecordOptions::new();
        if let Some(copyright) = &args.copyright {
            options = options.copyright(copyright.as_str());
        }
        if let Some(licence) = &args.licence {
            options = options.licence(licence.as_str());
        }
        let mut request = EvidenceRequest::new(
            args.id.as_str(),
            args.covers.clone(),
            args.by.actor(),
            source,
        )
        .limits(args.limit.clone())
        .options(options);
        if let Some(revision) = &args.revision {
            request = request.revision(revision.as_str());
        }
        if args.update {
            request = request.mode(WriteMode::Replace);
        }
        let runner = SystemRunner::new(Programs::new(root));
        let recorded = plan.record_evidence(root, &runner, &request)?;
        Ok(Report::of([recorded_record(&recorded)]))
    }

    /// The source of the verdict of `evidence record`: the bound test or example
    /// `--from-binding` names, or the command after `--`. Nothing is read and
    /// nothing is started here, so a refusal comes before root discovery.
    ///
    /// # Errors
    ///
    /// A [`Failure`] when the program name of the process is `--`, when
    /// `--from-binding` is given beside a `--`, when the command line holds no
    /// command after `--`, its program is the empty word or a word of it is not
    /// UTF-8, or when the words after its first `--` are not the command the
    /// parser read.
    pub(crate) fn source(args: &RecordArgs) -> Result<VerdictSource, Failure> {
        line(std::env::args_os(), args.from_binding.is_some())?;
        if let Some(path) = &args.from_binding {
            return Ok(VerdictSource::Binding(path.clone()));
        }
        let trusted = TrustedArgv::from_command_line(std::env::args_os())?;
        let words: Vec<&OsStr> = trusted
            .words()
            .iter()
            .map(|word| OsStr::new(word.as_str()))
            .collect();
        agree(&words, &args.command)?;
        Ok(VerdictSource::Command(trusted))
    }

    /// `evidence for <cap:slug>`: each record that supports the capability.

    //! Text from a document, a record or a commit, made safe to print: each
    //! character that changes how a terminal shows the text around it is written
    //! as its `\u{..}` escape. The history and coverage tables escape their cells
    //! with it, and the command line escapes the text output of the commands that
    //! print document text, so no text can move the cursor of a terminal, set its
    //! title, clear it, ring it, or reorder how a line reads.
    
    use std::fmt::Write as _;
    
    /// Whether `c` changes how a terminal shows the text around it: a control
    /// character, or a bidirectional formatting character (the marks U+061C,
    /// U+200E and U+200F, the embeddings and overrides U+202A to U+202E, and the
    /// isolates U+2066 to U+2069).
    fn hidden(c: char) -> bool {
        c.is_control()
            || matches!(
                c,
                '\u{61c}' | '\u{200e}' | '\u{200f}' | '\u{202a}'..='\u{202e}' | '\u{2066}'..='\u{2069}'
            )
    }
    
    /// `text` with each character that `keep` does not keep and that changes how
    /// a terminal shows the text around it as its `\u{..}` escape.
    fn escaped(text: &str, keep: impl Fn(char) -> bool) -> String {
        let mut out = String::with_capacity(text.len());
        for c in text.chars() {
            if hidden(c) && !keep(c) {
                let _ = write!(out, "\\u{{{:x}}}", u32::from(c));
            } else {
                out.push(c);
            }
        }
        out
    }
    
    /// `text` on one line: every control character, line feeds and tabs
    /// included, and every bidirectional formatting character as its escape.
    pub(crate) fn shown(text: &str) -> String {
        escaped(text, |_| false)
    }
    
    /// `text` as lines: each control character other than the line feed and the
    /// tab, a carriage return and an escape included, and each bidirectional
    /// formatting character as its `\u{..}` escape, so the text keeps its lines
    /// and indentation and nothing else of it reaches the terminal as a control.
    /// Other text, non-ASCII letters and symbols included, is kept as it is.
    ///
    /// ```rust
    /// use raf_workplan::escape::shown_lines;
    ///
    /// let text = "It holds.\u{1b}]0;title\u{7}\n\tSo \u{202e}does this.\n";
    /// assert_eq!(
    ///     shown_lines(text),
    ///     "It holds.\\u{1b}]0;title\\u{7}\n\tSo \\u{202e}does this.\n"
    /// );
    /// ```
    #[must_use]
    pub fn shown_lines(text: &str) -> String {
        escaped(text, |c| c == '\n' || c == '\t')
    }

    //! Process-free workspace discovery through `raf-source`.
    
    use raf_source::{DiskTree, LoadError, RelPath, TreeError};
    use std::error::Error;
    use std::fmt;
    use std::path::{Path, PathBuf};
    
    /// Why a workspace root cannot be discovered.
    #[derive(Debug)]
    #[non_exhaustive]
    pub enum RootError {
        /// The starting directory cannot be canonicalized.
        Directory(std::io::Error),
        /// The filesystem tree cannot be opened.
        Tree(TreeError),
        /// A manifest or membership finding prevents discovery.
        Source(LoadError),
        /// A filesystem path cannot be represented as a portable tree path.
        Path(String),
    }
    impl fmt::Display for RootError {
        fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
            match self {
                Self::Directory(error) => write!(f, "cannot open discovery directory: {error}"),
                Self::Tree(error) => write!(f, "{error}"),
                Self::Source(error) => write!(f, "{error}"),
                Self::Path(path) => write!(
                    f,
                    "cannot represent discovery path `{}` as a tree path",
                    path.escape_debug()
                ),
            }
        }
    }
    impl Error for RootError {
        fn source(&self) -> Option<&(dyn Error + 'static)> {
            match self {
                Self::Directory(error) => Some(error),
                Self::Tree(error) => Some(error),
                Self::Source(error) => Some(error),
                Self::Path(_) => None,
            }
        }
    }
    /// Find the workspace containing `directory`, without starting any process.
    ///
    /// # Errors
    ///
    /// Returns [`RootError`] for an inaccessible directory, a malformed manifest,
    /// an unlisted package, or conflicting membership. See
    /// [`raf_source::discover_root`] for the tree-based discovery contract.
    pub fn discover(directory: &Path) -> Result<PathBuf, RootError> {
        let directory = directory.canonicalize().map_err(RootError::Directory)?;
        let boundary = directory
            .ancestors()
            .last()
            .ok_or_else(|| RootError::Path(directory.display().to_string()))?;
        let relative = directory
            .strip_prefix(boundary)
            .map_err(|_| RootError::Path(directory.display().to_string()))?;
        let text = relative
            .to_str()
            .ok_or_else(|| RootError::Path(relative.display().to_string()))?;
        let start = RelPath::new(&text.replace(std::path::MAIN_SEPARATOR, "/"))
            .map_err(|_| RootError::Path(text.to_owned()))?;
        let tree = DiskTree::new(boundary).map_err(RootError::Tree)?;
        let root = raf_source::discover_root(&tree, &start).map_err(RootError::Source)?;
        Ok(boundary.join(root.as_str()))
    }
