    Contract
    
    ### Capability identity and shape
    <!-- raf:tested-by raf_workplan::test_crate::documents::the_model_holds_typed_values_and_bodies,raf_workplan::test_crate::references::a_slug_id_that_differs_from_the_file_name_is_refused,raf_workplan::test_crate::references::a_slug_that_is_not_kebab_case_is_refused,raf_workplan::test_crate::references::a_matching_kebab_slug_is_accepted -->
    
    A capability lives at `docs/capabilities/<slug>.md`, with
    the identity `cap:<slug>`, the keys and the seven sections defined in
    [the RAF profile of OKF](../architecture/okf-profile.md) (its
    [section table](../architecture/okf-profile.md#body-rules) says what each section holds) and read by
    [the OKF reader](./okf-profile.md).
    
    ### Capability lifetime identity
    <!-- raf:tested-by cargo_workplan::test_crate::new::the_printed_template_in_a_capability_of_each_state_gives_a_clean_check_and_one_unresolved_proposal,cargo_workplan::test_crate::complete::from_new_to_a_completed_change_through_the_binary -->
    
    The document is permanent: authors keep its identity and its path from the first
    time the capability is considered until the capability is removed. Lifecycle
    operations retain that identity and path as the author changes its state.
    
    ### State and open-record consistency
    <!-- raf:tested-by raf_workplan::test_crate::states::accepts_each_state_with_matching_content,raf_workplan::test_crate::states::rejects_each_non_delivered_state_without_an_open_record,raf_workplan::test_crate::states::rejects_delivered_with_open_change_record -->
    
    `state` is one of the following, and each fixes what the
    document and the change records may say.
    
    | State | What the capability document holds | Change record |
    | --- | --- | --- |
    | `considered` | Purpose, open questions and the candidate contract, the candidate inside PROPOSED blocks | An open record lists it |
    | `designed` | The designed contract, the selected approach, rationale and planned examples, stated plainly | An open record lists it |
    | `implementing` | The same contract with real code and test bindings and the remaining gaps | An open record lists it |
    | `delivered` | The supported contract, usage, examples, limitations, current rationale and verification links | No open record lists it |
    
    ### State transition policy
    <!-- raf:tested-by cargo_workplan::test_crate::new::the_printed_template_in_a_capability_of_each_state_gives_a_clean_check_and_one_unresolved_proposal,cargo_workplan::test_crate::complete::from_new_to_a_completed_change_through_the_binary,raf_workplan::test_crate::states::rejects_delivered_with_open_change_record -->
    
    A change to a delivered capability puts the capability back under an open record,
    which moves it to `implementing`: the current account stays as written, and the
    new text of the change sits beside it in PROPOSED blocks. Everything that moves a capability
    between states is a change. These are authoring obligations: `change new` prints
    the required state edit but does not perform it. Reconciliation and verification
    also retain the authored state; the author sets `delivered` before completion.
    
    ### Proposal ownership and placement
    <!-- raf:tested-by raf_workplan::test_crate::states::rejects_orphan_proposed_marker,raf_workplan::test_crate::states::rejects_proposed_section_missing_from_affects,raf_workplan::test_crate::states::rejects_proposed_change_that_does_not_list_the_capability,raf_workplan::test_crate::states::rejects_considered_without_proposed_block,raf_workplan::test_crate::states::rejects_delivered_with_proposed_block,raf_workplan::test_crate::states::rejects_designed_with_proposed_block,raf_workplan::test_crate::documents::rejects_proposed_marker_in_architecture,raf_workplan::test_crate::documents::rejects_proposed_marker_in_change -->
    
    Text that a change proposes is written into the capability
    document, marked as a block quote whose first line names the change:
    
    ```markdown
    > [!PROPOSED change:incremental-parsing]
    > The parser accepts input in arbitrary chunks and reports incomplete input when
    > the caller finishes the stream.
    ```
    
    The block continues while lines keep the quote marker, and ends at the first line
    without it, at the next marker, or at a fenced code block. The branch diff therefore
    shows the code and the documentation it produces together. Outside PROPOSED
    blocks a document states the current contract only. A PROPOSED block is valid only in
    a Capability document, only when `work/changes/<slug>.md` exists, only when that
    record lists the capability, and only when the record's `affects` names the section
    that holds the block. A `delivered` or `designed` capability has none, and a
    `considered` capability has at least one.
    
    ### Change record structure
    <!-- raf:tested-by raf_workplan::test_crate::documents::the_model_holds_typed_values_and_bodies,raf_workplan::test_crate::rules::every_rule_has_a_fixture_reported_with_file_and_location,raf_workplan::test_crate::references::accepts_a_moved_outcome_that_names_an_existing_change,raf_workplan::test_crate::references::rejects_moved_missing -->
    
    A change lives at `work/changes/<slug>.md` with the identity
    `change:<slug>`. Its keys are `type`, `id`, `title`, `description`, `changes`,
    `affects`, `contract_effect` and `items`:
    
    - `changes` lists the capabilities the change alters.
    - `affects` lists `cap:<slug>#<section>` entries naming the sections that must be
      reconciled.
    - `contract_effect` is `changes` when the documented contract moves and `none` when
      the change is internal.
    - `items` lists the claims the change makes. Each has a `claim` and, before the
      change completes, an optional `outcome` of `implemented`, `dropped` or
      `moved:change:<slug>`. A `moved` outcome names an existing change that now carries
      the claim.
    
    The body holds a non-empty `## Summary`.
    
    ### Completed change records
    <!-- raf:tested-by cargo_workplan::test_crate::complete::a_completed_change_prints_what_was_removed_and_rewritten_and_leaves_a_clean_check -->
    
    Completing a change deletes the file, and Git holds its history.
    
    ### Slug references
    <!-- raf:tested-by raf_workplan::test_crate::references::a_slug_id_that_differs_from_the_file_name_is_refused,raf_workplan::test_crate::references::a_slug_that_is_not_kebab_case_is_refused,raf_workplan::test_crate::references::a_matching_kebab_slug_is_accepted -->
    
    A slug is lowercase kebab case and equals the file name without
    `.md`. Every reference between documents uses the id form, so a rename is one edit to
    the file name, the id and the references, which `check` verifies.
    
    ### Typed loading and invalid-document exclusion
    <!-- raf:tested-by raf_workplan::test_crate::documents::accepts_valid_fixture,raf_workplan::test_crate::documents::the_model_holds_typed_values_and_bodies,raf_workplan::test_crate::documents::a_broken_document_is_a_finding_and_not_in_the_model,raf_workplan::test_crate::documents::an_oversize_file_is_reported_by_name_and_not_skipped -->
    
    `Workplan::load` reads `docs/capabilities`, `docs/architecture` and
    `work/changes` through a source tree, validates each document with the OKF reader
    and keeps the typed documents and their bodies. A document that does not validate is
    a finding and is not in the model; nothing is skipped and nothing panics. Links are
    judged against the tracked paths of a `LinkContext` (`Workplan::load_with`);
    `Workplan::load` takes every file of the tree as tracked. `Workplan::check` returns
    every finding.
    
    ### Finding vocabulary and diagnostics
    <!-- raf:tested-by raf_workplan::test_crate::kinds::kinds_are_unique_kebab_case_names,raf_workplan::test_crate::kinds::every_rule_and_every_reader_error_has_its_own_kind,raf_workplan::test_crate::kinds::every_kind_is_produced_by_a_named_fixture_and_every_produced_kind_is_a_kind,raf_workplan::test_crate::kinds::every_finding_names_a_fix_and_a_message,raf_workplan::test_crate::documents::a_finding_renders_with_its_place_and_its_fix -->
    
    A `Finding` has a stable kebab-case kind
    from `Finding::KINDS`, the file, a location (a key, a section or a line) and a fix;
    each rule of the profile and each reader error has its own kind.
    
    ### Typed records and absent directories
    <!-- raf:tested-by raf_workplan::test_crate::records::a_repository_without_record_directories_has_no_records_and_no_new_findings,raf_workplan::test_crate::records::each_record_type_loads_from_its_directory_into_the_model,raf_workplan::test_crate::records::work_coverage_holds_only_the_coverage_record,raf_workplan::test_crate::debt::a_file_other_than_the_one_record_is_a_finding -->
    
    `Workplan::load` also reads the records of the profile: the evidence
    records of `work/evidence`, the assessments of `work/assessments`, the coverage
    record `work/coverage/default.md` and the strict debt record `work/debt/default.md`
    of [complete policy](./workplan-strict.md), each validated with the OKF reader and kept
    as a typed record (`Workplan::evidence`, `Workplan::assessments`,
    `Workplan::coverage`, `Workplan::debt`). A record directory holds its records
    directly, as a document directory does, and `work/coverage` and `work/debt` hold only
    `default.md`: any other file there is `singleton-other-file` and is not read. A
    directory that does not exist holds nothing, so a repository without records loads
    and reports no finding of the record rules; that it has no coverage record is the
    one finding [two-way coverage](./workplan-two-way-coverage.md) gives it, and that it
    has no debt record is none.
    
    ### Complete policy and finding order
    <!-- raf:tested-by raf_workplan::test_crate::strict::content_and_binding_findings_follow_load_findings,raf_workplan::test_crate::strict::the_removed_policy_key_is_rejected_even_for_its_former_values,raf_workplan::test_crate::strict::the_default_gate_judges_the_complete_policy_in_its_opened_workplan -->
    
    Every `Workplan::check` judges the complete
    [content and binding policy](./workplan-strict.md) after the document-model and
    generated-block findings, then applies the debt ratchet. Loading documents
    retains only loading and relationship findings in `Workplan::findings`; it does
    not select a lighter check. Gate callers, reconciliation and the completion check
    after record removal use the same complete policy. There is no policy enum,
    caller floor or coverage key that disables those checks.
    
    ### Graph nodes and document edges
    <!-- raf:tested-by raf_workplan::test_crate::graph::the_graph_has_every_kind_of_node,raf_workplan::test_crate::graph::the_graph_has_every_kind_of_edge,raf_workplan::test_crate::graph::links_run_from_the_section_that_holds_them_to_the_section_they_name -->
    
    `raf-workplan` builds a graph (`Workplan::graph`) from the documents
    and the source.
    
    - Nodes: capabilities, sections, changes, architecture pages, proposals, the
      code symbols, tests and examples that bindings name, evidence records,
      assessments, the coverage record, the crates the
      coverage record scopes and the symbols the inputs of records name.
    - Edges: bindings (capability to symbol, test or example), `depends`, `changes`,
      `affects` and Markdown links. A link runs from the section that holds it to the
      section its anchor names, or to the document when it has no anchor.
    
    ### Record and proof edges
    <!-- raf:tested-by raf_workplan::test_crate::records::the_records_are_nodes_with_their_edges,raf_workplan::test_crate::records::claims_are_section_granular_and_one_edge_per_named_record,raf_workplan::test_crate::records::each_input_of_a_record_that_resolves_is_an_edge_and_one_that_does_not_is_no_finding,raf_workplan::test_crate::records::a_claim_inside_a_proposed_block_is_not_a_claim_until_it_is_resolved,raf_workplan::test_crate::graph::the_graph_has_every_kind_of_edge -->
    
    - Record edges: `for` from an evidence record to each capability it covers; a claim
      from the section of a capability that holds a claim marker to each evidence
      record the marker names; the subject of an assessment, a section; `scope` from
      the coverage record to each crate; and an input edge from a record to the
      section, the definitions of the symbol or the evidence record each of its input
      rows names. An input whose name resolves to nothing the repository holds makes no
      edge and is no finding of the load: an input that moved is a matter of the
      record's currency. A claim marker inside a PROPOSED block is not a claim until
      the block is resolved.
    - Tested-by edges: from the section of a capability that holds a tested-by marker
      to each test or example binding of the same capability whose path the marker
      names.
    
    ### Graph queries and dependency cycles
    <!-- raf:tested-by raf_workplan::test_crate::references::rejects_depends_cycles_once_for_each_group_naming_its_members,raf_workplan::test_crate::graph::code_of_lists_the_items_that_realise_a_capability_in_path_order,raf_workplan::test_crate::graph::capabilities_of_names_every_capability_bound_to_a_symbol,raf_workplan::test_crate::graph::tests_for_a_binding_named_in_two_sections_substantiates_both,raf_workplan::test_crate::graph::sections_of_a_change_are_its_affected_sections_sorted,raf_workplan::test_crate::graph::linking_sections_are_section_granular,raf_workplan::test_crate::records::the_records_are_nodes_with_their_edges,raf_workplan::test_crate::records::claims_are_section_granular_and_one_edge_per_named_record,raf_workplan::test_crate::records::each_input_of_a_record_that_resolves_is_an_edge_and_one_that_does_not_is_no_finding -->
    
    The graph must have no `depends` cycle. It answers questions in both directions:
    which code realises this capability (`Graph::code_of`), which capabilities a symbol
    is bound to (`Graph::capabilities_of`), which tests address a section
    (`Graph::tests_for`), which sections a change must update (`Graph::sections_of`),
    and which sections link to a section (`Graph::linking_sections`). For the records it
    lists the `for` edges (`Graph::covers`) and the evidence that covers a capability
    (`Graph::evidence_of`), the claims (`Graph::claims`) and those on one evidence
    record (`Graph::claims_on`), the tested-by edges (`Graph::tested_by`), the subjects of the assessments (`Graph::assesses`)
    and the assessments of a section (`Graph::assessments_of`), the `scope` edges
    (`Graph::scope`), and the input edges (`Graph::inputs`) and those of one record
    (`Graph::inputs_of`).
    
    ### Binding roles and resolution
    <!-- raf:tested-by raf_workplan::test_crate::bindings::a_binding_through_a_re_export_resolves_to_its_definition,raf_workplan::test_crate::bindings::the_role_is_judged_on_the_definition_a_re_export_leads_to,raf_workplan::test_crate::bindings::a_tests_binding_must_name_a_function_marked_test,raf_workplan::test_crate::bindings::a_code_binding_must_name_a_shipping_item,raf_workplan::test_crate::bindings::an_examples_binding_is_an_example_target_or_a_documented_library_item,raf_workplan::test_crate::bindings::a_binding_to_a_missing_path_is_reported_with_its_capability,raf_workplan::test_crate::bindings::a_path_two_globs_both_bring_in_is_ambiguous_and_names_both_definitions,raf_workplan::test_crate::bindings::a_binding_to_a_macro_generated_function_is_not_found -->
    
    Each entry in `bindings.code` is a Rust path to a shipping
    item, each entry in `bindings.tests` a path to a function marked `#[test]`, and each
    entry in `bindings.examples` an example target (`<package>::example_crate::<name>`)
    or a documented item of a library whose documentation tests run. All resolve through
    the [source index](./source-index.md), including re-exports, and the role is judged
    on the definition the path leads to. A binding that does not resolve, that names more
    than one definition, or whose item does not fit its list is an error naming the
    capability, the list and the binding. A symbol that a macro generates is not in the
    index, so it cannot be bound. A capability with nothing built binds nothing, so
    `designed` capabilities carry empty lists. An `implementing` capability may have
    empty or missing bindings; `status` and the catalogue report each one as a gap;
    [reconcile](./workplan-reconcile.md) defines the obligation it becomes. A
    `delivered` capability binds at least one code path and one test.
    
    ### Roadmap grouping and binding gaps
    <!-- raf:tested-by raf_workplan::test_crate::roadmap::an_implementing_capability_lists_its_gaps_exactly,raf_workplan::test_crate::roadmap::only_an_implementing_capability_has_gaps,raf_workplan::test_crate::roadmap::a_resolving_binding_of_the_wrong_role_is_not_a_gap,raf_workplan::test_crate::roadmap::open_changes_are_the_changes_that_list_the_capability,raf_workplan::test_crate::roadmap::the_roadmap_does_not_depend_on_insertion_order_and_repeats,raf_workplan::test_crate::roadmap::slug_order_is_not_file_name_order -->
    
    `Workplan::status` returns the `Roadmap`: every capability that loaded,
    grouped by state in the order `delivered`, `implementing`, `designed`, `considered`
    and sorted by slug inside a group. Each entry carries its state, the open changes
    that list it and, for an `implementing` capability, its gaps: the binding lists that
    are empty and the bindings that do not resolve.
    
    ### Profile and directory checks
    <!-- raf:tested-by raf_workplan::test_crate::rules::every_rule_has_a_fixture_reported_with_file_and_location,raf_workplan::test_crate::parse_errors::every_reader_error_has_a_fixture_reported_with_file_and_line,raf_workplan::test_crate::documents::rejects_nested_documents,raf_workplan::test_crate::documents::rejects_type_in_the_wrong_directory,raf_workplan::test_crate::documents::rejects_capability_without_frontmatter,raf_workplan::test_crate::references::a_slug_id_that_differs_from_the_file_name_is_refused -->
    
    `check` reports every violation of these rules, each naming its file:
    
    - the schemas and closed key sets of every document;
    - flat document directories, each document in the directory of its type, and no
      Markdown file without frontmatter beside the documents;
    - ids that equal their file names, and references that exist;
    
    ### Relationship and Markdown checks
    <!-- raf:tested-by raf_workplan::test_crate::references::rejects_depends_cycles_once_for_each_group_naming_its_members,raf_workplan::test_crate::references::rejects_depends_missing,raf_workplan::test_crate::references::rejects_changes_missing,raf_workplan::test_crate::references::rejects_moved_missing,raf_workplan::test_crate::links::rejects_broken_relative_link,raf_workplan::test_crate::links::rejects_broken_anchor,raf_workplan::test_crate::links::rejects_link_to_a_tracked_symlink,raf_workplan::test_crate::links::rejects_link_leaving_the_repository,raf_workplan::test_crate::refs::every_document_type_and_the_frontmatter_are_scanned,raf_workplan::test_crate::generated::a_body_that_mixes_line_endings_is_refused_by_sync_and_reported_by_check -->
    
    The relationship and Markdown rules cover:
    
    - an acyclic `depends` graph;
    - links that resolve inside the repository against the tracked paths, including
      heading anchors, and no link to a tracked symlink;
    - no issue or pull request reference and no development-process wording, by the
      one pattern set of `raf_workplan::refs` that every consumer's `check` applies;
    - a document whose body mixes CRLF and LF line endings, which is an error;
    
    ### Binding, generated-content and state checks
    <!-- raf:tested-by raf_workplan::test_crate::bindings::bindings_that_name_real_symbols_resolve,raf_workplan::test_crate::bindings::a_tests_binding_must_name_a_function_marked_test,raf_workplan::test_crate::bindings::a_code_binding_must_name_a_shipping_item,raf_workplan::test_crate::generated::the_stale_finding_points_at_the_opening_marker_of_the_block,raf_workplan::test_crate::states::rejects_orphan_proposed_marker,raf_workplan::test_crate::states::rejects_proposed_section_missing_from_affects,raf_workplan::test_crate::states::rejects_proposed_change_that_does_not_list_the_capability,raf_workplan::test_crate::states::rejects_each_non_delivered_state_without_an_open_record,raf_workplan::test_crate::states::surfaces_the_single_document_state_rules_from_the_profile -->
    
    The binding, generated-content and state checks require:
    
    - bindings that resolve through the source index in their roles;
    - generated blocks that match what the sync operation (`Workplan::sync`) writes
      (see [generated documents](./workplan-generated-docs.md));
    - PROPOSED blocks that name an existing change which lists their capability and
      affects their section;
    - an open change record for every capability that is not `delivered`;
    - a `delivered` capability with no PROPOSED block, no open change record and no
      empty required section;
    - a `designed` capability with no PROPOSED block;
    - a `considered` capability with its candidate contract in PROPOSED blocks;
    
    ### Record relationships and complete checks
    <!-- raf:tested-by raf_workplan::test_crate::records::a_record_that_names_what_does_not_exist_is_a_finding_and_its_neighbour_is_clean,raf_workplan::test_crate::records::a_claim_on_unknown_evidence_names_the_file_and_the_line,raf_workplan::test_crate::records::a_claim_on_evidence_for_another_capability_is_a_finding,raf_workplan::test_crate::claim_coverage::an_unbound_claim_marker_is_refused_beside_covered_neighbors,raf_workplan::test_crate::strict::content_and_binding_findings_follow_load_findings,raf_workplan::test_crate::lines::an_exception_by_item_prefix_file_and_directory_takes_its_lines_out_and_one_beside_it_that_matches_nothing_is_a_finding,raf_workplan::test_crate::lines::a_ceiling_row_of_no_package_is_scope_crate_missing_at_ceilings,raf_workplan::test_crate::debt::a_row_of_a_kind_that_is_no_debt_or_a_subject_of_another_form_is_invalid,raf_workplan::test_crate::debt::a_paid_finding_fails_until_the_write_and_then_the_record_equals_the_present_debt -->
    
    The record checks report:
    
    - the references of the records and the claims, each with its file and, for a
      claim, the line of its marker: a claim on evidence that does not exist
      (`claim-evidence-missing`) or whose `for` does not list the capability
      (`claim-evidence-not-for`); an evidence record whose `for` names no capability
      document (`evidence-for-missing`); an assessment whose subject is a section of no
      capability document (`assessment-subject-missing`); an assessment whose id is not
      `assessment:<capability slug>-<section>` of its subject, the one id the
      assessment of that section has (`assessment-id-mismatch`); and a `scope` entry
      that is no package of the source workspace (`scope-crate-missing`). A name whose
      document or record exists and is broken is explained by the findings of that
      file;
    - on every check, a tested-by marker entry that is no path of the
      capability's `tests` or `examples` bindings (`claim-test-unbound`), at the line of
      the marker; each entry that is one is a `TestedByEdge` of the graph
      (`Graph::tested_by`), from the section that holds the marker to the binding;
    - on every check, the rules of [complete policy](./workplan-strict.md), each a `Finding`
      of a kind in `Finding::KINDS` with its file, location and fix;
    - on every check, the rules of the line keys of the coverage record: a line
      exception that names nothing of the source index (`coverage-exception-unmatched`)
      and a `ceilings` row whose `crate` is no package of the source workspace
      (`scope-crate-missing`), each at its key.
    
    - on every check, a debt row that holds no debt (`debt-entry-invalid`), and a row
      that records debt that is paid (`debt-resolved`).
    
    ### Tracked Markdown outside document directories

    ### Canonical input digests
    <!-- raf:tested-by raf_workplan::test_crate::digest::each_kind_hashes_its_documented_encoding,raf_workplan::test_crate::digest::a_symbol_and_a_record_with_equal_bytes_differ,raf_workplan::test_crate::digest::crlf_and_lf_give_the_same_digest,raf_workplan::test_crate::digest::a_regenerated_block_leaves_the_section_digest_and_an_edit_moves_it,raf_workplan::test_crate::digest::every_definition_of_a_path_counts_once_in_file_order,raf_workplan::test_crate::digest::a_module_stands_for_its_files_and_the_modules_below_it_and_a_sibling_does_not_move_it,raf_workplan::test_crate::digest::a_digest_is_written_and_read_as_sixty_four_lowercase_hex_digits -->
    
    `raf_workplan::digest::Digest` is the SHA-256 (FIPS 180-4) of a canonical
    encoding of a record input, one or more fields
    `<kind> NUL <name> NUL <length> NUL <text>`: the kind (`section`, `symbol` or
    `record`) keeps the domains apart and the decimal length says where each field
    ends.
    `Digest::section` hashes the authored text of a section, with the content of its
    generated blocks left out; `Digest::symbol` hashes the source span of each
    definition a path resolves to, once per source item and in file order, and for a

symbol raf_workplan::LinkContext (named in the section)

    /// The oracle the link rules judge links against.
    ///
    /// A relative link must lead to a path in the set of tracked paths or to a
    /// directory that holds one, and not to a tracked symlink. A link with an
    /// anchor to a Markdown file must name a heading of that file, which is read

    ///
    /// [`LinkContext::new`] takes the tracked paths from the caller, typically
    /// the list of the version-control index. [`LinkContext::of_tree`] takes every
    /// file the tree lists. For a memory tree and a small fixture that is the
    /// tracked set. For a disk tree it also includes untracked and ignored files,
    /// build output and the `.git` directory, so a link to a file that is not
    /// tracked passes: a caller that checks a working copy passes its tracked list
    /// to [`LinkContext::new`].

    /// once, with interior mutability that is not thread-safe, so it is neither
    /// `Send` nor `Sync`; use one on one thread.

    /// use std::collections::BTreeSet;
    /// use raf_source::{MemoryTree, RelPath};

    /// assert!(plain::check("NOTES.md", "[a](README.md#readme)\n", &context).is_empty());

        bodies: RefCell<BTreeMap<String, Option<Rc<Body>>>>,
    }

symbol raf_workplan::digest::Digest::symbol (named in the section)
  in crates/raf-workplan/src/digest.rs
    /// The digest of the source text of the symbol `path`, resolved through
        /// `source` as a binding is.
        ///
        /// The text of a definition is its whole span in its file, attributes and
        /// documentation included, with CRLF read as LF. A path with more than one
        /// definition (`#[cfg(unix)] fn a()` beside `#[cfg(windows)] fn a()`)
        /// hashes each once, in the order of file and position; a definition the
        /// index reaches under several module paths, because its file is read by
        /// more than one target, has one source key and counts once. Each
        /// definition is the field `symbol NUL <path> NUL <length> NUL <text>`.
        ///
        /// A module stands for its whole content, as it does in coverage: after
        /// the field of its own span (an inline module's braces, or the
        /// declaration `mod name;`), each file of the module and of the modules
        /// below it in the same target is one more field with the file's whole
        /// text, the fields in the order of file and position. Editing any item inside a bound
        /// module, in its own file or in a child module's file, moves the digest;
        /// editing a sibling module does not. A crate root stands for nothing
        /// below it, so only its own span is hashed.
        ///
        /// ```rust
        /// use raf_source::{MemoryTree, Workspace};
        /// use raf_workplan::digest::Digest;
        ///
        /// let load = |lib: &str| {
        ///     Workspace::load(
        ///         &MemoryTree::from([
        ///             ("Cargo.toml", "[package]\nname = \"demo\"\nversion = \"0.1.0\"\n"),
        ///             ("src/lib.rs", lib),
        ///         ]),
        ///         &["."],
        ///     )
        /// };
        /// let before = load("pub fn other() {}\npub fn run() {}\n")?;
        /// let after = load("pub fn other() { let _ = 1; }\npub fn run() {}\n")?;
        /// // Editing another item leaves the digest of `run` as it was.
        /// assert_eq!(Digest::symbol(&before, "demo::run")?, Digest::symbol(&after, "demo::run")?);
        /// assert_ne!(Digest::symbol(&before, "demo::other")?, Digest::symbol(&after, "demo::other")?);
        /// # Ok::<(), Box<dyn std::error::Error>>(())
        /// ```
        ///
        /// # Errors
        ///
        /// [`SymbolDigestError::Resolve`] when the path does not resolve to one
        /// symbol, and [`SymbolDigestError::Source`] when the index holds no text
        /// for a definition's span.
        pub fn symbol(source: &Workspace, path: &str) -> Result<Self, SymbolDigestError> {
            let sites = symbol_sites(source, path)?;
            Ok(symbol_of(path, sites))
        }

        rules(path, text, context, &mut out);

    //! Writing the evidence, assessment, coverage and debt records.
    //!
    //! A [`Record`] is written as the text the `raf-okf` writer renders for its
    //! type ([`raf_okf::EvidenceRecord::to_document`] and its siblings), opened
    //! with the two SPDX comment lines when [`RecordOptions`] gives them. Before
    //! any byte is written the text is read back through the profile and the
    //! reference scan at the path of the record, so a written record loads with
    //! no finding of its own. [`create`] writes a new record and never replaces
    //! a file; [`replace`] puts new text in place of a record that exists, through
    //! a temporary file and a rename.

    /// A record to write.
    #[derive(Debug, Clone, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum Record {
        /// An evidence record, written to `work/evidence/<slug>.md`.
        Evidence(EvidenceRecord),
        /// An assessment record, written to `work/assessments/<slug>.md`.
        Assessment(AssessmentRecord),
        /// The coverage record, written to `work/coverage/default.md`.
        Coverage(CoverageRecord),
        /// The debt record, written to `work/debt/default.md`.
        Debt(DebtRecord),
    }
    
    impl Record {
        /// The type of the record.
        #[must_use]
        pub fn doc_type(&self) -> DocType {
            match self {
                Self::Evidence(_) => DocType::Evidence,
                Self::Assessment(_) => DocType::Assessment,
                Self::Coverage(_) => DocType::Coverage,
                Self::Debt(_) => DocType::Debt,
            }
        }
    
        /// The id, slug, tags and timestamp of the record.
        #[must_use]
        pub fn header(&self) -> &RecordHeader {
            match self {
                Self::Evidence(record) => &record.header,
                Self::Assessment(record) => &record.header,
                Self::Coverage(record) => &record.header,
                Self::Debt(record) => &record.header,
            }
        }
    
        /// The repository-relative path of the record: the directory of its type
        /// and its slug.
        ///
        /// # Errors
        ///
        /// [`RecordError::BadSlug`] when the slug is not a lowercase kebab-case
        /// slug, so it names no file of the directory.
        pub fn path(&self) -> Result<RelPath, RecordError> {
            let slug = &self.header().slug;
            let bad = || RecordError::BadSlug { slug: slug.clone() };
            if !is_kebab(slug) {
                return Err(bad());
            }
            RelPath::new(&format!("{}/{slug}.md", self.doc_type().directory())).map_err(|_| bad())
        }
    
        /// The text of the record file: the rendering of the `raf-okf` writer,
        /// with the SPDX comment lines of `options` after the opening fence, read
        /// back through the profile and the reference scan at [`Record::path`].
        ///
        /// ```rust
        /// use raf_okf::{CoverageRecord, Exclusion, ExclusionItem};
        /// use raf_workplan::record::{Record, RecordOptions};
        ///
        /// let record = Record::Coverage(CoverageRecord::new(
        ///     vec!["demo".to_string()],
        ///     vec![Exclusion::new(
        ///         ExclusionItem::Prefix("demo::internal".to_string()),
        ///         "Helpers with no contract.",
        ///     )],
        /// ));
        /// let options = RecordOptions::new()
        ///     .copyright("2026 Example Org <dev@example.org>")
        ///     .licence("CC-BY-4.0");
        /// let text = record.text(&options)?;
        /// assert!(text.starts_with("---\n# SPDX-"));
        /// assert!(text.contains("\nscope: [demo]\n"));
        /// assert_eq!(record.path()?.as_str(), "work/coverage/default.md");
        /// # Ok::<(), Box<dyn std::error::Error>>(())
        /// ```
        ///
        /// # Errors
        ///
        /// [`RecordError::BadSlug`]; [`RecordError::SpdxUnset`] or
        /// [`RecordError::SpdxInvalid`] when only one SPDX field is given or a
        /// field is not one line of text; [`RecordError::Build`] when a value
        /// cannot be written in the frontmatter subset; and
        /// [`RecordError::Invalid`] when the text does not read back as a record
        /// with no finding, such as a value the profile refuses or an issue
        /// reference in a command.
        pub fn text(&self, options: &RecordOptions) -> Result<String, RecordError> {
            let path = self.path()?;
            let spdx = spdx::pair(options.copyright.as_deref(), options.licence.as_deref())?;
            let document = match self {
                Self::Evidence(record) => record.to_document(),
                Self::Assessment(record) => record.to_document(),
                Self::Coverage(record) => record.to_document(),
                Self::Debt(record) => record.to_document(),
            }?;
            let text = spdx::with_spdx(document.render(), spdx);
            let mut findings = Vec::new();
            refs::scan(path.as_str(), &text, &mut findings);
            match Document::parse(&text) {
                Ok(read) => {
                    if let Err(violations) = Profile.validate(&read, path.as_str()) {
                        findings.extend(violations.iter().map(Finding::from_violation));
                    }
                }
                Err(error) => findings.push(Finding::from_parse_error(path.as_str(), &error)),
            }
            if findings.is_empty() {
                Ok(text)
            } else {
                Err(RecordError::Invalid { path, findings })
            }
        }
    }
    
    /// The SPDX comment lines a written record opens with.
    ///
    /// A repository that checks the licence of every file (REUSE) needs each
    /// record to open with two SPDX comment lines; `copyright` and `licence` give
    /// their text, and are written together or not at all.
    #[derive(Debug, Clone, Default, PartialEq, Eq)]
    #[non_exhaustive]
    pub struct RecordOptions {
        /// The text of the `SPDX-FileCopyrightText` comment line. Required when
        /// `licence` is set.
        pub copyright: Option<String>,
        /// The identifier of the `SPDX-License-Identifier` comment line. Required
        /// when `copyright` is set.
        pub licence: Option<String>,
    }
    
    impl RecordOptions {
        /// Options with no SPDX lines.
        #[must_use]
        pub fn new() -> Self {
            Self::default()
        }
    
        /// Open the record with the SPDX copyright comment line `text`.
        #[must_use]
        pub fn copyright(mut self, text: impl Into<String>) -> Self {
            self.copyright = Some(text.into());
            self
        }
    
        /// Open the record with the SPDX licence comment line `id`.
        #[must_use]
        pub fn licence(mut self, id: impl Into<String>) -> Self {
            self.licence = Some(id.into());
            self
        }
    }
    
    /// Why a record was not written. Nothing is written in any case.
    #[derive(Debug)]
    #[non_exhaustive]
    pub enum RecordError {
        /// The slug is not a lowercase kebab-case slug.
        BadSlug {
            /// The slug as given.
            slug: String,
        },
        /// One of `copyright` and `licence` is given and the other is not.
        SpdxUnset {
            /// The field that is missing: `copyright` or `licence`.
            field: &'static str,
        },
        /// An SPDX field cannot be written as one comment line.
        SpdxInvalid {
            /// The field: `copyright` or `licence`.
            field: &'static str,
            /// Why.
            reason: &'static str,
        },
        /// A value cannot be written in the frontmatter subset.
        Build(ConstructError),
        /// The text does not read back as a record with no finding.
        Invalid {
            /// The path of the record.
            path: RelPath,
            /// The findings the text would have.
            findings: Vec<Finding>,
        },
        /// [`create`]: a file, or a link, is already at the path. It is untouched.
        Exists {
            /// The path of the record.
            path: RelPath,
        },
        /// [`replace`]: no regular file is at the path to replace.
        Missing {
            /// The path of the record.
            path: RelPath,
        },
        /// The file could not be written, or a directory it needs is refused.
        Write {
            /// The path that was being written or judged.
            path: String,
            /// Why.
            source: io::Error,
        },
    }
    
    impl fmt::Display for RecordError {
        fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
            match self {
                Self::BadSlug { slug } => write!(
                    f,
                    "`{slug}` is not a record slug; use lowercase letters and digits joined by single `-`"
                ),
                Self::SpdxUnset { field } => write!(
                    f,
                    "the record needs both SPDX lines or neither, and the {field} is not given; pass --copyright <text> and --licence <id> together"
                ),
                Self::SpdxInvalid { field, reason } => write!(
                    f,
                    "the {field} of the SPDX header of the record is refused: {reason}"
                ),
                Self::Build(error) => write!(f, "the record cannot be written: {error}"),
                Self::Invalid { path, findings } => {
                    write!(
                        f,
                        "the record {path} would not load clean, so nothing is written"
                    )?;
                    crate::lookup::write_findings(f, findings)
                }
                Self::Exists { path } => write!(
                    f,
                    "{path} already exists and is left as it is; a new record never replaces a file"
                ),
                Self::Missing { path } => write!(
                    f,
                    "{path} is not a record file that exists, so there is nothing to replace"
                ),
                Self::Write { path, source } => write!(f, "cannot write {path}: {source}"),
            }
        }
    }
    
    impl Error for RecordError {
        fn source(&self) -> Option<&(dyn Error + 'static)> {
            match self {
                Self::Build(error) => Some(error),
                Self::Write { source, .. } => Some(source),
                _ => None,
            }
        }
    }
    
    impl From<ConstructError> for RecordError {
        fn from(error: ConstructError) -> Self {
            Self::Build(error)
        }
    }
    
    impl From<Refused> for RecordError {
        fn from(refused: Refused) -> Self {
            Self::Write {
                path: refused.path,
                source: refused.source,
            }
        }
    }
    
    impl From<SpdxError> for RecordError {
        fn from(error: SpdxError) -> Self {
            match error {
                SpdxError::Unset { field } => Self::SpdxUnset { field },
                SpdxError::Invalid { field, reason } => Self::SpdxInvalid { field, reason },
            }
        }
    }
    
    /// Write the new record `record` below `root`, the directory that holds
    /// `work/`, and return its path.
    ///
    /// The text is [`Record::text`]. The file is created exclusively: a file or a
    /// link already at the path is [`RecordError::Exists`] and is not touched.
    /// The directory of the record type is created when it is missing; it and
    /// `work` must each be a directory or not exist, and a symbolic link, inside
    /// the root or out of it, or a file there is refused during preflight. This
    /// path-based inspection retains no directory handles against a later name
    /// swap. A failure after the file was
    /// created removes it again.
    ///
    /// # Errors
    ///
    /// Every error of [`Record::text`], before anything is written;
    /// [`RecordError::Exists`]; and [`RecordError::Write`] when the file or its
    /// directory cannot be created, in which case no file is left.
    pub fn create(
        root: &Path,
        record: &Record,
        options: &RecordOptions,
    ) -> Result<RelPath, RecordError> {
        let text = record.text(options)?;
        let path = record.path()?;
        files::create_new(root, record.doc_type().directory(), &path, &text).map_err(|error| {
            match error {
                CreateError::Exists => RecordError::Exists { path: path.clone() },
                CreateError::Write { path, source } => RecordError::Write { path, source },
            }
        })?;
        Ok(path)
    }
    
    /// Put the text of `record` in place of the record file that exists at its
    /// path below `root`, and return the path.
    ///
    /// `work` and the directory of the record type must each be a directory, and
    /// a symbolic link there, inside the root or out of it, or a file is refused,
    /// as [`create`] refuses it during preflight. Publication uses those paths
    /// without retaining directory handles against a later name swap. The target
    /// must then be a regular file; a missing file, a
    /// directory and a symbolic link are refused.
    /// The new text is written to a temporary file beside the target, created
    /// exclusively, and renamed over it, so the target holds either its old text
    /// or the new one, never part of either. The file keeps its permissions.
    ///
    /// # Errors
    ///
    /// Every error of [`Record::text`], before anything is written;
    /// [`RecordError::Missing`] when no regular file is at the path;
    /// [`RecordError::Write`] naming the directory refused on the way, before
    /// anything is written; and [`RecordError::Write`] when the temporary file
    /// cannot be written or renamed, in which case the temporary file is removed
    /// and the target is unchanged.
    pub fn replace(
        root: &Path,
        record: &Record,
        options: &RecordOptions,
    ) -> Result<RelPath, RecordError> {
        let text = record.text(options)?;
        let path = record.path()?;
        let write = |source: io::Error| RecordError::Write {
            path: path.to_string(),
            source,
        };
        match files::target(root, record.doc_type().directory(), &path) {
            Ok(Target {
                kind: Some(EntryKind::File),
                ..
            }) => {}
            Ok(_) => return Err(RecordError::Missing { path }),
            Err(error) => return Err(error.into()),
        }
        publish_replacement(root, &path, &text).map_err(write)?;
        Ok(path)
    }
    
    /// Publish the replacement after the regular-file and directory inspection.
    /// The path inspection retains no handles or later-name comparison.
    fn publish_replacement(root: &Path, path: &RelPath, text: &str) -> io::Result<()> {
        let target = fs::canonicalize(root)?.join(path.as_str());
        let temporary = sync::stage(&target, text)?;
        if let Err(error) = fs::rename(&temporary, &target) {
            // Only the temporary file this call created is removed.
            let _ = fs::remove_file(&temporary);
            return Err(error);
        }
        Ok(())
    }
    
    #[cfg(all(test, unix))]
    mod tests {
        use super::{
            Record, RecordError, RecordOptions, Target, files, fs, publish_replacement, replace,
        };
        use raf_okf::CoverageRecord;
        use raf_source::EntryKind;
    
        #[test]
        fn a_directory_swap_after_preflight_is_not_rechecked_by_replacement_publication() {
            let scratch = purrdf_testkit::TempDir::new_in(std::env::temp_dir())
                .expect("create replacement fixture");
            let root = scratch.path();
            let record = Record::Coverage(CoverageRecord::new(Vec::new(), Vec::new()));
            let options = RecordOptions::new();
            let path = record.path().unwrap();
            let text = record.text(&options).unwrap();
            fs::create_dir_all(root.join("work/coverage")).unwrap();
            fs::create_dir(root.join("alternate")).unwrap();
            fs::write(root.join(path.as_str()), "original\n").unwrap();
            fs::write(root.join("alternate/default.md"), "alternate\n").unwrap();
            assert!(matches!(
                files::target(root, "work/coverage", &path).unwrap(),
                Target {
                    kind: Some(EntryKind::File),
                    directories: true
                }
            ));
    
            fs::rename(root.join("work/coverage"), root.join("original")).unwrap();
            std::os::unix::fs::symlink("../alternate", root.join("work/coverage")).unwrap();
            publish_replacement(root, &path, &text)
                .expect("replacement follows the names after inspection");
            assert_eq!(
                fs::read_to_string(root.join("alternate/default.md")).unwrap(),
                text
            );
            assert_eq!(
                fs::read_to_string(root.join("original/default.md")).unwrap(),
                "original\n"
            );
            assert!(matches!(
                replace(root, &record, &options),
                Err(RecordError::Write { path, .. }) if path == "work/coverage"
            ));
    
            fs::remove_file(root.join("work/coverage")).unwrap();
            fs::rename(root.join("original"), root.join("work/coverage")).unwrap();
            assert_eq!(replace(root, &record, &options).unwrap(), path);
            assert_eq!(fs::read_to_string(root.join(path.as_str())).unwrap(), text);
        }
    }

    //! The one pattern set for issue and pull request numbers and for
    //! development-process wording.
    //!
    //! The patterns are a small hand-made matcher, so no pattern-matching crate
    //! is needed. [`banned_in_line`] judges one line of text. The repository
    //! gates and the `issue-reference` rule of [`Workplan::check`](crate::Workplan::check)
    //! both call it, so there is a single definition of what such a reference is.
    //!
    //! Phrases below are written with a `[ ]` character class in place of a
    //! space. That keeps every pattern from matching its own text, and `unclass`
    //! turns the class back into a space for matching.
    
    use std::fmt;
    
    use raf_okf::Location;
    
    use crate::Finding;
    use crate::finding::kind;
    
    /// Why a line is banned.
    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum Banned {
        /// An issue or pull request number or link.
        IssueNumber,
        /// Wording that refers to the development process that produced a file.
        ProcessWording,
    }
    
    impl Banned {
        /// The reason, as a phrase.
        #[must_use]
        pub fn description(self) -> &'static str {
            match self {
                Self::IssueNumber => "issue or pull request number",
                Self::ProcessWording => "development-process wording",
            }
        }
    }
    
    impl fmt::Display for Banned {
        fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
            f.write_str(self.description())
        }
    }
    
    /// Phrases that mark development-process wording (matched case-insensitively).
    const PROCESS_PHRASES: [&str; 3] = ["this[ ]issue", "per[ ]the[ ]plan", "this[ ]branch"];
    
    /// A prefix that must be followed by digits to be an issue or change number.
    struct NumberedForm {
        /// The literal text before the digits, with `[ ]` standing for a space.
        prefix: &'static str,
        /// Match without regard to letter case.
        ignore_case: bool,
        /// Require a non-word character (or the line start) before the prefix.
        word_start: bool,
        /// Report as process wording rather than as an issue number.
        process: bool,
    }
    
    const NUMBERED_FORMS: [NumberedForm; 7] = [
        NumberedForm {
            prefix: "/issues/",
            ignore_case: false,
            word_start: false,
            process: false,
        },
        NumberedForm {
            prefix: "/pull/",
            ignore_case: false,
            word_start: false,
            process: false,
        },
        NumberedForm {
            prefix: "CHANGE[-]",
            ignore_case: false,
            word_start: false,
            process: false,
        },
        NumberedForm {
            prefix: "issue[ ]",
            ignore_case: true,
            word_start: true,
            process: false,
        },
        NumberedForm {
            prefix: "GH[-]",
            ignore_case: true,
            word_start: true,
            process: false,
        },
        NumberedForm {
            prefix: "pull[ ]request[ ]",
            ignore_case: true,
            word_start: true,
            process: false,
        },
        NumberedForm {
            prefix: "task[ ]",
            ignore_case: true,
            word_start: false,
            process: true,
        },
    ];
    
    /// Replace each `[ ]` and `[-]` character class with its literal character.
    fn unclass(pattern: &str) -> String {
        pattern.replace("[ ]", " ").replace("[-]", "-")
    }
    
    fn is_word(c: char) -> bool {
        c.is_alphanumeric() || c == '_'
    }
    
    /// The character before byte offset `index`, if any.
    fn char_before(line: &str, index: usize) -> Option<char> {
        line.get(..index).and_then(|s| s.chars().next_back())
    }
    
    /// Byte offsets where `needle` occurs in `line`, optionally ignoring case.
    fn find_all(line: &str, needle: &str, ignore_case: bool) -> Vec<usize> {
        if ignore_case {
            // Lowercasing can change byte lengths for non-ASCII text, so fold
            // ASCII only; every needle here is ASCII.
            line.to_ascii_lowercase()
                .match_indices(&needle.to_ascii_lowercase())
                .map(|(index, _)| index)
                .collect()
        } else {
            line.match_indices(needle).map(|(index, _)| index).collect()
        }
    }
    
    /// True when a digit directly follows an occurrence of the form's prefix.
    fn numbered_form_hit(line: &str, form: &NumberedForm) -> bool {
        let needle = unclass(form.prefix);
        find_all(line, &needle, form.ignore_case)
            .into_iter()
            .any(|index| {
                if form.word_start && char_before(line, index).is_some_and(is_word) {
                    return false;
                }
                line.get(index + needle.len()..)
                    .and_then(|rest| rest.chars().next())
                    .is_some_and(|c| c.is_ascii_digit())
            })
    }
    
    /// A `PR` label followed by a number, with or without a space or hash, and
    /// with a non-word character before `PR`.
    fn pull_request_label(line: &str) -> bool {
        line.match_indices("PR").any(|(index, _)| {
            if char_before(line, index).is_some_and(is_word) {
                return false;
            }
            let rest = line.get(index + 2..).unwrap_or_default();
            let rest = rest.strip_prefix(' ').unwrap_or(rest);
            let rest = rest.strip_prefix('#').unwrap_or(rest);
            rest.chars().next().is_some_and(|c| c.is_ascii_digit())
        })
    }
    
    /// An acceptance-criterion label: `AC` and digits, delimited by non-word text.
    fn acceptance_label(lower: &str) -> bool {
        lower.match_indices("ac").any(|(index, _)| {
            let rest = lower.get(index + 2..).unwrap_or_default();
            let digits = rest.chars().take_while(char::is_ascii_digit).count();
            digits > 0
                && !char_before(lower, index).is_some_and(is_word)
                && !rest.chars().nth(digits).is_some_and(is_word)
        })
    }
    
    /// "the plan" followed by any one character and `s` (a possessive).
    fn plan_possessive(lower: &str) -> bool {
        let needle = unclass("the[ ]plan");
        lower.match_indices(&needle).any(|(index, _)| {
            let mut rest = lower
                .get(index + needle.len()..)
                .unwrap_or_default()
                .chars();
            rest.next().is_some() && rest.next() == Some('s')
        })
    }
    
    /// A `#` followed by one to five decimal digits that reads as a reference.
    ///
    /// The character before `#` must not be `&` or `#`; a word character before
    /// it (a cross-repository reference, or a keyword with no space) does not
    /// spare the token. The run of word characters after `#` must be one to five
    /// digits, so a letter a-f (a hex colour such as `#1f2`) or a longer run
    /// (`#123456`) is spared. A three- or four-digit token is also spared when it
    /// directly follows `"` or `'`, which is how a colour attribute value is
    /// written in markup. After `:` or a space only a token with a hex letter is
    /// spared, so an all-digit token after a keyword and a colon, or an all-digit
    /// CSS colour, fails closed; write such a colour with letters or as `#112233`.
    fn hash_number(line: &str) -> bool {
        line.match_indices('#').any(|(index, _)| {
            let before = char_before(line, index);
            if before.is_some_and(|c| c == '&' || c == '#') {
                return false;
            }
            let run: String = line
                .get(index + 1..)
                .unwrap_or_default()
                .chars()
                .take_while(|c| is_word(*c))
                .collect();
            let numeric = (1..=5).contains(&run.len()) && run.chars().all(|c| c.is_ascii_digit());
            let colour_context = matches!(before, Some('"' | '\''));
            numeric && !((3..=4).contains(&run.len()) && colour_context)
        })
    }
    
    /// Why a line is banned, or `None` when it is clean.
    ///
    /// A line is banned when it holds an issue or pull request number (a hash and
    /// up to five digits, an issue or pull request label with a number, a tracker
    /// link) or wording that refers to the development process (a task number, an
    /// acceptance label, a reference to a plan or a branch). A colour written as a
    /// hexadecimal triple and numbers in prose are not references.
    #[must_use]
    pub fn banned_in_line(line: &str) -> Option<Banned> {
        if hash_number(line)
            || pull_request_label(line)
            || NUMBERED_FORMS
                .iter()
                .filter(|form| !form.process)
                .any(|form| numbered_form_hit(line, form))
        {
            return Some(Banned::IssueNumber);
        }
        let lower = line.to_lowercase();
        let process = PROCESS_PHRASES
            .iter()
            .any(|phrase| lower.contains(&unclass(phrase)))
            || plan_possessive(&lower)
            || NUMBERED_FORMS
                .iter()
                .filter(|form| form.process)
                .any(|form| numbered_form_hit(&lower, form))
            || acceptance_label(&lower);
        process.then_some(Banned::ProcessWording)
    }
    
    /// The `issue-reference` findings of the text of the file `file`: one for each
    /// line [`banned_in_line`] bans.
    pub(crate) fn scan(file: &str, text: &str, out: &mut Vec<Finding>) {
        for (index, line) in text.lines().enumerate() {
            if let Some(banned) = banned_in_line(line) {
                out.push(Finding::new(
                    kind::ISSUE_REFERENCE,
                    file,
                    Location::Line(index + 1),
                    format!("{banned} is banned"),
                    "describe the system, not the tracker or the process that produced the file; remove the reference",
                ));
            }
        }
    }
