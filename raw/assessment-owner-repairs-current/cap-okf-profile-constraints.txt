section docs/capabilities/okf-profile.md
    Constraints
    
    - The crate reads and writes text only. It touches no file and runs no process, so
      a caller supplies the document text as strings.
      <!-- raf:tested-by raf_okf::test_crate::render::a_change_document_built_from_constructors_renders_and_reads_back_equal -->
    - Input is bounded to 1 MiB, 32 YAML levels, 64 Markdown block levels and 4096 bytes
      per link destination or title, and YAML anchors and aliases are refused. A bound
      violation is a parse error.
      <!-- raf:tested-by raf_okf::test_crate::refusals::a_text_of_exactly_one_mebibyte_parses_and_one_more_byte_is_refused,raf_okf::test_crate::refusals::nesting_over_thirty_two_levels_is_refused_before_descent,raf_okf::test_crate::body_structure::block_nesting_of_sixty_four_levels_parses_and_sixty_five_is_refused,raf_okf::test_crate::links::a_destination_or_title_of_exactly_4096_bytes_is_read_and_one_more_is_refused -->
    - Only ATX headings (`#` marks) and fenced code blocks are modelled. A setext heading
      is not a heading, and indented code is read as ordinary text, so a marker or a link
      in it counts; write code that holds a marker or a link in a fence.
      <!-- raf:tested-by raf_okf::test_crate::body_structure::only_atx_headings_are_headings_and_setext_headings_are_not,raf_okf::test_crate::body_structure::indented_code_is_ordinary_text_so_links_and_markers_in_it_count -->
    - Keys are exactly those of the profile. There is no pass-through for extra keys.
      <!-- raf:tested-by raf_okf::test_crate::profile::an_unknown_or_foreign_key_is_reported_on_every_type,raf_okf::test_crate::profile::a_nested_unknown_key_is_reported_in_bindings_and_in_a_change_item -->
    - A document is valid or invalid. There is no warning level.
      <!-- raf:tested-by raf_okf::test_crate::profile::a_document_with_three_faults_returns_three_violations,raf_okf::test_crate::profile::valid_documents_of_each_type_validate_to_typed_values -->
    - The writer preserves comments in the frontmatter but does not reflow the body.
      <!-- raf:tested-by raf_okf::test_crate::render::comments_attach_to_the_next_key_and_trailing_comments_stay_on_their_line,raf_okf::test_crate::render::a_parsed_document_equals_its_rendering_read_back,raf_okf::test_crate::splice::two_generated_blocks_change_only_their_byte_ranges -->
    - The crate takes no position on tense or content. Checks on prose belong to the
      reconcile operation.
      <!-- raf:tested-by raf_okf::test_crate::profile::future_tense_prose_is_not_a_violation -->

    /// Why a value or document cannot be built from its parts.
    ///
    /// The constructors refuse every value the reader would not read back, so a
    /// document built from parts renders text that parses to an equal document.
    #[derive(Debug, Clone, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum ConstructError {
        /// A scalar holds a control character that has no escape, so no style can
        /// write it.
        Unrepresentable {
            /// The character.
            character: char,
        },
        /// A key is empty or holds characters outside `A-Z a-z 0-9 _ -`.
        InvalidKey {
            /// The offending key text.
            key: String,
        },
        /// A key occurs twice in one mapping.
        DuplicateKey {
            /// The repeated key.
            key: String,
        },
        /// A mapping has no entries; the reader reads `key:` as an empty scalar.
        EmptyMap,
        /// A block list has no items; write a flow list `[]` instead.
        EmptyBlockList,
        /// A list item is an empty unquoted scalar.
        EmptyListItem,
        /// A flow list holds an unquoted scalar with a character the flow syntax
        /// reserves, or one the reader would read as something else.
        NotFlowSafe {
            /// The scalar text.
            text: String,
        },
        /// A block list mixes scalar items and mapping items.
        MixedList,
        /// A list item is itself a list.
        NestedSequence,
        /// Nesting is deeper than the bound.
        DepthExceeded {
            /// The bound in levels.
            max: usize,
        },
        /// The rendered text exceeds the size bound.
        TooLarge {
            /// Size of the rendered text in bytes.
            len: usize,
            /// The bound in bytes.
            max: usize,
        },
        /// The body does not read: a malformed marker or nesting over the bound.
        /// The line and offset are in the text the document renders to.
        Body(ParseError),
    }

symbol raf_okf::CoverageRecord::to_document (bound by the capability; the section names no bound symbol by a path)
  in crates/raf-okf/src/profile/write.rs
    /// The record as a document, with its keys in the order of the profile's
        /// key table, the exclusions in record order and an empty body; an empty
        /// `scope` or `exclusions` is written `[]`.
        /// The ceilings and the exceptions are written in record order after the
        /// exclusions, each key left out when it holds none; a ceiling writes
        /// `crate`, `lines` or `percent`, and `of` unless it is `all`, and an
        /// exception its `item` or `file` and its `reason`.
        /// See [`EvidenceRecord::to_document`].
        ///
        /// # Errors
        ///
        /// A [`ConstructError`] when a value cannot be written in the frontmatter
        /// subset.
        pub fn to_document(&self) -> Result<Document, ConstructError> {
            let mut entries = header(DocType::Coverage, &self.header)?;
            entries.push(flow("scope", &self.scope)?);
            entries.push(rows(
                "exclusions",
                self.exclusions
                    .iter()
                    .map(|exclusion| {
                        let item = match &exclusion.item {
                            ExclusionItem::Item(path) => path.clone(),
                            ExclusionItem::Prefix(path) => format!("{path}::*"),
                        };
                        vec![("item", item), ("reason", exclusion.reason.clone())]
                    })
                    .collect(),
            )?);
            if !self.ceilings.is_empty() {
                let rows = self
                    .ceilings
                    .iter()
                    .map(|ceiling| {
                        let mut row = vec![("crate", Scalar::new(ceiling.package.as_str())?)];
                        row.push(match &ceiling.limit {
                            CeilingLimit::Lines(lines) => ("lines", number(lines)),
                            CeilingLimit::Percent(percent) => ("percent", number(percent)),
                        });
                        if ceiling.of != CeilingClass::All {
                            row.push(("of", Scalar::new(ceiling.of.name())?));
                        }
                        Ok(row)
                    })
                    .collect::<Result<Vec<_>, ConstructError>>()?;
                entries.push(scalar_rows("ceilings", rows)?);
            }
            if !self.exceptions.is_empty() {
                entries.push(rows(
                    "exceptions",
                    self.exceptions
                        .iter()
                        .map(|exception| {
                            vec![
                                (exception.target.key(), exception.target.written()),
                                ("reason", exception.reason.clone()),
                            ]
                        })
                        .collect(),
                )?);
            }
            document(entries)
        }

symbol raf_okf::DebtRecord::to_document (bound by the capability; the section names no bound symbol by a path)
  in crates/raf-okf/src/profile/write.rs
    /// The record as a document, with its keys in the order of the profile's
        /// key table, the rows in record order and an empty body; an empty
        /// `findings` or `lines` is written `[]`. A finding writes `kind` and
        /// `subject`, and a line `item` and `orphans`, a whole number written
        /// plain. [`DebtRecord::new`] sorts the rows, so two equal debts write
        /// the same bytes. See [`EvidenceRecord::to_document`].
        ///
        /// # Errors
        ///
        /// A [`ConstructError`] when a value cannot be written in the frontmatter
        /// subset.
        pub fn to_document(&self) -> Result<Document, ConstructError> {
            let mut entries = header(DocType::Debt, &self.header)?;
            entries.push(rows(
                "findings",
                self.findings
                    .iter()
                    .map(|finding| {
                        vec![
                            ("kind", finding.kind.clone()),
                            ("subject", finding.subject.clone()),
                        ]
                    })
                    .collect(),
            )?);
            let lines = self
                .lines
                .iter()
                .map(|line| {
                    Ok(vec![
                        ("item", Scalar::new(line.item.as_str())?),
                        (
                            "orphans",
                            Scalar {
                                text: line.orphans.to_string(),
                                style: ScalarStyle::Plain,
                            },
                        ),
                    ])
                })
                .collect::<Result<Vec<_>, ConstructError>>()?;
            entries.push(scalar_rows("lines", lines)?);

symbol raf_okf::EvidenceRecord::to_document (bound by the capability; the section names no bound symbol by a path)
  in crates/raf-okf/src/profile/write.rs
    /// The record as a document, with its keys in the order of the profile's
        /// key table, the measures in record order and an empty body. Its
        /// [`Document::render`] is the text of `work/evidence/<slug>.md`, which
        /// [`Profile::validate`](crate::Profile::validate) reads back as a record
        /// equal to this one when the values satisfy the profile. Comments are
        /// not part of the typed value and are not written.
        ///
        /// ```rust
        /// use raf_okf::{
        ///     Actor, Document, EvidenceRecord, EvidenceSubject, EvidenceVerdict, Input, InputKind,
        ///     Profile, RafDocument,
        /// };
        ///
        /// let digest = "9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08";
        /// let mut record = EvidenceRecord::new(
        ///     "parse-bound",
        ///     EvidenceSubject::Command,
        ///     vec![Input::new(InputKind::Symbol, "raf_okf::Document::parse", digest)],
        ///     EvidenceVerdict::Pass,
        ///     Actor::Agent,
        ///     vec!["cap:okf-profile".to_string()],
        /// );
        /// record.command = Some("cargo bench parse".to_string());
        /// let text = record.to_document()?.render();
        /// let read = Document::parse(&text)?;
        /// match Profile.validate(&read, "work/evidence/parse-bound.md") {
        ///     Ok(RafDocument::Evidence(back)) => assert_eq!(back, record),
        ///     other => panic!("{other:?}"),
        /// }
        /// # Ok::<(), Box<dyn std::error::Error>>(())
        /// ```
        ///
        /// # Errors
        ///
        /// A [`ConstructError`] when a value cannot be written in the frontmatter
        /// subset, such as a control character with no escape or a measure name
        /// that is not a key.
        pub fn to_document(&self) -> Result<Document, ConstructError> {
            let mut entries = header(DocType::Evidence, &self.header)?;
            entries.push(text("subject", &self.subject.text())?);
            entries.push(inputs(&self.inputs)?);
            entries.push(text("verdict", self.verdict.name())?);
            entries.push(text("by", self.by.name())?);
            entries.push(flow("for", &self.covers)?);
            if let Some(command) = &self.command {
                entries.push(text("command", command)?);
            }
            if let Some(revision) = &self.revision {
                entries.push(text("revision", revision)?);
            }
            entries.extend(measures("values", &self.values)?);
            entries.extend(measures("limits", &self.limits)?);
            document(entries)
        }

    /// The order of the retained native exact decimal values of `self` and
        /// `other`, using `PurRDF`'s value comparison. Padding does not change the
        /// value, and negative zero equals zero. No text is reparsed and no
        /// floating-point value is read.
        ///
        /// ```rust
        /// use std::cmp::Ordering;
        /// use raf_okf::Number;
        ///
        /// let n = |text| Number::parse(text).expect("a number");
        /// assert_eq!(n("9007199254740993").compare(&n("9007199254740992")), Ordering::Greater);
        /// assert_eq!(n("0.30000000000000001").compare(&n("0.3")), Ordering::Greater);
        /// assert_eq!(n("1.50").compare(&n("01.5")), Ordering::Equal);
        /// assert_eq!(n("-0").compare(&n("0.0")), Ordering::Equal);
        /// assert_eq!(n("-2").compare(&n("-1.5")), Ordering::Less);
        /// ```
        #[must_use]
        pub fn compare(&self, other: &Self) -> Ordering {
            self.value.cmp(&other.value)
        }

symbol raf_okf::is_kebab (bound by the capability; the section names no bound symbol by a path)
  in crates/raf-okf/src/body/marker.rs
    /// Whether `slug` is a lowercase kebab-case slug: one or more parts of ASCII
    /// lowercase letters and digits, joined by single `-`, with no `-` at either
    /// end. It is the one slug pattern of the profile: the slug of a document id
    /// and of a PROPOSED marker, and the kind of a generated marker.
    ///
    /// ```rust
    /// use raf_okf::is_kebab;
    ///
    /// assert!(is_kebab("incremental-parsing"));
    /// assert!(is_kebab("2fa"));
    /// assert!(!is_kebab("-rf"));
    /// assert!(!is_kebab("Upper"));
    /// assert!(!is_kebab("a--b"));
    /// assert!(!is_kebab("../x"));
    /// assert!(!is_kebab(""));
    /// ```
    #[must_use]
    pub fn is_kebab(slug: &str) -> bool {
        !slug.is_empty()
            && slug.split('-').all(|part| {
                !part.is_empty()
                    && part
                        .chars()
                        .all(|c| c.is_ascii_lowercase() || c.is_ascii_digit())
            })
    }

    /// Whether `text` can be written as an unquoted scalar in a block or a flow
    /// position, and read back as exactly `text`.
    ///
    /// This is the one predicate the reader and the writer share. It is stricter
    /// than what the reader takes in a block position: it also refuses the flow

    }
symbol raf_okf::validate_timestamp (bound by the capability; the section names no bound symbol by a path)
  in crates/raf-okf/src/profile/timestamp.rs
    /// Check that `text` is an RFC 3339 date and time that is also a valid
    /// `xsd:dateTime`: four-digit year, a capital `T`, seconds from 00 to 59, an
    /// optional fraction of one or more digits, and a capital `Z` or a numeric
    /// offset. A timestamp without an offset is refused.
    ///
    /// # Errors
    ///
    /// [`TimestampError::Malformed`] when the text does not have the shape, and
    /// [`TimestampError::OutOfRange`] when a field is outside its range.
    pub fn validate_timestamp(text: &str) -> Result<(), TimestampError> {
        use purrdf_xsd::rfc3339::{self, LeapSecond, ParseErrorKind, Separator};
    
        // RAF's authored profile is narrower than RFC 3339's case-insensitive ABNF.
        if text.as_bytes().get(10) != Some(&b'T') || text.ends_with('z') {
            return Err(TimestampError::Malformed);
        }
        let parsed = rfc3339::parse(text, Separator::Rfc3339Abnf, LeapSecond::MonthEnd);
        match parsed {
            Ok(_) if text.as_bytes().get(17..19) == Some(b"60") => {
                Err(TimestampError::OutOfRange { field: "second" })
            }
            Ok(_) => Ok(()),
            Err(error) => Err(match error.kind() {
                ParseErrorKind::OutOfRange { field, .. } => TimestampError::OutOfRange {
                    field: if field == "day of month" {
                        "day"
                    } else {
                        field
                    },
                },
                ParseErrorKind::LeapSecond(_) => TimestampError::OutOfRange { field: "second" },
                ParseErrorKind::EndOfInput { .. }
                | ParseErrorKind::Unexpected { .. }
                | ParseErrorKind::Trailing { .. } => TimestampError::Malformed,
            }),
        }
    }

    //! Counts of the work the validator does, for tests that assert a bound on the
    //! work instead of timing it.
    //!
    //! A place that does a unit of work calls [`add`] with the kind and the amount.
    //! Outside `cfg(test)` the call compiles to nothing. In a test, [`measure`]
    //! runs a closure against fresh tallies and panics the moment any tally passes
    //! its ceiling, so an implementation that does too much work fails at once
    //! instead of running to the end. The tallies belong to the calling thread, so
    //! only work done on that thread is counted.
    
    /// One kind of work that is counted.
    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    pub(crate) enum Work {
        /// An entry of `changes` put into the set that `affects` is judged against.
        ChangeIdsSet,
        /// An `affects` entry judged against that set.
        AffectsEntries,
        /// An `affects` entry looked up in that set.
        ListedLookups,
        /// A generated block looked at by the search for the visible content of a
        /// section.
        BlocksVisited,
        /// A value of an evidence record put into the table the limits are judged
        /// against.
        MeasuresIndexed,
        /// A limit of an evidence record looked up among the values.
        LimitLookups,
        /// A line tested for opening or closing a fenced code block.
        FenceScans,
    }
    
    /// The number of kinds of [`Work`].
    #[cfg(test)]
    const KINDS: usize = 7;
    
    /// Every kind of [`Work`], in tally order.
    #[cfg(test)]
    const ALL: [Work; KINDS] = [
        Work::ChangeIdsSet,
        Work::AffectsEntries,
        Work::ListedLookups,
        Work::BlocksVisited,
        Work::MeasuresIndexed,
        Work::LimitLookups,
        Work::FenceScans,
    ];
    
    /// What one [`measure`] counted, per kind of [`Work`].
    #[cfg(test)]
    #[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
    pub(crate) struct Tally([usize; KINDS]);
    
    #[cfg(test)]
    impl Tally {
        /// The count of one kind of work.
        pub(crate) const fn get(&self, work: Work) -> usize {
            self.0[work as usize]
        }
    }
    
    #[cfg(test)]
    mod counting {
        use std::cell::Cell;
    
        use super::{KINDS, Tally, Work};
    
        thread_local! {
            /// The counts of this thread since the last reset.
            static TALLY: Cell<Tally> = const { Cell::new(Tally([0; KINDS])) };
            /// The count a kind may not pass while a measure runs: the one kind
            /// it limits, or every kind when that is `None`.
            static CEILING: Cell<Option<(Option<Work>, usize)>> = const { Cell::new(None) };
        }
    
        /// Count `amount` units of `work`, and panic if that passes the ceiling.
        pub(crate) fn add(work: Work, amount: usize) {
            let mut tally = TALLY.get();
            let slot = &mut tally.0[work as usize];
            *slot = slot.saturating_add(amount);
            let count = *slot;
            TALLY.set(tally);
            if let Some((limited, ceiling)) = CEILING.get()
                && limited.is_none_or(|kind| kind == work)
            {
                assert!(
                    count <= ceiling,
                    "{work:?} work passed the ceiling of {ceiling}: {count}"
                );
            }
        }
    
        /// Clears the ceiling when a measure ends, even by a panic.
        struct Armed;
    
        impl Drop for Armed {
            fn drop(&mut self) {
                CEILING.set(None);
            }
        }
    
        /// Run `run` against fresh tallies and return its result with what it
        /// counted. Panics the moment any kind of work passes `ceiling`.
        pub(crate) fn measure<T>(ceiling: usize, run: impl FnOnce() -> T) -> (T, Tally) {
            measured(None, ceiling, run)
        }
    
        /// Like [`measure`], but only `limited` is held to `ceiling`; the other
        /// kinds are counted without a limit.
        pub(crate) fn measure_kind<T>(
            limited: Work,
            ceiling: usize,
            run: impl FnOnce() -> T,
        ) -> (T, Tally) {
            measured(Some(limited), ceiling, run)
        }
    
        fn measured<T>(limited: Option<Work>, ceiling: usize, run: impl FnOnce() -> T) -> (T, Tally) {
            TALLY.set(Tally::default());
            CEILING.set(Some((limited, ceiling)));
            let _armed = Armed;
            let result = run();
            (result, TALLY.get())
        }
    }
    
    #[cfg(test)]
    pub(crate) use counting::{add, measure, measure_kind};
    
    /// Count work: nothing outside tests.
    #[cfg(not(test))]
    #[inline]
    pub(crate) fn add(_work: Work, _amount: usize) {}

            });
            assert_eq!(tally.get(Work::LimitLookups), 5);
            assert_eq!(tally.get(Work::AffectsEntries), 7);

        }
    
        #[test]

            let ((), tally) = measure(100, || {

            });

            assert_eq!(tally.get(Work::LimitLookups), 0);

            add(Work::LimitLookups, 1000);
        }
    }
