section docs/capabilities/source-index.md
    Usage
    
    The runnable `raf_source::example_crate::registry_scan` loads a small in-memory
    package, checks its module placement and prints the actual load counters when
    started without arguments. Passing a registry directory runs the native child
    scanner instead. The built-in package demonstrates the loader and formatter;
    it does not exercise process orchestration or establish arbitrary registry
    compatibility. The registry scanner retains its explicit platform and work-limit
    constraints.
    
    The runnable `raf_source::example_crate::corpus_generate` checks the actual shape
    and oracle corpus writers in temporary directories without a generated-program
    search. Explicit maintenance uses `shapes --write DIRECTORY` or
    `oracle --write DIRECTORY`; only the latter runs the existing full oracle search.
    For the committed destinations, run from the repository root:
    `cargo run -p raf-source --example corpus_generate -- shapes --write fuzz/corpus/parse-source`
    or `cargo run -p raf-source --example corpus_generate -- oracle --write fuzz/corpus/rustc-oracle`.
    
    The runnable API example `raf_source::Workspace::exported_items` loads a memory-backed workspace and inspects its supported public surface.
    
    Load a workspace from a real directory and ask where a path is defined. The block
    needs a real tree, so it is compiled and not run:
    
    ```rust,no_run
    use raf_source::{DiskTree, Workspace};
    
    let ws = Workspace::load(&DiskTree::new(".")?, &["crates"])?;
    let resolution = ws.resolve("raf_okf::Document")?;
    for site in &resolution.sites {
        let item = ws.item(*site).expect("a site is an item of this workspace");
        println!("{} at {}:{}", item.path, item.file, item.name_line);
    }
    for target in ws.targets().filter(|t| !t.shipping) {
        println!("{} is a non-shipping target", target.name);
    }
    # Ok::<(), Box<dyn std::error::Error>>(())
    ```
    
    A line that starts with `# ` is hidden by rustdoc and is there so that the block
    compiles.
    
    List the public surface of a library or a binary with `ws.exported_items(id)`, for
    an `id` of `ws.target_ids()`. Each `ExportedItem` of `items` maps its exported
    `path` back to its definition through `ws.item(export.item)`, and each `Reexport`
    of `reexports` gives what it re-exports as `written`. `exported_items_with(id,
    &options)`, with `options.include_hidden` set on `ExportOptions::default()`, lists
    what `#[doc(hidden)]` hides as well. The block lists the surface of each library of
    a real tree, so it is compiled and not run:
    
    ```rust,no_run
    use raf_source::{DiskTree, TargetKind, Workspace};
    
    let ws = Workspace::load(&DiskTree::new(".")?, &["crates"])?;
    for id in ws.target_ids() {
        let target = ws.target(id).expect("an id of this workspace");
        if target.kind != TargetKind::Lib {
            continue;
        }
        let exports = ws.exported_items(id)?;
        for export in &exports.items {
            let item = ws.item(export.item).expect("an item of this workspace");
            println!("{} is {} in {}", export.path, item.path, export.file);
        }
        for reexport in &exports.reexports {
            println!("{} re-exports {}", reexport.path, reexport.written);
        }
    }
    # Ok::<(), Box<dyn std::error::Error>>(())
    ```
    
    Resolve a path as a `use` written in a module would with `ws.resolve_from(module, path)`, or in one name space with `ws.resolve_from_in(module, path, namespace)`, for a `module` such as `"demo::inner"`. The reading module is the viewer: `ws.resolve_from("demo::b", "crate::a::go")` finds `demo::a::go` when `go` is `pub` in `a`, and a private item of `a` is `ResolveError::NotFound` for `b`. A module that is not in the index is `ResolveError::UnknownModule`.

symbol raf_source::Workspace::exported_items_with (named in the section)
  in crates/raf-source/src/workspace.rs
    /// The public surface of a library or binary target: the items another
        /// crate can name through its crate root, each under the path it is
        /// named by, and the public re-exports that name nothing the target
        /// defines.
        ///
        /// An item is exported when a chain of `pub` declarations reaches it from
        /// the crate root: `pub` modules, and `pub use` re-exports, named or glob,
        /// renamed or not, through modules of any visibility. A `pub` item of a
        /// private module is exported only through such a re-export, and a
        /// `pub(crate)`, `pub(super)`, `pub(in path)` or private item never is,
        /// nor is one that a re-export that is not `pub` carries on the way.
        /// Test code is never exported. The members of an exported type or trait
        /// are listed under its path: each member of a trait, and each `pub`
        /// member of an inherent impl of a type; the members of trait impls are
        /// not. A binary's surface is read the same way from its crate root; no
        /// other crate can name it. A re-export of another crate, of an enum
        /// variant or of a path the index cannot follow is a
        /// [`Reexport`](crate::Reexport) and not an item, also where a `pub` glob
        /// carries it from a module it reaches.
        ///
        /// # Errors
        ///
        /// Returns [`ExportError::NotLibraryOrBinary`] for a target id that names
        /// no library or binary of the workspace, [`ExportError::Resolve`] when a
        /// public name is ambiguous, goes through a cycle of imports or reads a
        /// glob whose path names nothing in the workspace, and
        /// [`ExportError::Budget`] when what the surface holds passes the
        /// item-bytes budget left after the load, and
        /// [`ExportError::CarryBudget`], naming the re-export, when the work of
        /// deciding whether the public globs carry a re-export passes it.
        pub fn exported_items_with(
            &self,
            target: TargetId,
            options: &ExportOptions,
        ) -> Result<Exports, ExportError> {
            let Some(found) = self
                .targets
                .get(target.index())
                .filter(|found| matches!(found.kind, TargetKind::Lib | TargetKind::Bin))
            else {
                return Err(ExportError::NotLibraryOrBinary(target));
            };
            let meter = Meter::new(&self.options);
            meter
                .items(self.usage.item_bytes, &found.root, None)
                .map_err(ExportError::Budget)?;
            // The modules of the target whose own file has `#![doc(hidden)]`.
            let hidden_files: BTreeSet<&str> = self
                .files
                .values()
                .filter(|file| file.facts.doc_hidden)
                .flat_map(|file| &file.reached)
                .filter(|reach| reach.target == target)
                .map(|reach| reach.module_path.as_str())
                .collect();
            Surface::new(
                &self.index,
                target,
                &found.crate_path,
                options,
                &meter,
                &hidden_files,
            )
            .list()
        }
symbol raf_source::Workspace::resolve_from (named in the section)

    /// Resolve the path of a `use` declaration written in the module `module`
        /// (a canonical module path such as `demo::inner`), trying the type, value
        /// and macro name spaces in that order. The reading module is the viewer:
        /// the path starts as code of that module starts it (`crate`, `self`,
        /// `super`, a name the module binds, or a crate of the extern prelude)
        /// and each segment counts only the bindings the module can access, as
        /// rustc settles an import.
        ///
        /// # Errors
        ///
        /// Returns [`ResolveError::UnknownModule`] when `module` is not a module
        /// of the workspace, and otherwise as [`Workspace::resolve`]: a path
        /// that names nothing the module can access is
        /// [`ResolveError::NotFound`], and one that names several symbols is
        /// [`ResolveError::Ambiguous`]. So is a `module` that starts with a
        /// crate path that targets of several packages share (two libraries with
        /// one crate name), as for [`Workspace::resolve`]: the answer lists the
        /// crate roots of those packages, and a module of any other crate reads
        /// as before. Nothing names the package here, so such a module cannot be
        /// read from.
        ///
        /// # Examples
        ///
        /// ```
        /// use raf_source::{MemoryTree, Workspace};
        ///
        /// let tree: MemoryTree = [
        ///     ("Cargo.toml", "[package]\nname = \"demo\"\nversion = \"0.1.0\"\nedition = \"2021\"\n"),
        ///     ("src/lib.rs", "mod a { pub fn go() {} fn hidden() {} }\nmod b {}\n"),
        /// ]
        /// .into_iter()
        /// .collect();
        /// let ws = Workspace::load(&tree, &["."])?;
        /// assert_eq!(ws.resolve_from("demo::b", "crate::a::go")?.path, "demo::a::go");
        /// assert!(ws.resolve_from("demo::b", "crate::a::hidden").is_err());
        /// # Ok::<(), Box<dyn std::error::Error>>(())
        /// ```
        pub fn resolve_from(&self, module: &str, path: &str) -> Result<Resolution, ResolveError> {
            self.index.resolve_from(module, path, None)
        }

    /// Text that the records of one load share: an item path, a name, a module

    /// One named item of the workspace.
    ///
    /// A written source item is identified in its file by the byte offset where its
    /// span starts. Crate-root items represent whole files instead and have no source
    /// group, even when their key equals that of the first written item.
    /// A file that several module trees reach has one `Item` for each path it is
    /// reached under; the items share their file and offset and differ in `path`
    /// and `target`.
    ///
    /// A record is at most 256 bytes: its text is shared ([`SharedStr`] and
    /// [`RelPath`]), and the trait key of an impl member is shared by the members
    /// of its impl block.
    #[derive(Debug, Clone, PartialEq, Eq)]
    #[non_exhaustive]
    pub struct Item {
        /// The identity of the item.
        pub id: ItemId,
        /// The full path: the module path and the name, with a method under its
        /// impl type, `<trait>::<method>` for a trait impl on a type that is not
        /// a local struct, enum or union, or `<self path>::<method>` for an

    impl Item {
        /// True when the item defines a name in `namespace`.
        #[must_use]
        pub fn in_namespace(&self, namespace: Namespace) -> bool {
            self.namespace == namespace
                || (namespace == Namespace::Value
                    && self.kind == SymbolKind::Struct
                    && matches!(self.shape, Some(FieldShape::Unit | FieldShape::Tuple)))
        }
    
        /// The names the parameters of a function or method bind, in signature
        /// order, as the source writes them: a `mut x`, a `ref x`, the names
        /// inside tuple, struct and slice patterns, a raw identifier with its
        /// `r#`. A receiver contributes `self`, first. Names that occur only in
        /// types are not bindings. Empty for an item that is not a function, for
        /// a function with no parameters and for a function the index reads from
        /// a declaration with no body.
        ///
        /// The names are read during the budgeted parse, so no caller re-parses
        /// the signature.
        #[must_use]
        pub fn parameter_bindings(&self) -> &[String] {
            self.detail
                .as_deref()
                .map_or(&[], |detail| detail.bindings.as_slice())
        }
    
        /// The byte range, in the text of the item's file, of the value of a
        /// constant, an associated constant or a static: after the `=` and before
        /// the `;`, never the type and never an attribute. `None` for an item that
        /// has no such value, such as a trait's required constant or a function.
        #[must_use]
        pub fn initializer(&self) -> Option<Range<usize>> {
            self.detail
                .as_deref()
                .and_then(|detail| detail.initializer.clone())
        }
    
        /// The identity of the source item: its file and the byte offset where its
        /// span starts. A crate root spans a whole file and can share this key with
        /// its first written item; workspace source-group accessors exclude roots.
        #[must_use]
        pub fn source_key(&self) -> (&RelPath, usize) {
            (&self.file, self.span.start_byte)
        }
    }

            assert_eq!(text, "demo::go".to_owned());
