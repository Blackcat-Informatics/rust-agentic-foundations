section docs/capabilities/workplan-document-model.md
    Explanation
    
    The pattern this model removes is the reader who has to apply amendments in their
    head: the parser behaves as one decision says, except for a second decision, with an
    error-handling adjustment from a third. The current documentation instead states the
    complete contract that applies, and the historical sequence stays in Git, where
    reading it is a deliberate investigation.
    
    Each capability gets a permanent home because the work items that create or change it
    are execution concerns, and the capability has a continuing identity. The roadmap
    follows from the states: a considered or designed capability is upcoming work, an
    implementing capability with unresolved bindings shows its gap, and a delivered one
    is in the catalogue. A completed requirements document does not remain beside a
    second, partly updated description of what was built.
    
    Design begins in the shape of the eventual documentation. If the first design were
    written as a proposal for approval, turning it into documentation would be a second
    writing project, and that project is easy to neglect. With seven fixed sections from
    the first draft, uncertainty is marked and resolved in place. Promotion to
    `delivered` requires reconciliation, not just a status edit: the implementation may
    have changed the API, a guarantee may have proved impractical, and an attractive
    option may have been dropped. Those outcomes are written into the current text before
    the state moves. Design material maps to outcomes in the same way: a stated need
    becomes a documented guarantee with linked tests, an open question becomes an
    explicit contract with a short explanation of the choice, a sketched API becomes a
    real reference with a compiling example, and a possibility that was not pursued
    becomes either a stated limitation or a claim with the outcome `dropped` or
    `moved:change:<slug>`. A claim is never left open as an outcome. Normal links between current topics
    remain useful: the reader follows the structure of the system and not its
    chronology.
    
    The graph keeps intention, implementation and documentation aligned in both
    directions. It follows the discipline of the GMEOW
    [Grounding Contract](https://github.com/Blackcat-Informatics/gmeow-ontology/blob/a631f73e6e39b4493d295bcd83b4deec80637f54/docs/GROUNDING.md):
    a design promise needs an accounted-for realisation, and built functionality needs
    documentation that follows it. Documentation maintenance becomes work the system can
    identify: the graph shows which sections a broken binding or a failing example
    touches, and the obligations those sections receive are defined by
    [reconcile](./workplan-reconcile.md).

    /// The checks of a repository on disk, for a test of the repository itself.
    ///
    /// A repository of one package and one delivered capability, written to a
    /// scratch directory, loads with complete bindings and prose. After synchronizing
    /// the capability, its one finding is the unwritten catalogue; writing that
    /// catalogue supplies the passing neighbor:
    ///
    /// ```rust
    /// use std::fs;
    ///
    /// use raf_source::RelPath;
    /// use raf_workplan::{Gate, SyncOptions, Workplan};
    ///
    /// let scratch = purrdf_testkit::TempDir::new_in(std::env::temp_dir())?;
    /// let dir = scratch.path();
    /// let sections: String = ["Purpose", "Contract", "Usage", "Examples", "Constraints", "Explanation", "Verification"]
    ///     .iter()
    ///     .map(|name| {
    ///         let detail = match *name {
    ///             "Contract" => "<!-- raf:tested-by demo::tests::it_runs -->\n",
    ///             "Usage" => "Call `demo::run` to exercise its runnable documentation example.\n",
    ///             "Constraints" => "<!-- raf:tested-by demo::tests::it_runs -->\n\n- This demonstration records no persistent application data.\n<!-- raf:tested-by demo::tests::it_runs -->\n",
    ///             "Verification" => "<!-- raf:generated:verification-matrix -->\n<!-- raf:generated:end -->\n",
    ///             _ => "",
    ///         };
    ///         let lead = if *name == "Contract" { "**Running.** " } else { "" };
    ///         format!("## {name}\n\n{lead}The demo function returns successfully without arguments or persistent changes; its executable checks exercise the same behavior through a small standalone library.\n{detail}\n")
    ///     })
    ///     .collect();
    /// let capability = format!(
    ///     "---\ntype: Capability\nid: cap:demo\ntitle: \"Demo\"\ndescription: \"One line.\"\n\
    ///      state: delivered\n\
    ///      bindings:\n  code: [demo::run]\n  tests: [demo::tests::it_runs]\n  examples: [demo::run]\n\
    ///      depends: []\n---\n\n# Demo\n\n{sections}"
    /// );
    /// let files = [
    ///     ("Cargo.toml", "[package]\nname = \"demo\"\nversion = \"0.1.0\"\n".to_string()),
    ///     ("src/lib.rs", "/// Runs without persistent changes.\n/// ```\n/// demo::run();\n/// ```\npub fn run() {}\n\n#[cfg(test)]\nmod tests {\n    #[test]\n    fn it_runs() {\n        super::run();\n    }\n}\n".to_string()),
    ///     ("docs/capabilities/demo.md", capability),
    ///     ("work/coverage/default.md", "---\ntype: Coverage\nid: coverage:default\nscope: [demo]\nexclusions: []\n---\n".to_string()),
    /// ];
    /// for (path, text) in files {
    ///     let file = dir.join(path);
    ///     fs::create_dir_all(file.parent().expect("a file has a directory"))?;
    ///     fs::write(file, text)?;
    /// }
    ///
    /// let gate = Gate::workspace(&dir).tracked_paths([]);
    /// let opened = gate.open()?;
    /// let synced = opened.workplan().sync(&SyncOptions::new("2026 Example", "CC-BY-4.0"))?;
    /// for (path, text) in &synced.edits {
    ///     if path.as_str() == "docs/capabilities/demo.md" {
    ///         fs::write(dir.join(path.as_str()), text)?;
    ///     }
    /// }
    /// let findings = gate.try_check()?;
    /// let kinds: Vec<&str> = findings.iter().map(|finding| finding.kind).collect();
    /// assert_eq!(kinds, ["index-missing"]);
    /// assert_eq!(findings[0].file, "docs/capabilities/index.md");
    /// Workplan::write(&synced, &dir)?;
    /// let tracked = ["docs/capabilities/demo.md", "docs/capabilities/index.md"]
    ///     .into_iter().map(RelPath::new).collect::<Result<Vec<_>, _>>()?;
    /// let clean = Gate::workspace(&dir)
    ///     .tracked_paths(tracked)
    ///     .try_check()?;
    /// assert!(clean.is_empty(), "{clean:?}");
    /// # Ok::<(), Box<dyn std::error::Error>>(())
    /// ```
    ///
    /// [`Gate::workspace`] names the directory. The gate reads `docs/capabilities`,
    /// `docs/architecture` and `work/changes` below it, and the records of
    /// `work/evidence`, `work/assessments`, `work/coverage` and `work/debt`, loads the source
    /// [`Workspace`] with the roots `["."]` (change them with
    /// [`Gate::source_roots`]), and runs [`Workplan::check`].
    ///
    /// A repository with no `docs/capabilities` directory, or with a directory
    /// that holds no capability document, is an error and not a clean verdict: a
    /// gate pointed at the wrong directory must not pass. A missing `work/changes`
    /// is the empty set of changes.
    ///
    /// Links are judged against the tracked paths of the checkout. They are taken
    /// from `git ls-files` when the directory is inside a git work tree. If `git`
    /// cannot run, fails for another reason, is told by `GIT_DIR` or
    /// `GIT_WORK_TREE` about a repository it cannot use, or cannot list the index,
    /// the gate is an error ([`GateError::Tracked`]).
    ///
    /// There is one fallback, taken only when `git` itself answers that the
    /// directory is not inside a git work tree, as for a copy of the files without
    /// `.git` such as the snapshot of a commit hook. Then every file under the
    /// directory stands for a tracked path (see [`LinkContext::of_tree`]). That
    /// weakens the rule that a link to an untracked file is broken, since a file
    /// that is on disk and untracked then passes. [`Gate::tracked_paths`] replaces
    /// both with a list the caller owns. A path that is a symlink on disk is a
    /// tracked symlink, and a link to it is `link-symlink`.
    ///
    /// Every opened workplan judges the complete coverage, prose, claims and
    /// debt policy. There is no caller-selected policy floor.
    #[derive(Debug, Clone)]
    pub struct Gate {
        dir: PathBuf,
        roots: Vec<String>,
        tracked: Option<Vec<RelPath>>,
        programs: Option<Programs>,
        record: RecordOptions,
    }

    /// The sections that hold a link to a section, sorted and without repeats.
        /// A link whose target is a document as a whole is not a link to one of
        /// its sections, and a link written outside every section has no source
        /// section.
        #[must_use]
        pub fn linking_sections(&self, section: &SectionId) -> Vec<SectionId> {
            let found: BTreeSet<&SectionId> = self
                .links
                .iter()
                .filter(|edge| matches!(&edge.to, LinkEnd::Section(target) if target == section))
                .filter_map(|edge| match &edge.from {
                    LinkEnd::Section(source) => Some(source),
                    _ => None,
                })
                .collect();
            found.into_iter().cloned().collect()
        }

symbol raf_workplan::LinkContext (bound by the capability; the section names no bound symbol by a path)
  in crates/raf-workplan/src/links.rs
    /// The oracle the link rules judge links against.
    ///
    /// A relative link must lead to a path in the set of tracked paths or to a
    /// directory that holds one, and not to a tracked symlink. A link with an
    /// anchor to a Markdown file must name a heading of that file, which is read
    /// through the tree the context was built with; a tracked Markdown file the
    /// tree cannot give is reported, not skipped.
    ///
    /// [`LinkContext::new`] takes the tracked paths from the caller, typically
    /// the list of the version-control index. [`LinkContext::of_tree`] takes every
    /// file the tree lists. For a memory tree and a small fixture that is the
    /// tracked set. For a disk tree it also includes untracked and ignored files,
    /// build output and the `.git` directory, so a link to a file that is not
    /// tracked passes: a caller that checks a working copy passes its tracked list
    /// to [`LinkContext::new`].
    ///
    /// A context caches the Markdown files it reads and walks the tree at most
    /// once, with interior mutability that is not thread-safe, so it is neither
    /// `Send` nor `Sync`; use one on one thread.
    ///
    /// ```rust
    /// use std::collections::BTreeSet;
    /// use raf_source::{MemoryTree, RelPath};
    /// use raf_workplan::{LinkContext, plain};
    ///
    /// let tree = MemoryTree::from([("README.md", "# Readme\n"), ("NOTES.md", "[a](README.md#readme)\n")]);
    /// let tracked = BTreeSet::from([RelPath::new("README.md")?, RelPath::new("NOTES.md")?]);
    /// let context = LinkContext::new(&tree, tracked);
    /// assert!(plain::check("NOTES.md", "[a](README.md#readme)\n", &context).is_empty());
    /// assert_eq!(plain::check("NOTES.md", "[a](gone.md)\n", &context)[0].kind, "link-broken");
    /// # Ok::<(), Box<dyn std::error::Error>>(())
    /// ```
    pub struct LinkContext<'t> {
        tree: &'t dyn Tree,
        universe: OnceCell<Universe>,
        /// Tracked symlinks the caller named on top of the universe.
        symlinks: BTreeSet<String>,
        bodies: RefCell<BTreeMap<String, Option<Rc<Body>>>>,
    }

    //! The digest of a record input: the SHA-256 of a canonical encoding of the
    //! text the input names.
    //!
    //! An evidence record and an assessment keep one digest for each input they
    //! were made against, and an input whose digest now differs has moved. The
    //! three inputs are an authored section ([`Digest::section`]), the source
    //! text of a symbol ([`Digest::symbol`]) and the text of a record
    //! ([`Digest::record`]).
    //!
    //! The hashed bytes are one or more fields, each written as
    //!
    //! ```text
    //! <kind> NUL <name> NUL <length> NUL <bytes>
    //! ```
    //!
    //! where `kind` is `section`, `symbol` or `record`, `name` names the input
    //! (the section slug, the symbol path, or nothing for a record), `length` is
    //! the number of bytes in decimal ASCII and `bytes` is the text. The kind
    //! separates the domains, so a section and a symbol with the same text have
    //! different digests, and the length ends each field. The kind and the name
    //! end at their NUL, and no kind or name holds one (a kind is one of the
    //! three words, a name is a section slug, a resolved symbol path or empty), so
    //! no two different sequences of fields encode to the same bytes. Every text
    //! has its CRLF line endings replaced by LF exactly once, in one pass, before
    //! it is hashed, so a checkout that converts line endings does not move a
    //! digest; a lone CR is text and is kept, so `x\r\r\ny` is hashed with one CR
    //! left before its LF and differs from both `x\r\ny` and `x\ny`. The
    //! digest is a pure function of the text: equal on every run and every
    //! platform.
    //!
    //! SHA-256 uses the same streaming implementation as `PurRDF`; its public
    //! content-store API supplies one-shot hashing, not a streaming state. The digest detects change; it is not a secret, and its
    //! comparison is not constant-time.

    /// The SHA-256 digest of a record input, written as 64 lowercase hexadecimal
    /// digits.
    ///
    /// ```rust
    /// use raf_workplan::digest::Digest;
    ///
    /// let digest = Digest::record("---\ntype: Coverage\n---\n");
    /// let text = digest.to_string();
    /// assert_eq!(text.len(), 64);
    /// assert_eq!(text.parse::<Digest>()?, digest);
    /// // CRLF line endings are read as LF.
    /// assert_eq!(Digest::record("---\r\ntype: Coverage\r\n---\r\n"), digest);
    /// # Ok::<(), raf_workplan::digest::ParseDigestError>(())
    /// ```
    #[derive(Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash)]
    pub struct Digest([u8; 32]);
    
    impl Digest {
        /// The digest of the authored text of the section `section` of `body`,
        /// or `None` when the body has no such section.
        ///
        /// The text is the one [`section_digest`] keeps: the heading and the
        /// content of the section, with the content of each generated block left
        /// out and CRLF read as LF (the one pass of the module), so syncing a
        /// generated block does not move the digest and an edit of the prose
        /// does. The field is `section NUL <section slug> NUL <length> NUL <text>`.
        #[must_use]
        pub fn section(body: &Body, section: CapabilitySection) -> Option<Self> {
            // `section_digest` has replaced CRLF already; the text is hashed as it is.
            let authored = section_digest(body, section)?;
            let mut hasher = Sha256::new();
            field(&mut hasher, "section", section.slug(), authored.text());
            Some(Self(hasher.finalize().into()))
        }
    
        /// The digest of the source text of the symbol `path`, resolved through
        /// `source` as a binding is.
        ///
        /// The text of a definition is its whole span in its file, attributes and
        /// documentation included, with CRLF read as LF. A path with more than one
        /// definition (`#[cfg(unix)] fn a()` beside `#[cfg(windows)] fn a()`)
        /// hashes each once, in the order of file and position; a definition the
        /// index reaches under several module paths, because its file is read by
        /// more than one target, has one source key and counts once. Each
        /// definition is the field `symbol NUL <path> NUL <length> NUL <text>`.
        ///
        /// A module stands for its whole content, as it does in coverage: after
        /// the field of its own span (an inline module's braces, or the
        /// declaration `mod name;`), each file of the module and of the modules
        /// below it in the same target is one more field with the file's whole
        /// text, the fields in the order of file and position. Editing any item inside a bound
        /// module, in its own file or in a child module's file, moves the digest;
        /// editing a sibling module does not. A crate root stands for nothing
        /// below it, so only its own span is hashed.
        ///
        /// ```rust
        /// use raf_source::{MemoryTree, Workspace};
        /// use raf_workplan::digest::Digest;
        ///
        /// let load = |lib: &str| {
        ///     Workspace::load(
        ///         &MemoryTree::from([
        ///             ("Cargo.toml", "[package]\nname = \"demo\"\nversion = \"0.1.0\"\n"),
        ///             ("src/lib.rs", lib),
        ///         ]),
        ///         &["."],
        ///     )
        /// };
        /// let before = load("pub fn other() {}\npub fn run() {}\n")?;
        /// let after = load("pub fn other() { let _ = 1; }\npub fn run() {}\n")?;
        /// // Editing another item leaves the digest of `run` as it was.
        /// assert_eq!(Digest::symbol(&before, "demo::run")?, Digest::symbol(&after, "demo::run")?);
        /// assert_ne!(Digest::symbol(&before, "demo::other")?, Digest::symbol(&after, "demo::other")?);
        /// # Ok::<(), Box<dyn std::error::Error>>(())
        /// ```
        ///
        /// # Errors
        ///
        /// [`SymbolDigestError::Resolve`] when the path does not resolve to one
        /// symbol, and [`SymbolDigestError::Source`] when the index holds no text
        /// for a definition's span.
        pub fn symbol(source: &Workspace, path: &str) -> Result<Self, SymbolDigestError> {
            let sites = symbol_sites(source, path)?;
            Ok(symbol_of(path, sites))
        }
    
        /// The digest of the text of a record file, with CRLF read as LF: the
        /// field `record NUL NUL <length> NUL <text>`.
        #[must_use]
        pub fn record(text: &str) -> Self {
            let mut hasher = Sha256::new();
            field(&mut hasher, "record", "", &lf(text));
            Self(hasher.finalize().into())
        }
    
        /// The 32 bytes of the digest.
        #[must_use]
        pub fn bytes(&self) -> &[u8; 32] {
            &self.0
        }
    }
    
    impl fmt::Display for Digest {
        /// The 64 lowercase hexadecimal digits, the form a record stores.
        fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
            fmt::Display::fmt(&purrdf_hash::hex::Lower(&self.0), f)
        }
    }
    
    impl fmt::Debug for Digest {
        fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
            write!(f, "Digest({self})")

    }
    
    impl FromStr for Digest {
        type Err = ParseDigestError;

        fn from_str(text: &str) -> Result<Self, Self::Err> {

    /// Why a symbol has no digest.
    #[derive(Debug, Clone, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum SymbolDigestError {

        Resolve {
            /// The path as given.
            path: String,
            /// What the source index said.

    /// A text of a symbol: its key (file, start offset, and whether it is a whole
    /// file of a module rather than an item's span) and the text.
    type Site<'w> = ((&'w str, usize, bool), &'w str);
    
    /// The definitions of the symbol `path`, each with its source key (file and
    /// start offset) and its source text, in no particular order and possibly
    /// with a definition listed twice; [`symbol_of`] and [`symbol_texts`] order
    /// and de-duplicate them.
    fn symbol_sites<'w>(source: &'w Workspace, path: &str) -> Result<Vec<Site<'w>>, SymbolDigestError> {
        let resolution = source
            .resolve(path)
            .map_err(|error| SymbolDigestError::Resolve {
                path: path.to_string(),
                error,
            })?;
        let mut sites = Vec::new();
        for id in resolution.sites {
            let missing = || SymbolDigestError::Source {
                path: path.to_string(),
            };
            let item = source.item(id).ok_or_else(missing)?;
            let text = source
                .source(&item.file)
                .and_then(|text| text.get(item.span.start_byte..item.span.end_byte))
                .ok_or_else(missing)?;
            let (file, start) = item.source_key();
            sites.push(((file.as_str(), start, false), text));
            if item.kind == SymbolKind::Mod {
                sites.extend(
                    module_files(source, item)
                        .into_iter()
                        .map(|(file, text)| ((file, 0, true), text)),
                );
            }
        }
        Ok(sites)
    }
    
    /// The path and the whole text of each file of the module `module` and of
    /// the modules below it, in the module's target, in the order of the files
    /// of the index: the content a module binding stands for. A crate root
    /// stands for nothing below it, as in coverage, so it has no file here and
    /// only its own span is hashed. The history of a module binding reads the
    /// log of each of these files.
    pub(crate) fn module_files<'w>(source: &'w Workspace, module: &Item) -> Vec<(&'w str, &'w str)> {
        let is_root = source
            .target(module.target)
            .is_some_and(|target| *module.path == *target.crate_path);
        if is_root {
            return Vec::new();
        }
        let below = format!("{}::", module.path);
        source
            .files()
            .filter(|file| {
                file.reached.iter().any(|reach| {
                    reach.target == module.target
                        && (*reach.module_path == *module.path || reach.module_path.starts_with(&below))
                })
            })
            .map(|file| (file.path.as_str(), file.text.as_str()))
            .collect()
    }
    
    /// The source text of each definition of the symbol `path`, as
    /// [`Digest::symbol`] hashes it: once per source key, in key order, with CRLF
    /// read as LF. Each entry is the file and the text.
    pub(crate) fn symbol_texts(
        source: &Workspace,
        path: &str,
    ) -> Result<Vec<(String, String)>, SymbolDigestError> {
        let mut sites = symbol_sites(source, path)?;
        sites.sort_by(|a, b| a.0.cmp(&b.0));
        sites.dedup_by(|a, b| a.0 == b.0);
        Ok(sites
            .into_iter()
            .map(|((file, _, _), text)| (file.to_string(), lf(text)))
            .collect())
    }
    
    /// The digest of the symbol `path` from the texts of its definitions, each
    /// with its source key (file and start offset): one field per source key, in
    /// key order, so a definition listed twice counts once.
    fn symbol_of(path: &str, mut sites: Vec<Site<'_>>) -> Digest {
        sites.sort_by(|a, b| a.0.cmp(&b.0));
        sites.dedup_by(|a, b| a.0 == b.0);
        let mut hasher = Sha256::new();
        for (_, text) in sites {
            field(&mut hasher, "symbol", path, &lf(text));
        }
        Digest(hasher.finalize().into())
    }
    
    /// `text` with each CRLF replaced by LF, in one pass.
    fn lf(text: &str) -> String {
        text.replace("\r\n", "\n")
    }
    
    /// Feed one field `kind NUL name NUL length NUL text` to `hasher`. The text
    /// is hashed as given: the callers have replaced its CRLF line endings once.
    fn field(hasher: &mut Sha256, kind: &str, name: &str, text: &str) {
        hasher.update(kind.as_bytes());
        hasher.update([0]);
        hasher.update(name.as_bytes());
        hasher.update([0]);
        hasher.update(text.len().to_string().as_bytes());
        hasher.update([0]);
        hasher.update(text.as_bytes());
    }

        /// The padding boundaries: 55 bytes fit one block, 56 need two, and a
        /// message fed in pieces hashes as it does whole.
        #[test]
        fn sha256_is_the_same_over_block_boundaries_and_pieces() {
            let message: Vec<u8> = (0..=255_u8).cycle().take(1000).collect();
            for length in [0, 1, 55, 56, 63, 64, 65, 119, 120, 128, 1000] {
                let whole = sha256(&message[..length]);
                for piece in [1, 3, 64, 100] {
                    let mut hasher = Sha256::new();
                    for chunk in message[..length].chunks(piece) {
                        hasher.update(chunk);
                    }
                    assert_eq!(
                        hex(&hasher.finalize()),
                        whole,
                        "{length} in pieces of {piece}"
                    );
                }
            }
            // 56 bytes leave no room for the length, so the padding takes a
            // second block (checked against `sha256sum`).
            assert_eq!(

            );

    /// The tracked paths of the work tree the runner's directory is in, relative
    /// to that directory, as `git ls-files -z` lists them.
    ///
    /// `None` is returned in exactly one case: `git` runs and answers that the
    /// directory is not inside a git work tree (it is outside any repository, or
    /// inside a `.git` directory). Every other failure is an error: `git` cannot
    /// run, `git` fails for another reason, `GIT_DIR` or `GIT_WORK_TREE` names a
    /// repository that cannot be used, `git ls-files` fails inside a work tree, or
    /// a path is not UTF-8 or not a relative path.
    ///
    /// # Errors
    ///
    /// A [`GitError`]: [`GitError::Exec`], [`GitError::Environment`],
    /// [`GitError::Answer`], [`GitError::Failed`], [`GitError::NotUtf8`] or
    /// [`GitError::NotAPath`].
    pub fn tracked_paths(runner: &dyn Runner) -> Result<Option<Vec<RelPath>>, GitError> {
        let inside = Invocation::git_inside_work_tree();
        let answer = query(runner, &inside)?;
        if answer.success() {
            match answer.stdout.trim_ascii() {
                b"true" => {}
                b"false" => return Ok(None),
                other => {
                    return Err(GitError::Answer {
                        command: inside.to_string(),
                        expected: "`true` or `false`",
                        answer: shown(&String::from_utf8_lossy(other)),
                    });
                }
            }
        } else {
            let message = answer.stderr_text();
            let environment = ["GIT_DIR", "GIT_WORK_TREE"]
                .into_iter()
                .find(|name| std::env::var_os(name).is_some());
            return match environment {
                Some(name) => Err(GitError::Environment { name, message }),
                None if message.contains("not a git repository") => Ok(None),
                None => Err(failed(&inside, &answer)),
            };
        }
        let list = Invocation::git_ls_files();
        let output = query(runner, &list)?;
        if !output.success() {
            return Err(failed(&list, &output));
        }
        let mut paths = Vec::new();
        for name in output
            .stdout
            .split(|byte| *byte == 0)
            .filter(|name| !name.is_empty())
        {
            let text = std::str::from_utf8(name).map_err(|error| GitError::NotUtf8 {
                reason: error.to_string(),
            })?;
            paths.push(RelPath::new(text).map_err(|error| GitError::NotAPath {
                path: text.to_string(),
                reason: error.to_string(),
            })?);
        }
        Ok(Some(paths))
    }

        /// The id of the capability.

    /// A tested-by edge: a statement of a capability mapped by a tested-by

    /// What an input of a record leads to.
    #[derive(Debug, Clone, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum InputTarget {

    /// The kinds of edge of the graph.
    #[derive(Debug, Clone, Copy, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum EdgeKind {
        /// A capability bound to a source path.
        Binding,
        /// A capability depends on a capability.
        Depends,
        /// A change affects a section of a capability.
        Affects,
        /// A change delivers a capability.
        Changes,
        /// A Markdown link.
        Link,
        /// An evidence record covers a capability.
        Covers,
        /// A statement of a capability rests on an evidence record.
        Claim,
        /// A statement of a capability is shown by a test or example it binds.
        TestedBy,
        /// An assessment assesses a section of a capability.
        Assesses,
        /// The coverage record enforces the coverage of a crate.
        Scope,
        /// A record was made against an input: a section, a symbol or an
        /// evidence record.
        Input,
    }
    
    impl EdgeKind {
        /// Every kind of edge.
        pub const ALL: [Self; 11] = [
            Self::Binding,
            Self::Depends,
            Self::Affects,
            Self::Changes,
            Self::Link,
            Self::Covers,
            Self::Claim,
            Self::TestedBy,
            Self::Assesses,
            Self::Scope,
            Self::Input,
        ];
    }
    
    /// An edge of the graph.
    #[derive(Debug, Clone, PartialEq, Eq)]
    #[non_exhaustive]
    pub enum Edge {
        /// A binding.
        Binding(Binding),
        /// A `depends` edge.
        Depends(DependsEdge),
        /// An `affects` edge.
        Affects(AffectsEdge),
        /// A `changes` edge.
        Changes(ChangesEdge),
        /// A link edge.
        Link(LinkEdge),
        /// A `for` edge of an evidence record.
        Covers(CoversEdge),
        /// A claim.
        Claim(ClaimEdge),
        /// A tested-by edge.
        TestedBy(TestedByEdge),
        /// The subject of an assessment.
        Assesses(AssessesEdge),
        /// A `scope` edge of the coverage record.
        Scope(ScopeEdge),
        /// An input of a record.
        Input(InputEdge),
    }
    
    impl Edge {
        /// The kind of the edge.
        #[must_use]
        pub fn kind(&self) -> EdgeKind {
            match self {
                Self::Binding(_) => EdgeKind::Binding,
                Self::Depends(_) => EdgeKind::Depends,
                Self::Affects(_) => EdgeKind::Affects,
                Self::Changes(_) => EdgeKind::Changes,
                Self::Link(_) => EdgeKind::Link,
                Self::Covers(_) => EdgeKind::Covers,
                Self::Claim(_) => EdgeKind::Claim,
                Self::TestedBy(_) => EdgeKind::TestedBy,
                Self::Assesses(_) => EdgeKind::Assesses,
                Self::Scope(_) => EdgeKind::Scope,
                Self::Input(_) => EdgeKind::Input,
            }
        }
    }
    
    /// The graph of a loaded repository. Its nodes and edges are listed by [`Graph::nodes`] and [`Graph::edges`].
    #[derive(Debug, Default)]
    pub struct Graph {
        capabilities: Vec<String>,
        changes: Vec<String>,
        architecture: Vec<String>,
        proposals: Vec<Proposal>,
        bindings: Vec<Binding>,
        depends: Vec<DependsEdge>,
        affects: Vec<AffectsEdge>,
        changes_edges: Vec<ChangesEdge>,
        links: Vec<LinkEdge>,
        evidence: Vec<String>,
        assessments: Vec<String>,
        coverage: Vec<String>,
        crates: Vec<String>,
        covers: Vec<CoversEdge>,
        claims: Vec<ClaimEdge>,
        tested_by: Vec<TestedByEdge>,
        assesses: Vec<AssessesEdge>,
        scope: Vec<ScopeEdge>,
        inputs: Vec<InputEdge>,
        /// The source path of every item a binding resolved to.
        item_paths: BTreeMap<ItemId, String>,
    }
    
    impl Graph {
        /// Every node: the capabilities, their sections, the changes, the
        /// architecture pages, the proposals, the symbols, tests and examples
        /// bound by a resolving binding, the evidence, assessment and coverage
        /// records, and the crates of the coverage scope, each group sorted.
        #[must_use]
        pub fn nodes(&self) -> Vec<Node> {
            let mut nodes: Vec<Node> = self
                .capabilities
                .iter()
                .cloned()
                .map(Node::Capability)
                .collect();
            for id in &self.capabilities {
                nodes.extend(
                    CapabilitySection::ALL
                        .into_iter()
                        .map(|section| Node::Section(SectionId::new(id.clone(), section))),
                );
            }
            nodes.extend(self.changes.iter().cloned().map(Node::Change));
            nodes.extend(self.architecture.iter().cloned().map(Node::Architecture));
            nodes.extend(self.proposals.iter().cloned().map(Node::Proposal));
            let input_symbols = self.inputs.iter().flat_map(|edge| match &edge.to {
                InputTarget::Symbol(items) => items.as_slice(),
                InputTarget::Section(_) | InputTarget::Record(_) => &[],
            });
            let symbols = self.sorted_items(
                self.bound_items(BindingKind::Code)
                    .into_iter()
                    .chain(input_symbols.copied()),
            );
            nodes.extend(symbols.into_iter().map(Node::Symbol));
            for (kind, make) in [
                (BindingKind::Test, Node::Test as fn(ItemId) -> Node),
                (BindingKind::Example, Node::Example),
            ] {
                nodes.extend(self.bound_items(kind).into_iter().map(make));
            }
            nodes.extend(self.evidence.iter().cloned().map(Node::Evidence));
            nodes.extend(self.assessments.iter().cloned().map(Node::Assessment));
            nodes.extend(self.coverage.iter().cloned().map(Node::Coverage));
            nodes.extend(self.crates.iter().cloned().map(Node::Crate));
            nodes
        }
    
        /// Every edge: the bindings, then `depends`, `affects`, `changes`, links,
        /// `for`, claims, tested-by edges, assessment subjects, `scope` and the
        /// inputs, each group sorted.
        #[must_use]
        pub fn edges(&self) -> Vec<Edge> {
            let mut edges: Vec<Edge> = self.bindings.iter().cloned().map(Edge::Binding).collect();
            edges.extend(self.depends.iter().cloned().map(Edge::Depends));
            edges.extend(self.affects.iter().cloned().map(Edge::Affects));
            edges.extend(self.changes_edges.iter().cloned().map(Edge::Changes));
            edges.extend(self.links.iter().cloned().map(Edge::Link));
            edges.extend(self.covers.iter().cloned().map(Edge::Covers));
            edges.extend(self.claims.iter().cloned().map(Edge::Claim));
            edges.extend(self.tested_by.iter().cloned().map(Edge::TestedBy));
            edges.extend(self.assesses.iter().cloned().map(Edge::Assesses));
            edges.extend(self.scope.iter().cloned().map(Edge::Scope));
            edges.extend(self.inputs.iter().cloned().map(Edge::Input));
            edges
        }
    
        /// The evidence record ids, sorted.
        #[must_use]
        pub fn evidence(&self) -> &[String] {
            &self.evidence
        }
    
        /// The assessment record ids, sorted.
        #[must_use]
        pub fn assessments(&self) -> &[String] {
            &self.assessments
        }
    
        /// The id of the coverage record, when it loaded.
        #[must_use]
        pub fn coverage(&self) -> Option<&str> {
            self.coverage.first().map(String::as_str)
        }
    
        /// The `for` edges to capabilities that exist, by evidence record and
        /// then by capability.
        #[must_use]
        pub fn covers(&self) -> &[CoversEdge] {
            &self.covers
        }
    
        /// The claims that name an evidence record that loaded, by capability,
        /// line and record.
        #[must_use]
        pub fn claims(&self) -> &[ClaimEdge] {
            &self.claims
        }
    
        /// The tested-by edges, by capability, line and path.
        #[must_use]
        pub fn tested_by(&self) -> &[TestedByEdge] {
            &self.tested_by
        }
    
        /// The subjects of the assessments, to sections of capabilities that
        /// exist, by assessment.
        #[must_use]
        pub fn assesses(&self) -> &[AssessesEdge] {
            &self.assesses
        }
    
        /// The `scope` edges of the coverage record to crates of the source
        /// workspace, sorted by package name.
        #[must_use]
        pub fn scope(&self) -> &[ScopeEdge] {
            &self.scope
        }
    
        /// The input edges of the records: each input row whose section,
        /// symbol or evidence record resolves, by record, kind and name. An input
        /// that names nothing the repository holds now makes no edge and no
        /// finding: an input that moved is a matter of the record's currency, not
        /// of the load.
        #[must_use]
        pub fn inputs(&self) -> &[InputEdge] {
            &self.inputs
        }
    
        /// The input edges of the record `record`, by kind and name.
        #[must_use]
        pub fn inputs_of(&self, record: &str) -> Vec<&InputEdge> {
            self.inputs
                .iter()
                .filter(|edge| edge.record == record)
                .collect()
        }
    
        /// The evidence records whose `for` lists the capability, sorted by id.
        #[must_use]
        pub fn evidence_of(&self, capability: &str) -> Vec<&str> {
            self.covers
                .iter()
                .filter(|edge| edge.capability == capability)
                .map(|edge| edge.evidence.as_str())
                .collect()
        }
    
        /// The claims that name the evidence record `evidence`, by capability and
        /// line.
        #[must_use]
        pub fn claims_on(&self, evidence: &str) -> Vec<&ClaimEdge> {
            self.claims
                .iter()
                .filter(|edge| edge.evidence == evidence)
                .collect()
        }
    
        /// The assessments whose subject is `section`, sorted by id.
        #[must_use]
        pub fn assessments_of(&self, section: &SectionId) -> Vec<&str> {
            self.assesses
                .iter()
                .filter(|edge| &edge.section == section)
                .map(|edge| edge.assessment.as_str())
                .collect()
        }
    
        /// The capability ids, sorted.
        #[must_use]
        pub fn capabilities(&self) -> &[String] {
            &self.capabilities
        }
    
        /// The change ids, sorted.
        #[must_use]
        pub fn changes(&self) -> &[String] {
            &self.changes
        }
    
        /// The architecture page ids, sorted.
        #[must_use]
        pub fn architecture(&self) -> &[String] {
            &self.architecture
        }
    
        /// The seven sections of the capability `capability`, in document order;
        /// empty when the graph has no such capability.
        #[must_use]
        pub fn sections(&self, capability: &str) -> Vec<SectionId> {
            if self.capabilities.iter().any(|id| id == capability) {
                CapabilitySection::ALL
                    .into_iter()
                    .map(|section| SectionId::new(capability, section))
                    .collect()
            } else {
                Vec::new()
            }
        }
    
        /// The PROPOSED blocks, by capability and then by place in the document.
        #[must_use]
        pub fn proposals(&self) -> &[Proposal] {
            &self.proposals
        }
    
        /// The binding edges, by capability, then code, tests and examples, then
        /// by path.
        #[must_use]
        pub fn bindings(&self) -> &[Binding] {
            &self.bindings
        }
    
        /// The bindings of one capability, with the result of resolving each, by
        /// list (code, tests, examples) and then by path. A binding that did not
        /// resolve is here with its error, so a reader never resolves again.
        pub fn bindings_of<'a>(&'a self, capability: &'a str) -> impl Iterator<Item = &'a Binding> {
            self.bindings
                .iter()
                .filter(move |binding| binding.capability == capability)
        }
    
        /// The `depends` edges between capabilities that exist, sorted.
        #[must_use]
        pub fn depends(&self) -> &[DependsEdge] {
            &self.depends
        }
    
        /// The `affects` edges to sections of capabilities that exist, sorted.
        #[must_use]
        pub fn affects(&self) -> &[AffectsEdge] {
            &self.affects
        }
    
        /// The `changes` edges to capabilities that exist, sorted.
        #[must_use]
        pub fn changes_edges(&self) -> &[ChangesEdge] {
            &self.changes_edges
        }
    
        /// The link edges, by source, target and line.
        #[must_use]
        pub fn links(&self) -> &[LinkEdge] {
            &self.links
        }
    
        /// The items that realise a capability: what its `bindings.code` entries
        /// resolve to, sorted by source path and then by id.
        #[must_use]
        pub fn code_of(&self, capability: &str) -> Vec<ItemId> {
            let items = self
                .bindings
                .iter()
                .filter(|b| b.capability == capability && b.kind == BindingKind::Code)
                .flat_map(|b| b.items().iter().copied());
            self.sorted_items(items)
        }
    
        /// The capabilities bound to an item by any of their lists, sorted by id.
        #[must_use]
        pub fn capabilities_of(&self, symbol: ItemId) -> Vec<&str> {
            let found: BTreeSet<&str> = self
                .bindings
                .iter()
                .filter(|b| b.items().contains(&symbol))
                .map(|b| b.capability.as_str())
                .collect();
            found.into_iter().collect()
        }
    
        /// The test bindings of a capability that substantiate one of its
        /// sections, sorted by path. See [`Binding::sections`] for the rule.
        #[must_use]
        pub fn tests_for(&self, capability: &str, section: CapabilitySection) -> Vec<&Binding> {
            self.bindings
                .iter()
                .filter(|b| {
                    b.capability == capability
                        && b.kind == BindingKind::Test
                        && b.sections.contains(&section)
                })
                .collect()
        }
    
        /// The sections a change affects, sorted and without repeats.
        #[must_use]
        pub fn sections_of(&self, change: &str) -> Vec<SectionId> {
            let found: BTreeSet<&SectionId> = self
                .affects
                .iter()
                .filter(|edge| edge.change == change)
                .map(|edge| &edge.section)
                .collect();
            found.into_iter().cloned().collect()
        }
    
        /// The sections that hold a link to a section, sorted and without repeats.
        /// A link whose target is a document as a whole is not a link to one of
        /// its sections, and a link written outside every section has no source
        /// section.
        #[must_use]
        pub fn linking_sections(&self, section: &SectionId) -> Vec<SectionId> {
            let found: BTreeSet<&SectionId> = self
                .links
                .iter()
                .filter(|edge| matches!(&edge.to, LinkEnd::Section(target) if target == section))
                .filter_map(|edge| match &edge.from {
                    LinkEnd::Section(source) => Some(source),
                    _ => None,
                })
                .collect();
            found.into_iter().cloned().collect()
        }
    
        fn bound_items(&self, kind: BindingKind) -> Vec<ItemId> {
            let items = self
                .bindings
                .iter()
                .filter(|b| b.kind == kind)
                .flat_map(|b| b.items().iter().copied());
            self.sorted_items(items)
        }
    
        /// The items without repeats, by source path and then by id.
        fn sorted_items(&self, items: impl Iterator<Item = ItemId>) -> Vec<ItemId> {
            let ordered: BTreeSet<(&str, ItemId)> = items
                .map(|id| (self.item_paths.get(&id).map_or("", String::as_str), id))
                .collect();
            ordered.into_iter().map(|(_, id)| id).collect()
        }
    }
    
    /// The records of a load.
    pub(crate) struct Records<'a> {
        pub(crate) evidence: &'a [Loaded<EvidenceRecord>],
        pub(crate) assessments: &'a [Loaded<AssessmentRecord>],
        pub(crate) coverage: Option<&'a Loaded<CoverageRecord>>,
    }
    
    /// Build the graph of the loaded documents, and the findings of the rules
    /// between documents: a reference to a document or a record that does not
    /// exist, a claim on evidence that does not cover its capability, and a
    /// `depends` cycle.
    ///
    /// `present` holds the ids of the documents that exist as files, loaded or
    /// not: a reference to a document that is there but broken is reported by the
    /// findings of that document, not as a missing one.
    pub(crate) fn build(
        capabilities: &[Loaded<Capability>],
        changes: &[Loaded<Change>],
        architecture: &[Loaded<Architecture>],
        records: &Records<'_>,
        present: &BTreeSet<String>,
        source: &Workspace,
    ) -> (Graph, Vec<Finding>) {
        let mut graph = Graph::default();
        let mut findings = Vec::new();
        let mut caps: Vec<&Loaded<Capability>> = capabilities.iter().collect();
        caps.sort_by(|a, b| a.value().header.id.cmp(&b.value().header.id));
        let mut chgs: Vec<&Loaded<Change>> = changes.iter().collect();
        chgs.sort_by(|a, b| a.value().header.id.cmp(&b.value().header.id));
        graph.capabilities = caps.iter().map(|c| c.value().header.id.clone()).collect();
        graph.changes = chgs.iter().map(|c| c.value().header.id.clone()).collect();
        graph.architecture = architecture
            .iter()
            .map(|a| a.value().header.id.clone())
            .collect();
        graph.architecture.sort();
        let known: BTreeSet<String> = graph.capabilities.iter().cloned().collect();
    
        for cap in &caps {
            add_capability(&mut graph, cap, &known, present, source, &mut findings);
        }
        for change in &chgs {
            add_change(&mut graph, change, &known, present, &mut findings);
        }
        findings.extend(cycles(&caps, &graph.depends));
        graph
            .depends
            .sort_by(|a, b| (&a.from, &a.to).cmp(&(&b.from, &b.to)));
        graph.depends.dedup();
        graph.affects.sort();
        graph.affects.dedup();
        graph
            .changes_edges
            .sort_by(|a, b| (&a.change, &a.capability).cmp(&(&b.change, &b.capability)));
        graph.changes_edges.dedup();
        add_links(&mut graph, capabilities, changes, architecture);
        add_records(&mut graph, records, &known, present, source, &mut findings);
        add_claims(&mut graph, &caps, records.evidence, present, &mut findings);
        graph
            .tested_by
            .sort_by(|a, b| (&a.capability, a.line, &a.path).cmp(&(&b.capability, b.line, &b.path)));
        (graph, findings)
    }
    
    /// The record nodes, the `for`, subject and `scope` edges, and the findings
    /// for a capability or a crate a record names and that does not exist.
    fn add_records(
        graph: &mut Graph,
        records: &Records<'_>,
        known: &BTreeSet<String>,
        present: &BTreeSet<String>,
        source: &Workspace,
        findings: &mut Vec<Finding>,
    ) {
        for evidence in records.evidence {
            let id = &evidence.value().header.id;
            graph.evidence.push(id.clone());
            for capability in &evidence.value().covers {
                if known.contains(capability) {
                    graph.covers.push(CoversEdge {
                        evidence: id.clone(),
                        capability: capability.clone(),
                    });
                } else if !present.contains(capability) {
                    findings.push(Finding::new(
                        kind::EVIDENCE_FOR_MISSING,
                        evidence.path(),
                        Location::Key("for".to_string()),
                        format!("`for` names `{capability}`, which is not a capability document"),
                        "name a capability the evidence covers, or remove the entry",
                    ));
                }
            }
        }
        for assessment in records.assessments {
            let id = &assessment.value().header.id;
            graph.assessments.push(id.clone());
            let subject = &assessment.value().subject;
            findings.extend(assessment_id_mismatch(assessment));
            if known.contains(&subject.capability) {
                graph.assesses.push(AssessesEdge {
                    assessment: id.clone(),
                    section: SectionId::new(subject.capability.clone(), subject.section),
                });
            } else if !present.contains(&subject.capability) {
                findings.push(Finding::new(
                    kind::ASSESSMENT_SUBJECT_MISSING,
                    assessment.path(),
                    Location::Key("subject".to_string()),
                    format!(
                        "the subject `{}` is a section of `{}`, which is not a capability document",
                        subject.text(),
                        subject.capability
                    ),
                    "name a section of an existing capability, or remove the record",
                ));
            }
        }
        if let Some(coverage) = records.coverage {
            let id = &coverage.value().header.id;
            graph.coverage.push(id.clone());
            let packages = package_names(source);
            for package in &coverage.value().scope {
                if packages.contains(package.as_str()) {
                    graph.crates.push(package.clone());
                    graph.scope.push(ScopeEdge {
                        coverage: id.clone(),
                        package: package.clone(),
                    });
                } else {
                    // A crate name (`raf_okf`) is not the package name (`raf-okf`):
                    // say which package it is, rather than guess.
                    let crate_form = |name: &str| name.replace('-', "_");
                    let named: Vec<&str> = packages
                        .iter()
                        .copied()
                        .filter(|known| crate_form(known) == crate_form(package))
                        .collect();
                    let known = if let [only] = named.as_slice() {
                        format!(
                            "`scope` names packages by the `name` of their `[package]`, and `{package}` is the crate name of the package `{only}`"
                        )
                    } else if packages.is_empty() {
                        "the source workspace has no package".to_string()
                    } else {
                        format!(
                            "the packages are {}",
                            packages.iter().copied().collect::<Vec<_>>().join(", ")
                        )
                    };
                    findings.push(Finding::new(
                        kind::SCOPE_CRATE_MISSING,
                        coverage.path(),
                        Location::Key("scope".to_string()),
                        format!("`scope` names `{package}`, which is no package of the source workspace; {known}"),
                        "name the crate by the `name` of its `[package]`, or remove the entry",
                    ));
                }
            }
            ceilings_missing(coverage, &packages, findings);
        }
        graph.evidence.sort();
        graph.assessments.sort();
        graph.crates.sort();
        graph.crates.dedup();
        graph
            .covers
            .sort_by(|a, b| (&a.evidence, &a.capability).cmp(&(&b.evidence, &b.capability)));
        graph
            .assesses
            .sort_by(|a, b| (&a.assessment, &a.section).cmp(&(&b.assessment, &b.section)));
        graph.scope.sort_by(|a, b| a.package.cmp(&b.package));
        add_inputs(graph, records, known, source);
    }
    
    /// The names of the packages of `source`.
    fn package_names(source: &Workspace) -> BTreeSet<&str> {
        source
            .packages()
            .iter()
            .map(|package| package.name.as_str())
            .collect()
    }
    
    /// A `scope-crate-missing` finding at `ceilings` for each package a ceiling of
    /// the coverage record names that is no package of the source workspace, once
    /// for each name: a ceiling names its package as `scope` does.
    fn ceilings_missing(
        coverage: &Loaded<CoverageRecord>,
        packages: &BTreeSet<&str>,
        findings: &mut Vec<Finding>,
    ) {
        let mut named = BTreeSet::new();
        for ceiling in &coverage.value().ceilings {
            let package = ceiling.package.as_str();
            if packages.contains(package) || !named.insert(package) {
                continue;
            }
            let known = if packages.is_empty() {
                "the source workspace has no package".to_string()
            } else {
                format!(
                    "the packages are {}",
                    packages.iter().copied().collect::<Vec<_>>().join(", ")
                )
            };
            findings.push(Finding::new(
                kind::SCOPE_CRATE_MISSING,
                coverage.path(),
                Location::Key("ceilings".to_string()),
                format!(
                    "`ceilings` names `{package}`, which is no package of the source workspace; {known}"
                ),
                "name the crate by the `name` of its `[package]`, or remove the row",
            ));
        }
    }
    
    /// The `assessment-id-mismatch` finding of an assessment whose id is not the
    /// one id of its subject, `assessment:<capability slug>-<section>`.
    fn assessment_id_mismatch(assessment: &Loaded<AssessmentRecord>) -> Option<Finding> {
        let value = assessment.value();
        let subject = &value.subject;
        let wanted = crate::assessment::record_slug(&subject.capability, subject.section);
        if wanted.as_deref() == Some(value.header.slug.as_str()) {
            return None;
        }
        let wanted = wanted.map_or_else(
            || format!("`{}` is not a capability id", subject.capability),
            |slug| {
                format!(
                    "the id of an assessment of `{}` is `assessment:{slug}`",
                    subject.text()
                )
            },
        );
        Some(Finding::new(
            kind::ASSESSMENT_ID_MISMATCH,
            assessment.path(),
            Location::Key("id".to_string()),
            format!(
                "the record `{}` assesses `{}`, and {wanted}, so it is not the assessment of its subject",
                value.header.id,
                subject.text()
            ),
            "name the record after its subject, `<capability slug>-<section>`, or record the assessment again with `assess`",
        ))
    }
    
    /// The input edges of the evidence records and the assessments. The evidence
    /// ids are sorted already, so an input that names a record finds it.
    fn add_inputs(
        graph: &mut Graph,
        records: &Records<'_>,
        known: &BTreeSet<String>,
        source: &Workspace,
    ) {
        let inputs = records
            .evidence
            .iter()
            .map(|record| (&record.value().header.id, &record.value().inputs))
            .chain(
                records
                    .assessments
                    .iter()
                    .map(|record| (&record.value().header.id, &record.value().inputs)),
            );
        for (id, rows) in inputs {
            for input in rows {
                add_input(graph, id, input, known, source);
            }
        }
        graph
            .inputs
            .sort_by(|a, b| (&a.record, a.kind, &a.name).cmp(&(&b.record, b.kind, &b.name)));
    }
    
    /// The edge of one input row of the record `record`, when its name resolves:
    /// a section of a capability that exists, a symbol of the source index, or an
    /// evidence record that loaded.
    fn add_input(
        graph: &mut Graph,
        record: &str,
        input: &Input,
        known: &BTreeSet<String>,
        source: &Workspace,
    ) {
        let to = match input.kind {
            InputKind::Section => input.name.split_once('#').and_then(|(capability, slug)| {
                let section = CapabilitySection::from_slug(slug)?;
                known
                    .contains(capability)
                    .then(|| InputTarget::Section(SectionId::new(capability, section)))
            }),
            InputKind::Symbol => source.resolve(&input.name).ok().map(|found| {
                for id in &found.sites {
                    if let Some(item) = source.item(*id) {
                        graph.item_paths.insert(*id, item.path.to_string());
                    }
                }
                InputTarget::Symbol(graph.sorted_items(found.sites.into_iter()))
            }),
            InputKind::Record => graph
                .evidence
                .binary_search(&input.name)
                .is_ok()
                .then(|| InputTarget::Record(input.name.clone())),
        };
        if let Some(to) = to {
            graph.inputs.push(InputEdge {
                record: record.to_string(),
                kind: input.kind,
                name: input.name.clone(),
                to,
            });
        }
    }
    
    /// The claim edges of the capability documents, and the findings for a claim
    /// on a record that does not exist or does not cover the capability.
    fn add_claims(
        graph: &mut Graph,
        caps: &[&Loaded<Capability>],
        evidence: &[Loaded<EvidenceRecord>],
        present: &BTreeSet<String>,
        findings: &mut Vec<Finding>,
    ) {
        let loaded = Counted::new(
            Work::ClaimLookups,
            evidence
                .iter()
                .inspect(|_| add(Work::ClaimChecks, 1))
                .map(|record| record.value().header.id.as_str())
                .collect::<HashSet<&str>>(),
        );
        let covered = Counted::new(
            Work::ClaimLookups,
            evidence
                .iter()
                .flat_map(|record| {
                    record
                        .value()
                        .covers
                        .iter()
                        .map(|capability| (record.value().header.id.as_str(), capability.as_str()))
                })
                .inspect(|_| add(Work::ClaimChecks, 1))
                .collect::<HashSet<(&str, &str)>>(),
        );
        let present = Counted::new(Work::ClaimLookups, present);
        let prefix = DocType::Evidence.id_prefix();
        for cap in caps {
            let capability = cap.value().header.id.as_str();
            for claim in cap.body().claims() {
                let section = claim.section().and_then(CapabilitySection::from_slug);
                for slug in claim.evidence() {
                    add(Work::ClaimChecks, 1);
                    let id = format!("{prefix}{slug}");
                    if loaded.contains(id.as_str()) {
                        if !covered.contains(&(id.as_str(), capability)) {
                            findings.push(Finding::new(
                                kind::CLAIM_EVIDENCE_NOT_FOR,
                                cap.path(),
                                Location::Line(claim.line()),
                                format!(
                                    "the claim names `{id}`, whose `for` does not list `{capability}`"
                                ),
                                format!(
                                    "add `{capability}` to the `for` of the record, or name evidence that covers the capability"
                                ),
                            ));
                        }
                        graph.claims.push(ClaimEdge {
                            capability: capability.to_string(),
                            section,
                            evidence: id,
                            line: claim.line(),
                        });
                    } else if !present.contains(&id) {
                        findings.push(Finding::new(
                            kind::CLAIM_EVIDENCE_MISSING,
                            cap.path(),
                            Location::Line(claim.line()),
                            format!("the claim names `{id}`, which is not an evidence record"),
                            format!(
                                "record the evidence as {}/{slug}.md, or name an existing record",
                                DocType::Evidence.directory()
                            ),
                        ));
                    }
                }
            }
        }
        graph.claims.sort_by(|a, b| {
            (&a.capability, a.line, &a.evidence).cmp(&(&b.capability, b.line, &b.evidence))
        });
    }
    
    /// A document that can hold or receive a link.
    struct Doc<'a> {
        whole: LinkEnd,
        body: &'a Body,
        capability: Option<&'a str>,
    }
    
    /// The section of a capability body that holds a line.
    fn section_at(capability: &str, body: &Body, line: usize) -> Option<SectionId> {
        body.sections()
            .iter()
            .find(|s| s.line() <= line && line < s.content().lines.end)
            .and_then(|s| CapabilitySection::from_slug(s.slug()))
            .map(|section| SectionId::new(capability, section))
    }
    
    fn add_links(
        graph: &mut Graph,
        capabilities: &[Loaded<Capability>],
        changes: &[Loaded<Change>],
        architecture: &[Loaded<Architecture>],
    ) {
        let mut docs: BTreeMap<&str, Doc<'_>> = BTreeMap::new();
        for cap in capabilities {
            let id = cap.value().header.id.as_str();
            docs.insert(
                cap.path(),
                Doc {
                    whole: LinkEnd::Capability(id.to_string()),
                    body: cap.body(),
                    capability: Some(id),
                },
            );
        }
        for change in changes {
            docs.insert(
                change.path(),
                Doc {
                    whole: LinkEnd::Change(change.value().header.id.clone()),
                    body: change.body(),
                    capability: None,
                },
            );
        }
        for page in architecture {
            docs.insert(
                page.path(),
                Doc {
                    whole: LinkEnd::Architecture(page.value().header.id.clone()),
                    body: page.body(),
                    capability: None,
                },
            );
        }
        let mut links = Vec::new();
        for (path, doc) in &docs {
            for link in doc.body.links() {
                let (target_path, anchor) = match link.target_in(path) {
                    Ok(LinkTarget::Fragment(anchor)) => (*path, Some(anchor)),
                    Ok(LinkTarget::Relative { path, anchor }) => {
                        match docs.get_key_value(path.as_str()) {
                            Some((key, _)) => (*key, anchor),
                            None => continue,
                        }
                    }
                    // An external link, or a target that is not a path.
                    Ok(_) | Err(_) => continue,
                };
                let target = &docs[target_path];
                let to = match (anchor, target.capability) {
                    (Some(anchor), _) if !target.body.has_anchor(&anchor) => continue,
                    (Some(anchor), Some(id)) => target
                        .body
                        .headings()
                        .iter()
                        .find(|h| h.anchor() == anchor)
                        .and_then(|h| section_at(id, target.body, h.line()))
                        .map_or_else(|| target.whole.clone(), LinkEnd::Section),
                    (None, _) | (Some(_), None) => target.whole.clone(),
                };
                let from = doc
                    .capability
                    .and_then(|id| section_at(id, doc.body, link.line()))
                    .map_or_else(|| doc.whole.clone(), LinkEnd::Section);
                links.push(LinkEdge {
                    from,
                    to,
                    line: link.line(),
                });
            }
        }
        links.sort_by(|a, b| {
            (a.from.sort_key(), a.to.sort_key(), a.line).cmp(&(
                b.from.sort_key(),
                b.to.sort_key(),
                b.line,
            ))
        });
        links.dedup();
        graph.links = links;
    }
    
    fn add_capability(
        graph: &mut Graph,
        cap: &Loaded<Capability>,
        known: &BTreeSet<String>,
        present: &BTreeSet<String>,
        source: &Workspace,
        findings: &mut Vec<Finding>,
    ) {
        let id = &cap.value().header.id;
        for (index, block) in cap.body().proposed_blocks().iter().enumerate() {
            graph.proposals.push(Proposal {
                capability: id.clone(),
                change: block.slug().to_string(),
                section: block.section().and_then(CapabilitySection::from_slug),
                ordinal: index,
            });
        }
        for target in &cap.value().depends {
            if known.contains(target) {
                graph.depends.push(DependsEdge {
                    from: id.clone(),
                    to: target.clone(),
                });
            } else if !present.contains(target) {
                findings.push(Finding::new(
                    kind::DEPENDS_MISSING,
                    cap.path(),
                    Location::Key("depends".to_string()),
                    format!("`depends` names `{target}`, which is not a capability document"),
                    "name an existing capability, or remove the entry",
                ));
            }
        }
        let lists = [
            (BindingKind::Code, &cap.value().bindings.code),
            (BindingKind::Test, &cap.value().bindings.tests),
            (BindingKind::Example, &cap.value().bindings.examples),
        ];
        let mut bindings = Vec::new();
        for (kind, paths) in lists {
            for path in paths {
                bindings.push(bind(id, kind, path, cap.body(), source, graph));
            }
        }
        bindings.sort_by(|a, b| (a.kind, &a.path).cmp(&(b.kind, &b.path)));
        graph.bindings.extend(bindings);
        add_tested_by(graph, cap, findings);
    }
    
    /// The tested-by edges of one capability, and `claim-test-unbound` for each
    /// path of a marker that is no path of its `tests` or `examples` bindings.
    fn add_tested_by(graph: &mut Graph, cap: &Loaded<Capability>, findings: &mut Vec<Finding>) {
        let id = &cap.value().header.id;
        let bindings = &cap.value().bindings;
        for marker in cap.body().tested_by() {
            let section = marker.section().and_then(CapabilitySection::from_slug);
            for path in marker.paths() {
                if bindings.tests.contains(path) || bindings.examples.contains(path) {
                    graph.tested_by.push(TestedByEdge {
                        capability: id.clone(),
                        section,
                        path: path.clone(),
                        line: marker.line(),
                    });
                } else {
                    findings.push(Finding::new(
                        kind::CLAIM_TEST_UNBOUND,
                        cap.path(),
                        Location::Line(marker.line()),
                        format!(
                            "the tested-by marker names `{path}`, which is no path of the `tests` or `examples` bindings of `{id}`"
                        ),
                        "name a path of the capability's `bindings.tests` or `bindings.examples`, or bind the test there first",
                    ));
                }
            }
        }
    }
    
    fn bind(
        capability: &str,
        kind: BindingKind,
        path: &str,
        body: &Body,
        source: &Workspace,
        graph: &mut Graph,
    ) -> Binding {
        let resolution = source.resolve(path).map(|found| {
            let mut sites = found.sites;
            for id in &sites {
                if let Some(item) = source.item(*id) {
                    graph.item_paths.insert(*id, item.path.to_string());
                }
            }
            sites.sort_by(|a, b| {
                let name = |id: &ItemId| graph.item_paths.get(id).cloned().unwrap_or_default();
                (name(a), *a).cmp(&(name(b), *b))
            });
            sites.dedup();
            sites
        });
        let examples = match (&resolution, kind) {
            (Ok(sites), BindingKind::Example) => sites
                .iter()
                .filter_map(|id| {
                    let item = source.item(*id)?;
                    Some((*id, bindings::example_kind(source, item)?))
                })
                .collect(),
            _ => Vec::new(),
        };
        let sections = match kind {
            BindingKind::Code => Vec::new(),
            BindingKind::Test | BindingKind::Example => substantiated(body, path),
        };
        Binding {
            capability: capability.to_string(),
            kind,
            path: path.to_string(),
            resolution,
            sections,
            examples,
        }
    }
    
    fn add_change(
        graph: &mut Graph,
        change: &Loaded<Change>,
        known: &BTreeSet<String>,
        present: &BTreeSet<String>,
        findings: &mut Vec<Finding>,
    ) {
        let value = change.value();
        let id = &value.header.id;
        for target in &value.changes {
            if known.contains(target) {
                graph.changes_edges.push(ChangesEdge {
                    change: id.clone(),
                    capability: target.clone(),
                });
            } else if !present.contains(target) {
                findings.push(Finding::new(
                    kind::CHANGES_MISSING,
                    change.path(),
                    Location::Key("changes".to_string()),
                    format!("`changes` names `{target}`, which is not a capability document"),
                    "name an existing capability, or remove the entry",
                ));
            }
        }
        for entry in &value.affects {
            if known.contains(&entry.capability) {
                graph.affects.push(AffectsEdge {
                    change: id.clone(),
                    section: SectionId::new(entry.capability.clone(), entry.section),
                });
            }
        }
        for item in &value.items {
            if let Some(Outcome::Moved(slug)) = &item.outcome {
                let target = format!("change:{slug}");
                if !present.contains(&target) {
                    findings.push(Finding::new(
                        kind::MOVED_MISSING,
                        change.path(),
                        Location::Key("items".to_string()),
                        format!("an item has the outcome `moved:{target}`, but no such change record exists"),
                        "name the change record that now carries the claim, or give the item another outcome",
                    ));
                }
            }
        }
    }
    
    /// The `depends` cycles: one finding for each group of capabilities that
    /// depend on each other, named in the file of the first of them.
    fn cycles(caps: &[&Loaded<Capability>], depends: &[DependsEdge]) -> Vec<Finding> {
        let ids: Vec<&str> = caps.iter().map(|c| c.value().header.id.as_str()).collect();
        let index: BTreeMap<&str, usize> = ids.iter().enumerate().map(|(i, id)| (*id, i)).collect();
        let mut adjacent: Vec<Vec<usize>> = vec![Vec::new(); ids.len()];
        for edge in depends {
            if let (Some(&from), Some(&to)) =
                (index.get(edge.from.as_str()), index.get(edge.to.as_str()))
            {
                adjacent[from].push(to);
            }
        }
        let mut findings = Vec::new();
        for mut group in strongly_connected(&adjacent) {
            let cyclic = group.len() > 1 || adjacent[group[0]].contains(&group[0]);
            if !cyclic {
                continue;
            }
            group.sort_unstable();
            let members: Vec<&str> = group.iter().map(|i| ids[*i]).collect();
            let message = if members.len() == 1 {
                format!("`{}` depends on itself", members[0])
            } else {
                format!(
                    "the capabilities {} depend on each other",
                    members
                        .iter()
                        .map(|id| format!("`{id}`"))
                        .collect::<Vec<_>>()
                        .join(", ")
                )
            };
            findings.push(Finding::new(
                kind::DEPENDS_CYCLE,
                caps[group[0]].path(),
                Location::Key("depends".to_string()),
                message,
                "remove a `depends` entry so the capabilities form no cycle",
            ));
        }
        findings
    }
    
    /// The strongly connected components of a graph (Tarjan, without recursion),
    /// each as a list of node numbers, ordered by their smallest node.
    fn strongly_connected(adjacent: &[Vec<usize>]) -> Vec<Vec<usize>> {
        let mut groups = purrdf_core::graph::tarjan_scc(adjacent);
        for group in &mut groups {
            group.sort_unstable();
        }
        groups.sort();
        groups
    }
    
    /// The sections a test or example binding substantiates: each section other
    /// than Verification that names the path in a code span or holds a tested-by
    /// marker that names it, and Verification when there is none. A code span
    /// inside an HTML comment does not count: a comment is no text of the section.
    fn substantiated(body: &Body, path: &str) -> Vec<CapabilitySection> {
        let holding: Vec<CapabilitySection> = CapabilitySection::ALL
            .into_iter()
            .filter(|section| *section != CapabilitySection::Verification)
            .filter(|section| {
                let spanned = body
                    .sections()
                    .iter()
                    .find(|s| s.slug() == section.slug())
                    .and_then(|s| {
                        prose_of(body, s).map(|text| names_in_code_span(&without_comments(&text), path))
                    })
                    .unwrap_or(false);
                spanned || marks(body, *section, path)
            })
            .collect();
        if holding.is_empty() {
            vec![CapabilitySection::Verification]
        } else {
            holding
        }
    }
    
    /// Whether a tested-by marker in `section` names `path`.
    fn marks(body: &Body, section: CapabilitySection, path: &str) -> bool {
        body.tested_by().iter().any(|marker| {
            marker.section() == Some(section.slug()) && marker.paths().iter().any(|p| p == path)
        })
    }
    
    /// `text` with each HTML comment outside a code span removed, its line breaks
    /// kept. Code spans are read per paragraph as [`code_spans`] reads them: a run
    /// of backticks opens a span that the next run of the same length in the
    /// paragraph closes. A `<!--` that no `-->` closes runs to the end.
    fn without_comments(text: &str) -> String {
        let bytes = text.as_bytes();
        let run = |from: usize| bytes[from..].iter().take_while(|b| **b == b'`').count();
        let mut out = String::with_capacity(text.len());
        let mut at = 0;
        while at < bytes.len() {
            if bytes[at] == b'`' {
                let width = run(at);
                let mut scan = at + width;
                let mut close = None;
                while scan < bytes.len() && !bytes[scan..].starts_with(b"\n\n") {
                    if bytes[scan] == b'`' {
                        let other = run(scan);
                        if other == width {
                            close = Some(scan + width);
                            break;
                        }
                        scan += other;
                    } else {
                        scan += 1;
                    }
                }
                let end = close.unwrap_or(at + width);
                out.push_str(&text[at..end]);
                at = end;
            } else if text[at..].starts_with("<!--") {
                let body = &text[at + 4..];
                let end = body.find("-->").map_or(body.len(), |close| close + 3);
                out.extend(body[..end].chars().filter(|c| *c == '\n'));
                at += 4 + end;
            } else {
                let next = text[at..].chars().next().map_or(1, char::len_utf8);
                out.push_str(&text[at..at + next]);
                at += next;
            }
        }
        out
    }
    
    /// The text of a section with its fenced code blocks, PROPOSED blocks and
    /// generated blocks blanked out, line breaks kept. A generated block is
    /// derived from this very text, so it must not count as prose.
    ///
    /// The blocks are merged into sorted, disjoint ranges once and the text is
    /// read in one pass, so the time is linear in the text and the blocks.
    pub(crate) fn prose_of(body: &Body, section: &raf_okf::Section) -> Option<String> {
        let text = body.section_text(section)?;
        let start = section.content().bytes.start;
        let mut blanked: Vec<(usize, usize)> = body
            .fenced_blocks()
            .iter()
            .map(raf_okf::FencedBlock::span)
            .chain(
                body.proposed_blocks()
                    .iter()
                    .map(raf_okf::ProposedBlock::span),
            )
            .chain(
                body.generated_blocks()
                    .iter()
                    .map(raf_okf::GeneratedBlock::outer),
            )
            .map(|span| {
                (
                    span.bytes.start.saturating_sub(start),
                    span.bytes.end.saturating_sub(start),
                )
            })
            .filter(|(from, to)| from < to)
            .collect();
        blanked.sort_unstable();
        let mut merged: Vec<(usize, usize)> = Vec::with_capacity(blanked.len());
        for (from, to) in blanked {
            match merged.last_mut() {
                Some(last) if from <= last.1 => last.1 = last.1.max(to),
                _ => merged.push((from, to)),
            }
        }
        let mut ranges = merged.into_iter().peekable();
        Some(
            text.char_indices()
                .map(|(at, c)| {
                    add(Work::ProseChars, 1);
                    while ranges.peek().is_some_and(|(_, to)| *to <= at) {
                        ranges.next();
                        add(Work::BlankedSteps, 1);
                    }
                    let inside = ranges.peek().is_some_and(|(from, _)| *from <= at);
                    if inside && c != '\n' && c != '\r' {
                        ' '
                    } else {
                        c
                    }
                })
                .collect(),
        )
    }
    
    /// Every path a code span of `text` names as a whole path, by the rule of
    /// [`names_in_code_span`]: for each paragraph, each code span, and in it each
    /// run of identifiers joined by `::` that no identifier character or `:`
    /// precedes and no identifier character or `::` follows.
    ///
    /// A path `p` is in the set exactly when `names_in_code_span(text, p)`, and
    /// the set is found in one pass over the text, so a section that names many
    /// symbols is judged in time linear in its length.
    pub(crate) fn code_span_paths(text: &str) -> BTreeSet<String> {
        let mut found = BTreeSet::new();
        let mut paragraph = String::new();
        for line in text.lines().chain(std::iter::once("")) {
            add(Work::ContractLines, 1);
            if line.trim().is_empty() {
                for span in code_spans(&paragraph) {
                    paths_in_span(span, &mut found);
                }
                paragraph.clear();
            } else {
                paragraph.push_str(line);
                paragraph.push('\n');
            }
        }
        found
    }
    
    /// The whole paths of one code span (see [`code_span_paths`]).
    fn paths_in_span(span: &str, found: &mut BTreeSet<String>) {
        let ident = |c: char| c.is_alphanumeric() || c == '_';
        let chars: Vec<(usize, char)> = span.char_indices().collect();
        let mut index = 0;
        while index < chars.len() {
            let (at, c) = chars[index];
            let before = index.checked_sub(1).map(|i| chars[i].1);
            if !ident(c) || before.is_some_and(|b| ident(b) || b == ':') {
                index += 1;
                continue;
            }
            // The longest run `ident (:: ident)*` from here.
            let mut end = index;
            loop {
                while end < chars.len() && ident(chars[end].1) {
                    end += 1;
                }
                let joined = end + 2 < chars.len()
                    && chars[end].1 == ':'
                    && chars[end + 1].1 == ':'
                    && ident(chars[end + 2].1);
                if joined {
                    end += 2;
                } else {
                    break;
                }
            }
            let stop = chars.get(end).map_or(span.len(), |(at, _)| *at);
            let after = &span[stop..];
            if !after.starts_with("::") {
                found.insert(span[at..stop].to_string());
            }
            index = end.max(index + 1);
        }
    }
    
    /// Whether a code span of `text` names `path`: the path stands in the span as
    /// a whole path, not as a part of a longer identifier or of a longer path.
    fn names_in_code_span(text: &str, path: &str) -> bool {
        if path.is_empty() {
            return false;
        }
        let mut paragraph = String::new();
        for line in text.lines().chain(std::iter::once("")) {
            if line.trim().is_empty() {
                if code_spans(&paragraph).iter().any(|span| names(span, path)) {
                    return true;
                }
                paragraph.clear();
            } else {
                paragraph.push_str(line);
                paragraph.push('\n');
            }
        }
        false
    }
    
    /// The contents of the code spans of one paragraph: a run of backticks opens
    /// a span that the next run of the same length closes.
    fn code_spans(paragraph: &str) -> Vec<&str> {
        add(Work::ParagraphBytes, paragraph.len());
        let bytes = paragraph.as_bytes();
        let run = |from: usize| bytes[from..].iter().take_while(|b| **b == b'`').count();
        let mut spans = Vec::new();
        let mut at = 0;
        while at < bytes.len() {
            if bytes[at] != b'`' {
                at += 1;
                continue;
            }
            let width = run(at);
            let open_end = at + width;
            let mut scan = open_end;
            let mut close = None;
            while scan < bytes.len() {
                if bytes[scan] == b'`' {
                    let other = run(scan);
                    if other == width {
                        close = Some(scan);
                        break;
                    }
                    scan += other;
                } else {
                    scan += 1;
                }
            }
            if let Some(close) = close {
                spans.push(&paragraph[open_end..close]);
                at = close + width;
            } else {
                at = open_end;
            }
        }
        spans
    }
    
    fn names(span: &str, path: &str) -> bool {
        let ident = |c: char| c.is_alphanumeric() || c == '_';
        span.match_indices(path).any(|(at, _)| {
            let before = span[..at].chars().next_back();
            let after = &span[at + path.len()..];
            !before.is_some_and(|c| ident(c) || c == ':')
                && !after.chars().next().is_some_and(ident)
                && !after.starts_with("::")
        })
    }

    /// The rules of a Markdown file that are not about issue references.
    pub(crate) fn rules(path: &str, text: &str, context: &LinkContext<'_>, out: &mut Vec<Finding>) {
        let scanned = is_scanned(path);
        let parsed = if scanned {
            match Document::parse(text) {
                Ok(document) => Ok(document.body().clone()),
                Err(error) if error.kind().tag() == ErrorTag::MissingFence => Body::parse(text),
                Err(error) => Err(error),
            }
        } else {
            Body::parse(text)
        };
        let body = match parsed {
            Ok(body) => body,
            Err(error) => {
                out.push(Finding::from_parse_error(path, &error));
                return;
            }
        };
        for split in body.split_links() {
            out.push(Finding::from_rule(
                &Rule::SplitLink { form: split.form() },
                path,
                Location::Line(split.line()),
            ));
        }
        if scanned {
            for (line, token) in body.placeholder_lines() {
                out.push(Finding::from_rule(
                    &Rule::Placeholder {
                        token: token.to_string(),
                    },
                    path,
                    Location::Line(line),
                ));
            }
            for block in body.proposed_blocks() {
                let line = Location::Line(block.marker().lines.start);
                out.push(Finding::from_rule(
                    &Rule::ProposedOutsideCapability {
                        slug: block.slug().to_string(),
                    },
                    path,
                    line.clone(),
                ));
                let record = format!("work/changes/{}.md", block.slug());
                if !context.is_tracked_file(&record) {
                    out.push(Finding::new(
                        kind::PROPOSED_MISSING_CHANGE,
                        path,
                        line,
                        format!(
                            "the PROPOSED block names the change `{}`, but {record} does not exist",
                            block.slug()
                        ),
                        "create the change record, or correct the slug in the marker",
                    ));
                }
            }
            for claim in body.claims() {
                out.push(Finding::from_rule(
                    &Rule::ClaimOutsideCapability,
                    path,
                    Location::Line(claim.line()),
                ));
            }
            for marker in body.tested_by() {
                out.push(Finding::from_rule(
                    &Rule::TestedByOutsideCapability,
                    path,
                    Location::Line(marker.line()),
                ));
            }
        }
        links::check_body(path, &body, context, out);
    }

        /// The repository-relative path of the record: the directory of its type
        /// and its slug.
        ///
        /// # Errors
        ///
        /// [`RecordError::BadSlug`] when the slug is not a lowercase kebab-case
        /// slug, so it names no file of the directory.
        pub fn path(&self) -> Result<RelPath, RecordError> {
            let slug = &self.header().slug;
            let bad = || RecordError::BadSlug { slug: slug.clone() };
            if !is_kebab(slug) {
                return Err(bad());

            RelPath::new(&format!("{}/{slug}.md", self.doc_type().directory())).map_err(|_| bad())
        }
    
        /// The text of the record file: the rendering of the `raf-okf` writer,
        /// with the SPDX comment lines of `options` after the opening fence, read
        /// back through the profile and the reference scan at [`Record::path`].
        ///
        /// ```rust
        /// use raf_okf::{CoverageRecord, Exclusion, ExclusionItem};
        /// use raf_workplan::record::{Record, RecordOptions};
        ///
        /// let record = Record::Coverage(CoverageRecord::new(
        ///     vec!["demo".to_string()],
        ///     vec![Exclusion::new(
        ///         ExclusionItem::Prefix("demo::internal".to_string()),
        ///         "Helpers with no contract.",
        ///     )],
        /// ));
        /// let options = RecordOptions::new()
        ///     .copyright("2026 Example Org <dev@example.org>")
        ///     .licence("CC-BY-4.0");
        /// let text = record.text(&options)?;
        /// assert!(text.starts_with("---\n# SPDX-"));
        /// assert!(text.contains("\nscope: [demo]\n"));
        /// assert_eq!(record.path()?.as_str(), "work/coverage/default.md");
        /// # Ok::<(), Box<dyn std::error::Error>>(())
        /// ```
        ///
        /// # Errors
        ///
        /// [`RecordError::BadSlug`]; [`RecordError::SpdxUnset`] or
        /// [`RecordError::SpdxInvalid`] when only one SPDX field is given or a
        /// field is not one line of text; [`RecordError::Build`] when a value
        /// cannot be written in the frontmatter subset; and
        /// [`RecordError::Invalid`] when the text does not read back as a record
        /// with no finding, such as a value the profile refuses or an issue
        /// reference in a command.
        pub fn text(&self, options: &RecordOptions) -> Result<String, RecordError> {
            let path = self.path()?;
            let spdx = spdx::pair(options.copyright.as_deref(), options.licence.as_deref())?;
            let document = match self {
                Self::Evidence(record) => record.to_document(),
                Self::Assessment(record) => record.to_document(),
                Self::Coverage(record) => record.to_document(),
                Self::Debt(record) => record.to_document(),
            }?;
            let text = spdx::with_spdx(document.render(), spdx);
            let mut findings = Vec::new();
            refs::scan(path.as_str(), &text, &mut findings);
            match Document::parse(&text) {
                Ok(read) => {
                    if let Err(violations) = Profile.validate(&read, path.as_str()) {
                        findings.extend(violations.iter().map(Finding::from_violation));
                    }
                }
                Err(error) => findings.push(Finding::from_parse_error(path.as_str(), &error)),
            }
            if findings.is_empty() {
                Ok(text)
            } else {
                Err(RecordError::Invalid { path, findings })
            }
        }
    }

    /// Write the new record `record` below `root`, the directory that holds
    /// `work/`, and return its path.
    ///
    /// The text is [`Record::text`]. The file is created exclusively: a file or a
    /// link already at the path is [`RecordError::Exists`] and is not touched.
    /// The directory of the record type is created when it is missing; it and
    /// `work` must each be a directory or not exist, and a symbolic link, inside
    /// the root or out of it, or a file there is refused during preflight. This
    /// path-based inspection retains no directory handles against a later name
    /// swap. A failure after the file was
    /// created removes it again.
    ///
    /// # Errors
    ///
    /// Every error of [`Record::text`], before anything is written;
    /// [`RecordError::Exists`]; and [`RecordError::Write`] when the file or its
    /// directory cannot be created, in which case no file is left.
    pub fn create(
        root: &Path,
        record: &Record,
        options: &RecordOptions,
    ) -> Result<RelPath, RecordError> {
        let text = record.text(options)?;
        let path = record.path()?;
        files::create_new(root, record.doc_type().directory(), &path, &text).map_err(|error| {
            match error {
                CreateError::Exists => RecordError::Exists { path: path.clone() },
                CreateError::Write { path, source } => RecordError::Write { path, source },
            }
        })?;
        Ok(path)
    }
    
    /// Put the text of `record` in place of the record file that exists at its
    /// path below `root`, and return the path.
    ///
    /// `work` and the directory of the record type must each be a directory, and
    /// a symbolic link there, inside the root or out of it, or a file is refused,
    /// as [`create`] refuses it during preflight. Publication uses those paths
    /// without retaining directory handles against a later name swap. The target
    /// must then be a regular file; a missing file, a
    /// directory and a symbolic link are refused.
    /// The new text is written to a temporary file beside the target, created
    /// exclusively, and renamed over it, so the target holds either its old text
    /// or the new one, never part of either. The file keeps its permissions.
    ///
    /// # Errors
    ///
    /// Every error of [`Record::text`], before anything is written;
    /// [`RecordError::Missing`] when no regular file is at the path;
    /// [`RecordError::Write`] naming the directory refused on the way, before
    /// anything is written; and [`RecordError::Write`] when the temporary file
    /// cannot be written or renamed, in which case the temporary file is removed
    /// and the target is unchanged.
    pub fn replace(
        root: &Path,
        record: &Record,
        options: &RecordOptions,
    ) -> Result<RelPath, RecordError> {
        let text = record.text(options)?;
        let path = record.path()?;
        let write = |source: io::Error| RecordError::Write {
            path: path.to_string(),
            source,
        };
        match files::target(root, record.doc_type().directory(), &path) {
            Ok(Target {
                kind: Some(EntryKind::File),
                ..
            }) => {}
            Ok(_) => return Err(RecordError::Missing { path }),
            Err(error) => return Err(error.into()),
        }
        publish_replacement(root, &path, &text).map_err(write)?;
        Ok(path)
    }
    
    /// Publish the replacement after the regular-file and directory inspection.
    /// The path inspection retains no handles or later-name comparison.
    fn publish_replacement(root: &Path, path: &RelPath, text: &str) -> io::Result<()> {
        let target = fs::canonicalize(root)?.join(path.as_str());
        let temporary = sync::stage(&target, text)?;
        if let Err(error) = fs::rename(&temporary, &target) {
            // Only the temporary file this call created is removed.
            let _ = fs::remove_file(&temporary);
            return Err(error);
        }
        Ok(())
    }

    fn find_all(line: &str, needle: &str, ignore_case: bool) -> Vec<usize> {
        if ignore_case {

    fn numbered_form_hit(line: &str, form: &NumberedForm) -> bool {

    /// A `#` followed by one to five decimal digits that reads as a reference.
    ///
    /// The character before `#` must not be `&` or `#`; a word character before
    /// it (a cross-repository reference, or a keyword with no space) does not
    /// spare the token. The run of word characters after `#` must be one to five
    /// digits, so a letter a-f (a hex colour such as `#1f2`) or a longer run
    /// (`#123456`) is spared. A three- or four-digit token is also spared when it
    /// directly follows `"` or `'`, which is how a colour attribute value is
    /// written in markup. After `:` or a space only a token with a hex letter is
    /// spared, so an all-digit token after a keyword and a colon, or an all-digit
    /// CSS colour, fails closed; write such a colour with letters or as `#112233`.
    fn hash_number(line: &str) -> bool {
        line.match_indices('#').any(|(index, _)| {
            let before = char_before(line, index);
            if before.is_some_and(|c| c == '&' || c == '#') {
                return false;
            }
            let run: String = line
                .get(index + 1..)
                .unwrap_or_default()
                .chars()
                .take_while(|c| is_word(*c))
                .collect();
            let numeric = (1..=5).contains(&run.len()) && run.chars().all(|c| c.is_ascii_digit());
            let colour_context = matches!(before, Some('"' | '\''));
            numeric && !((3..=4).contains(&run.len()) && colour_context)
        })
    }

    ///
    /// A line is banned when it holds an issue or pull request number (a hash and
    /// up to five digits, an issue or pull request label with a number, a tracker
    /// link) or wording that refers to the development process (a task number, an
    /// acceptance label, a reference to a plan or a branch). A colour written as a
    /// hexadecimal triple and numbers in prose are not references.
    #[must_use]
    pub fn banned_in_line(line: &str) -> Option<Banned> {
        if hash_number(line)
            || pull_request_label(line)
            || NUMBERED_FORMS
                .iter()
                .filter(|form| !form.process)
                .any(|form| numbered_form_hit(line, form))
        {
            return Some(Banned::IssueNumber);
        }
        let lower = line.to_lowercase();
        let process = PROCESS_PHRASES
            .iter()
            .any(|phrase| lower.contains(&unclass(phrase)))
            || plan_possessive(&lower)
            || NUMBERED_FORMS
                .iter()
                .filter(|form| form.process)
                .any(|form| numbered_form_hit(&lower, form))
            || acceptance_label(&lower);
        process.then_some(Banned::ProcessWording)
    }
    
    /// The `issue-reference` findings of the text of the file `file`: one for each
    /// line [`banned_in_line`] bans.
    pub(crate) fn scan(file: &str, text: &str, out: &mut Vec<Finding>) {
        for (index, line) in text.lines().enumerate() {
            if let Some(banned) = banned_in_line(line) {
                out.push(Finding::new(
                    kind::ISSUE_REFERENCE,
                    file,
                    Location::Line(index + 1),
                    format!("{banned} is banned"),
                    "describe the system, not the tracker or the process that produced the file; remove the reference",
                ));
            }
        }
    }
